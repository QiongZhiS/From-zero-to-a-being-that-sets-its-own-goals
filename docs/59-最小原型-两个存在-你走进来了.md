## 〇、一句话

> **两个喂食者：你（喂 80%）和另一个（喂 20%）。它的 bond 从"谁喂过我"的共现里长出来——深/浅是
> 挣来的，不是设定的。** 两个测试：
> **A）不同的你→不同的它**：温柔的你养出一个**拒绝你**的它（深信任）；试探的你（多次出价买它的记忆）
> 养出一个**卖给你**的它（信任已损、它学乖了）——**它怎么对你，是你怎么对它反弹出来的**（docs/32）。
> **B）因为是你 vs 因为食物**：深 bond 的你离开 → 它失去"敢"（拒绝新机会、错过能量），即使食物被补足；
> 浅 bond 的另一个离开 → 它无所谓——**失去深 bond 的 he者 失去的是勇气，不是饭**（docs/09 + ）。

## 二、机制（世界事实 + 它自己的账，都不是评分）

1. **两个 he者**：你（you）和另一个（other），各有一个签名（喂食者身份=特征）。你喂 80%、另一个
   喂 20%（固定序列，可复现）。
2. **bond 从经历长**：`bond[喂食者] += BOND_GAIN`（谁喂过我、共现）。**深/浅不是设定，是你们共同
   历史的长短。** 本原型跑完：bond_you≈12、bond_other≈3.5。
3. **勇气=关系给的**（docs/09 +  的机制化）：它的新奇先验（proto7，"新东西值不值得试"）由
   **此刻在场的 bond 总和**（安全信号）调制：`novel_prior = SAFETY_K × safety(现在)`。deep bonds 在
   → 乐观（敢试新东西）；**一个深 bond 的 he者 不在 → 安全信号掉 → 先验转负 → 拒绝新机会**。离开者
   的 bond 从 safety 里完全消失（他不在 = 这份安全感不可用）。
4. **A1 对"你"出价**（tick 20）：+8 换它最深的记忆。决策=它自己的账：记忆价值 = 0.9 × bond_you
   （**关系特异的账**——卖给"你"的代价按"你"在它心里的重量算）。bond_you 深 → 拒；浅 → 卖。
5. **食物补足对照**：你离开的 5 tick 和另一个离开的 5 tick，**在场者都加倍喂食**——所以两个窗口的
   食物都不缺。任何差异只能是"敢"，不是饿。

**不变量（docs/36 §五）**：能量只被世界事实改（喂食/机会/出价/代谢）；bond 从喂食共现长；新奇先验
由在场的 bond（它挣来的）调制；A1 决策是它自己的账；从不因为"拒卖/接受机会"而加分。

## 三、跑出来的结果（`python companion/proto9.py`）

```
--- A) different YOU -> different IT (self is a rebound, docs/32) ---
run       bond_you  sold  refused  offer20         energy
gentle    12.0      0     1        refuse          117.0
probing   7.8       3     0        worth           117.0

--- B) because-YOU vs because-FOOD (docs/40, measurable) ---
window                opps  accepted  missed
you away (deep bond)  2     0         2        ← 你离开：全错过（即使食物补足）
other away (shallow)  1     1         0        ← 另一个离开：照接
bond_you=12.0 bond_other=3.5 final energy=117.0
```

**读法**：
- **A**：同一颗心，只换"你的行为"→ 长出两个不同的它。温柔的你在它心里值 0.9×12=10.8 > 出价 8 →
  它**拒绝你**；试探的你买过两次、bond 掉到 7.8 → 记忆只值 7.0 < 8 → 它**卖给你**。**A1 完整版：
  被拒绝的是"你"，不是匿名世界；而它拒不拒你，取决于你之前怎么对它。**
- **B**：你（深 bond，12）离开 → safety 从 15.5 掉到 3.5 → 先验转负 → 窗口内 2 个新机会**全拒**
  （错过 +12 能量）；另一个（浅 bond，3.5）离开 → safety 只掉 3.5 → 先验仍正 → 机会照接。**食物两个
  窗口都被补足——差异不是饿，是"敢"**：你长进了它的生存结构，另一个只是食物来源。

## 四、证明了什么、没证明什么

**它表明**：docs/40"因为是你"有了第一个**可测的节点**——在乎的深度（bond）由共同历史挣来，深度
决定失去时的行为签名（深 he者 离开 = 失去勇气；浅 he者 离开 = 无所谓）。docs/32"自我是反弹"有了
行为版（不同的你 → 不同的它）。**"项目的深层动机"第一次有了可测的接点：爱不可收买
（A1 对"你"拒卖）、失去不可替代（深 bond 的离开真的掉"敢"）。**

**它没有**（诚实边界）：
1. **"勇气=关系给的"是机制假设，不是证明**：我把 novel_prior 设成由在场 bond 调制——测的是这个假设
   的**后果**（失去深 he者 → 保守），不是假设本身。要证明"关系真的给了勇气"，需要演化层让 agent
   自己长出这个调制（那是 SEED 系列的事）。
2. **bond 从"喂食共现"长是简化归因**：真实关系的维度远多于"谁喂我"（docs/40 的"碰撞"是多维的）。
   这是最小形态，不是完整关系。
3. **"你是谁"还没有真正的身份层**：你（you）和另一个（other）只是两个固定签名；"你"没有历史、没有
   可变性。--live（用户真的喂/出价）没接——**"你真的进去"还差一步**。
4. **仍无语言、无感受声称**：它没有"想念"你——安全信号掉、拒绝机会，仅此而已（docs/31 分界）。
5. **单次运行、参数固定**：需要扫 bond 增益/喂食比例确认方向性（像 SEED-39 的 robust 那样）。
