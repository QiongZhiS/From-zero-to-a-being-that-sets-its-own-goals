# 18 — 可证伪预言：信号质量约束理论的行业检验清单

> **摘要**：docs/12 的命题——任何"从经验中提取信息"的机制受信号质量（信噪比）天花板约束——已在玩具世界（SEED-8/9/14）与深度学习蒸馏（docs/17：self-distill 0.165 vs human-label 0.355）两处证实。本清单把它写成 5 条可证伪预言：合成数据循环触顶、多智能体错误共识锁定、self-play 收益天花板、RAG 知识污染、推理期扩展触顶。每条给出撞墙点、机制、可观察指标、证伪条件、时间尺度与验证路径。任何一条被公开数据推翻，都意味着信号质量假设在该领域不成立。

## 预言 S1：合成数据循环的收益将在 2027 年前后触顶

- **撞墙点**：合成数据规模化——模型自生成语料训练下一代（Phi 式蒸馏、self-refine 数据管线）。这是"教师=模型自己"的行业版。
- **机制**：docs/17 m0_3_distill 是教科书对照——同一蒸馏机制，教师=自生成 → **-16.5pp 灾难**；教师=人类标签 → +2.5pp。自生成教师输出混入模型自身噪声，学生学到的是噪声而非知识，且噪声随代际累积。P16 污染锁死：无验证层时错误共识自我维持；SEED-16：用短期信号（模型自评）度量"最成功"会传播次优。
- **可观察指标**：合成数据占训练语料比例 vs 公开基准性能曲线出现拐点/回落（model collapse）；后一代相对前一代的增益逐代衰减；模型自评置信度与人类评估的相关性下降。
- **证伪条件**：若 2027-2028 年合成数据占比持续上升而基准性能仍线性/超线性提升、无任何回落报告，则本条证伪。
- **时间尺度与信心**：2026-2028，**高**。已有独立证据链（Shumailov 递归训练崩溃、多实验室合成数据质量报告），docs/17 的 -16.5pp 是最强先例。
- **验证路径**：公开系统卡（OpenAI/Anthropic/Google 代际报告）、Shumailov et al. "The Curse of Recursion"（2023）、对方仓库 `m0_3_distill.json`。

## 预言 S2：LLM 多智能体社会将出现"错误共识锁定"（NO RECOVERY）

- **撞墙点**：LLM 多智能体社会/协作框架（生成式代理社会、MetaGPT/AgentVerse 式多智能体、群体蒸馏"最成功输出"）。
- **机制**：SEED-14 棘轮：群体复制"当前最成功"，方差归零、共识锁定——但前提是成功信号稳定。SEED-18：文化层被污染后 **NO RECOVERY**（错误共识自我维持，模仿只复制当前最成功），基因层天然免疫。多智能体社会里"最成功"由短期信号度量（被采纳率/投票数/benchmark 分），污染后无验证层（P16/P19）→ 群体锁死在错误解上。
- **可观察指标**：环境切换后群体坚持旧错误共识的时长（恢复时间）；群体一致性 vs 准确率的负相关；"多数投票劣于随机个体"的公开实验记录。
- **证伪条件**：若公开多智能体实验中，注入错误"最成功"信号后群体能自发恢复（无需外部验证/干预），或从未观察到错误共识持续存在，则证伪。
- **时间尺度与信心**：2026-2028，**中**。机制在玩具世界极强（SEED-18：0.710 vs 0.487 的免疫/锁死分离），但 LLM 社会实验样本少、设计杂，观察窗口不确定。
- **验证路径**：重跑 Park et al. Generative Agents 的注入实验；用 AgentBench 等基准做群体一致性分析。

## 预言 S3：self-play 循环的收益天花板——轮次不是变量

- **撞墙点**：self-play 循环（SPIN、self-refine、自我对弈 RL、自我蒸馏迭代）。核心特征：教师=学生自己，无外部信息注入。
- **机制**：docs/12 统一形式：信号质量低时最优策略是"不基于信号行动"。self-play 中教师信号=自己对"输出好坏"的判断，若该判断本身是噪声（SEED-19：能量残值被省能量策略欺骗的教训——自评指标可被策略性欺骗），每轮迭代只是在同一噪声上重复采样——对方 k_curve 的行业版：候选展开 K=1→100 零增益，因为展开的候选之间没有可探索结构。
- **可观察指标**：self-play 迭代轮次 vs 基准性能曲线在 3-5 轮后进入平台期/回落；自评分数上升而外部评估停滞或下降（自评-外评分化）。
- **证伪条件**：若某公开 self-play 系统在 10+ 轮迭代后仍每轮显著提升外部基准（非自评），且无外部真值/奖励信号注入，则证伪。
- **时间尺度与信心**：2026-2028，**中**。有外部奖励（可验证任务）的 self-play 可长期有效（棋类即如此），理论预言的是"无外部验证的自我迭代"先触顶——须区分验证信号类型。
- **验证路径**：SPIN/self-refine 原始论文迭代曲线重分析；自我对弈 RL 报告按"有/无外部奖励"分组对照。

## 预言 S4：RAG 知识污染——检索信号信噪比下降导致收益反转

- **撞墙点**：RAG 检索增强生成。当语料库开始包含大量 LLM 生成内容（AI 写作/合成文档回流网络），检索结果信噪比下降。
- **机制**：P19 验证桥：外界信息经验证才进内生层——当前 RAG 无验证桥（P16：错误共识自我维持）。检索把"最相似"当作"最可信"，但相似≠正确；语料被污染后检索到的是"最相似的错误"。docs/12：信号质量低时更努力提取（更长检索列表、更大语料）只是把噪声变成更精致的错误。SEED-18：错误内容一旦高频，被检索/被引用的概率自增强。
- **可观察指标**：RAG 基准（RAGAS/RGB 等）收益随语料合成内容占比上升出现拐点；检索相关性上升而答案正确率下降（相似性≠正确性分化）；引用幻觉率上升。
- **证伪条件**：若公开实验表明语料中合成内容占比升至 30%+ 后 RAG 答案正确率仍单调上升、无任何反转，则证伪。
- **时间尺度与信心**：2026-2028，**中高**。机制直接对应 SEED-18（污染锁死）与 P19（无验证桥），行业已有零散证据（合成语料污染、引用幻觉）。
- **验证路径**：对公开 RAG 基准语料注入受控比例模型生成文本并重测（可预注册，仿 docs/17 对照法）；检索污染研究数据。

## 预言 S5：推理期扩展（test-time compute）在无真值领域先触顶

- **撞墙点**：推理期扩展——best-of-N、树搜索、o1 风格长思考（test-time compute scaling）。
- **机制**：对方 k_curve（K=1→100 零增益，成熟后 K=100 反降）+ 我们 B0（SEED-20，规模 300→5000 结论不变）= **数量不是变量**：加探索量只是对同一错误区域重复采样，除非候选间存在可探索结构（盆几何）。有真值/验证信号时（数学、代码可判对错）扩展有收益——验证=信号放大器（SEED-6）；无真值领域（开放生成/问答/写作）的"好/坏"信号来自模型自评，噪声信号下更多思考只是更精致的错误（docs/12）。
- **可观察指标**：有真值域 vs 无真值域的 scaling 曲线斜率分化；无真值域长思考 token 量与人类评估质量出现饱和或反降；best-of-N 收益随 N 的衰减速率。
- **证伪条件**：若公开实验显示无外部真值的开放领域，test-time scaling 与有真值域同等持续扩展（斜率不衰减），则证伪。
- **时间尺度与信心**：2027-2029，**低-中**。方向由 k_curve+B0 双重支持，但"何时触顶"依赖具体领域与验证信号设计，行业尚在早期，窗口难定。
- **验证路径**：o1/Kimi k1.5/DeepSeek R1 公开 scaling 曲线重分析（按可验证/开放任务分组）；对方 `k_curve.json` + 我们的 SEED-20。

## 预言之间的依赖关系

- **S1 与 S3 同命**：共享机制假设"教师=自己时，输出噪声随迭代累积，量无法弥补质"（docs/12 推论 3 + docs/17 命题 2）。若 S3 被证伪（self-play 长期有效），S1 的"合成数据触顶"压力也须下调。
- **S2 与 S4 同源**：共享"污染自增强 + 无验证层的锁死"（P16 + SEED-18）——S2 是群体内共识锁死，S4 是语料-检索回路污染，是同一"错误共识自我维持"机制的两个载体。
- **S5 独立于前两者但依赖最强**：共享"数量不是变量"（k_curve + B0），额外依赖"验证信号可获得性"（SEED-6/19 的信号放大器假设）——有验证则扩展有效，无验证则触顶。
- **共同地基**：五条全部依赖 docs/12 的单一命题——提取机制的共同天花板是**信噪比，而非计算量或数据量**。任一被证伪，只说明该领域存在我们未知的信号源或验证机制；若五条全被证伪，docs/12 作为跨范式假设（docs/17 第 7 节）需降级回"玩具世界现象"。
