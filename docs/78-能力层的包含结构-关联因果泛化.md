## 〇、一句话

> **能力层不能平铺着实现——概念是包含关系**：
> ```
> 泛化（容器）⊇ { 去噪, 压缩, 关联, 因果, 类比 }
>   去噪 ⊂ 压缩 ⊂ 泛化     ← 能力侧：从噪声提结构 → 留结构丢细节 → 迁移
>   关联 ⊂ 因果 ⊂ 泛化     ← 学习侧：观察频率 → 干预测试(do-operator) → 结构迁移
>   因果 = 泛化的最强形态  ← 跨环境不变的结构 = 可迁移的结构（Pearl：因果是干预下的不变性）
> ```
> **SEED-44 把它做成机制**：同一世界、同一信念结构与被动更新规则，唯一差别=因果学习者有
> do-operator（定期主动重测过时信念）。食物搬家后（SEED-26 动态世界）：**关联学习者 17/30 存活
> （43%），因果学习者 28/30（93%）**——被动观察者在适应期把自己烧干（锁死在旧结构上），
> 干预是信号放大器（docs/12/SEED-6），是唯一能打破"旧结构锁死"的。**只有干预式更新的知识
> 才能在环境变时迁移；纯观察频率是死知识。**

## 一、概念包含关系（为什么能力层要按这个叠）

用户点破"有些概念是包含关系"——泛化不是单一能力，是容器：
- **去噪 ⊂ 压缩 ⊂ 泛化**（docs/25/26）：去噪=从噪声提取结构；压缩=保留结构丢细节
  （rate-distortion/IB，docs/68 §A2 定理级）；泛化=把学到的结构用到新输入。三者的关系是
  逐层包含——泛化以压缩为内部，压缩以去噪为前提。
- **关联 ⊂ 因果 ⊂ 泛化**（学习侧）：关联=观察频率（A 和 B 一起出现）；因果=干预下的
  **不变性**（"无论我怎么做，A 都导致 B"——Pearl 的 do-演算）；泛化=结构迁移。因果是泛化的
  **最强形态**：跨环境不变的结构才是可迁移的结构。所以"泛化能力"里最高的那层是因果，
  "因果推断"是最深的泛化。
- 对应项目零件：关联=proto7/body 的观察归因；因果=SEED-6 的 do-operator（干预，不是观察）；
  泛化=docs/25 的压缩+docs/26 的去噪；动态判据=SEED-26"世界会搬走"。

## 二、机制（seed-44/seed44.py，纯本地）

- **世界**：5×5 格，食物随机再生（P_REGROW 0.12），第 30 天**全部搬家**（SEED-26 动态）；
- **两种学习者**，belief 结构与被动更新规则**完全相同**（空格 → belief ×0.80 慢更新）：
  - `assoc`（关联）：只按 belief 走（exploit 最大信念 / 随机探索），从不主动重测；
  - `causal`（因果）：同 + **do-operator**：每 2 天主动重测"过时的高信念格"
    （SEED-6 do→observe→update；SEED-27 独立验证：旧信念→重新测试，不信任陈货）；
    干预的空结果 → belief ×0.30 **快翻**（docs/12：验证是信号放大器——干预的信号质量
    > 被动观察，这是唯一的规则差别）；
- **测量**：存活、搬家后吃到新食物的次数（迁移）、末能量。

## 三、结果

| mode | 存活（5 seeds） | 存活（30 seeds） | 搬家后吃到（均） | 末能量（均） |
|---|---|---|---|---|
| assoc（关联/观察） | 3/5 | **17/30（43%）** | 8.9 | 12.4 |
| causal（因果/干预） | 5/5 | **28/30（93%）** | 10.4 | 16.8 |

- **分离是真实的**（30 seeds 方向稳定）：因果学习者存活率翻倍（93% vs 43%）、搬家后吃到更多、
  末能量更高；
- **为什么**：搬家后 assoc 继续 exploit 旧信念（已空）——被动观察每次 ×0.80，慢，它在适应期
  一直挨饿（MISS+METAB），把自己烧干（SEED-26 过度信任锁死）；causal 的 do-operator 每 2 天
  重测旧信念，干预 ×0.30 快翻 → 发现"它搬走了" → 转去探索 → 吃到新食物。
- **滞后指标诚实记录**：两者"第一口新食物"的时间接近（都在搬家后 ~3 天）——因为 regrow 随机，
  探索总能撞到；真正分开的是**适应期的代价**（能量烧干 vs 保住），不是首口时间。

## 四、诚实读法

1. **包含关系在机制上兑现**：关联(观察) ⊂ 因果(干预) ⊂ 泛化(动态迁移)——只有干预式更新的知识
   才能在环境变时迁移；纯观察频率是死知识。这就是 SEED-6/26/27 线的显式化。
2. **干预=信号放大器是唯一的规则差别**（docs/12）：被动观察 ×0.80、干预 ×0.30——同一个世界、
   同一套信念，只差"敢不敢主动重测"，结果 43% vs 93%。**因果能力不是多了一套知识，是多了
   一个 do-operator。**
3. **能力层与主体层的关系**（docs/75 反驳后仍成立的）：泛化/因果**可以无主体存在**（LLM 就有，
   Kıcıman 2023 因果结构发现）——本实验的两种学习者都没有主体（没有会失去的立场），但都有
   能力签名。项目要的不是"更多泛化/因果"，是**有立场的泛化/因果**（docs/48：根=会失去、
   果=预见错会死）——那需要载体（A2/A4），不是能力层能给的。
4. **诚实边界**：toy 探针；泛化/因果是丰富概念（类比/反事实/组合/层级抽象 未实现）；
   它显示"干预>观察（对迁移）"这个**包含机制**，不是完整 AGI 能力。
5. **与 P20 一致**：能力被信号质量封顶（docs/12）——本实验里两者都被噪声封顶（regrow 随机），
   干预是唯一能突破"旧结构锁死"的（=提高信号质量的机制侧）。
