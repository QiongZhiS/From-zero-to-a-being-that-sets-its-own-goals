# 09 — 业内方案对照：我们的每个发现都有人在做

> 检索日期：2026-08。我们的实验撞上的每个问题，业内都有对应流派。
> 本文档逐个对照，明确我们与它们的差异和位置。

## 我们的独特位置（为什么不是重复造轮子）

1. **无外部奖励的严格性**：所有 SEED 实验里，"活着"不是目标，是物理结果——
   业界的 intrinsic motivation 仍是"奖励设计"，我们的好奇心/勇气是被选择出来的
2. **完整思想链**：docs/01→08，从"算法不高深"到"倒果为因"，哲学→实验一条线——
   论文里看不到"我们为什么做"和"我们怎么失败的"
3. **诚实记录失败**：七个负面结果（SEED-0/7/8/10/11 等）全部记录——
   业界论文几乎不报告"演化没有涌现勇气"这类结果
4. **规模诚实**：我们不假装玩具规模能产生 AGI——docs/08 明确记录
   "从零长勇气需要更大舞台"，并指出这是规模问题不是架构问题

## 最有价值的对齐（下一步候选）

- **EvoAgent**（持续世界模型 + 自主演化）最接近我们想做的"动态可预测结构 +
  开放空间"——它的"持续世界模型"就是我们要的"可利用结构"
- **Overflow / Jeff Clune 路线**：质量多样性 + 环境自动课程——这正是我们的
  SEED-10/11 缺的（没有这些机制，开放演化必然退化或灭绝）
- 若继续：SEED-12 可以对标 EvoAgent，在玩具规模里加"最小质量多样性"
  （保留行为多样性，防止收敛到固着）
