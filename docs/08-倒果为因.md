# 08 — 倒果为因：能力是谁创造的？

> 用户在 SEED-9 之后提出的方法论批判，九代实验中最锋利的一刀。
> 本文档记录这个批判、我们的承认、以及 SEED-10 的回应。

## 批判

九代实验的每个"能力参数"——hunger、memory_weight、curiosity、learning_rate、
verification_bias、boldness——**都是我们先定义好，再让演化调值的**。

- 我们预设了"勇气"这个参数维度 → 演化在 0~1 之间选了 0.425
- 结论"演化创造了勇气"是**倒果为因**：真正创造勇气的是我们（把勇气写进了基因空间），
  不是自然选择

**这不是调参技巧问题，是方法论问题**：照这个模式走下去，我们永远只能发现
自己已知的能力（预设清单），永远无法发现真正新的事物。

## 澄清：真实生物学也"预设"

自然选择从没"创造"过能力维度——它只是在物理允许的空间里选择：
- DNA → 蛋白质空间是物理/化学预设的
- 动物行为学里的 boldness-shyness 是选择在"神经机制空间"里调出来的

**区别不在"有没有预设"，在空间的开放性**：

| | 物理世界 | 我们的代码 |
|---|---------|-----------|
| 能力空间 | 无限、不可预测、超越设计者 | 有限、完全可预测 |
| 命名 | 事后（考古） | 事前（预设） |
| 我们能发现什么 | 意想不到的新事物 | 我们已知的一切 |

## 出路

让能力空间像物理世界一样开放：
1. **机制开放**：神经网络权重为基因，能力清单不预设
2. **命名后验**：先演化，再分析行为，最后命名（考古，不是设计）
3. **感知只给原始物理量**：能量、命中率、视野方向——不给"勇气""好奇"这些语义输入

## SEED-10 的承诺

如果演化出的行为里真的出现了"模糊信号下提前撤离"的模式——
**那是从 71 个随机权重里长出来的，不是我们写进去的**。那时我们才有资格说"勇气涌现了"。

## SEED-10 实测结果

**涌现了，但不是勇气**：种群在富饶世界稳定存活（pop 10-17），考古显示网络
收敛到"永远 GATHER"——**固着滤食策略**（所有情境 88-100% GATHER，移动几乎消失）。
我们预设的"觅食通路"被演化抹掉了。

| 发现 | 含义 |
|------|------|
| 命名后验可行 | "固着"不是我们预设的概念，是从数据里读出来的——开放空间能产生超出预设的行为 |
| 无压力 → 最简解 | 富饶世界 = 惰性系统的演化尺度复现：最小化消耗的极限是静止 |
| 开放空间需要结构 | 纯随机必死（先验鸿沟演化版）；压力太大灭绝；中间地带催生丰富行为 |

## 对"倒果为因"的最终回答

预设不可完全避免（感知输入、网络结构、压力参数都是我们选的），但可以最小化：
**开放空间 + 事后命名**——让"我们已知的"不进入基因空间，让"未知的"有机会出现。

同时确认了一个更深的限制：**演化需要设计者提供压力**。
固着者不需要勇气，因为世界没逼它；勇气在 SEED-9 出现，是因为我们设计了枯竭。
造物主（我们）通过"世界压力"决定能力空间的形状——这不是倒果为因，
是**因果的源头本来就在造物主手里**（docs/04）。

## 局限（诚实记录）

- 感知输入（哪些原始量）仍是我们选的——感知是物理接口，无法完全中立
- 网络结构（层数/宽度）仍是我们选的——结构本身携带偏置
- 真正的"开放"是程度问题：SEED-10 比 SEED-1~9 开放，但不如物理世界开放
- SEED-10 涌现的行为是退化的（固着），不是丰富的——开放不等于丰富，丰富需要压力
