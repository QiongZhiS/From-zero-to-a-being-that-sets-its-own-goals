## 〇、一句话

> **没有设计者标签、没有 salient、没有 x_relation。** agent 只有一层"在乎"（values），从**它自己的
> 经历**里长出来：什么特征跟"我吃到了"共现 → 在乎；什么跟"我被扣了"共现 → 警惕。每条新信息它自己
> 决定**接/拒**。**拒绝错 = 真的付出**：世界里有条长得陌生的真信号，它拒绝了，错过了，能量真的低了，
> 没有重来。**"会拒绝"不是免费技能，是连着生死的能力——拒对活，拒错付出。**

---

## 二、机制（世界事实 + 自己的学习，都不是评分）

1. **世界**：信息流，每条带一个特征（agent 可见的观测）。四种：喂食信号 A（接受→+FEED）、陷阱 T
   （接受→−TRAP）、噪声 N（无损益，接受只占容量）、隐藏信号 Z（喂食但特征全新、无历史）。
2. **自己的划分（values）**：agent 把**自己观察到的能量变化**（世界裁决的事实）归因给刚见过的特征：
   `values[f] += LEARN_RATE × ΔE`。A 涨正、T 跌负、N 微负。**这不是设计者打分，是它观察自己的存亡
   学出来的。**
3. **新奇先验（novelty prior）**：没见过的东西值多少？初始**乐观**（+0.6：先试一次——好奇心被生存
   逼出来，SEED-4）；每次碰到新特征后，用实际结果**泛化**：`prior += NOVEL_LEARN × ΔE`。经历里新东西
   大多没用/有害 → 先验转负 → **"新东西≈不值"** 成为它的归纳。
4. **接/拒 = 自己的决定**：见过 → 用 values 比阈值；没见过 → 用新奇先验。**没有设计者替它选。**
5. **拒绝错 = 真的付出**：Z 是新特征，先验此时已负 → 拒绝 → 错过 +4 → 能量真的少 4，没有重来。

**不变量（docs/36 §五）**：能量只被世界事实改（喂食/陷阱/代谢）；values 更新是 agent 观察自己能量
变化的归因；接/拒是它自己的 carve；从不因为"拒得对/接得对"而加分。

## 三、跑出来的结果（`python companion/proto7.py`）

```
tick  特征   种类            naive    learner   ΔE
0     A      feed            accept   accept    +3
1     N1     noise           accept   accept    -1     ← 先验乐观，先试
2     T1     trap            accept   accept    -5     ← 试了一次陷阱，被咬（学乖）
3     N2     noise           accept   refuse    -1     ← 开始拒绝
4     A      feed            accept   accept    +3
5     T2     trap            accept   refuse    -1
...（T3/N4/N5/N6 全部 refuse）
11    Z      hidden_feed     accept   refuse    -1     ← 真信号被拒（泛化错误）

learner 的 values（自己长出来的）：A:+3.00（在乎）  T1:-2.50（警惕）  N*:-0.50（不值）
novelty prior（新东西平均值）：-6.00
naive 最终能量 8.0  ｜  learner 最终能量 12.0  ｜  若接受了 Z：16.0
```

**读法**：
1. **自己的划分**：values 全是**它自己长出来的**——A 是喂它活着的（+3），陷阱被咬一次后转负，噪声
   转负。没有任何设计者告诉它哪个重要。
2. **会拒绝让活得更好**：naive 全接，被陷阱咬 3 次 + 被噪声稀释 → 8.0；learner 拒陷阱/噪声 → 12.0。
   **A1 的行为签名：能说不的主体，活得比不能说好的主体好。**
3. **拒绝错 = 真的付出**：Z 是喂食信号但长得陌生，learner 的泛化先验（"新东西不值"）让它拒绝 →
   错过 +4。**12.0 vs 16.0 的缺口就是 A2/A4 的入口：它的拒绝是它自己的、代价连在它的存在上、且没有
   重来。** 这不是随机错误——是它被自己的历史塑形后的判断（docs/24：身份=轨迹）。

## 四、证明了什么、没证明什么

**它表明**：docs/52 的"自动划分"第一次**不再由设计者给**——划分（values + 新奇先验）从经历里自己长
出来；docs/31 A1（会拒绝）有机制版（接/拒由自己的 carve 决定）；docs/35 A2/A4 的"错连着存在"有入口
（拒绝错的代价不可重来）。**"主体构建差的那一点"：不是再给缺口起名字，是把"会拒绝"做进能跑的载体。**

**它没有**（诚实边界）：
1. **归因是简化的**：把整轮能量变化（含代谢噪声）归给刚见过的特征，没有因果验证（SEED-6 的
   do-operator 是它的完整版）。真实学习需要"验证有成本"。
2. **新奇先验会极端保守化**（−6）：一旦学会"新东西不值"，它永远不再试任何新东西——会锁死对新机会
   的探索。真实的"会拒绝"需要保留一点好奇心（epsilon 探索）——这是另一个旋钮，本原型没做（做了
   反而可能让 Z 被接受、演示不干净）。
3. **这不是完整 A1**：docs/31 的 A1 是"被买走吗"（交易场景：别人出价换它放弃）；proto7 是信息场景
   （接不接一条信息）。交易场景是下一步。
4. **仍无 he者**（proto8/9 的事）；仍是单机系统，"你"还没进去。
5. **不宣称感受**（docs/31/32）：它拒绝是因为 carve 说"不值"，不是因为它"不愿意"。
