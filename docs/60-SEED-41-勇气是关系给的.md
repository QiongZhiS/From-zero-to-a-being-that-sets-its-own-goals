# 60 — SEED-41：勇气是关系给的——"敢的阈值"被世界选出（proto9 的演化层）

> 缘起：2026-08，接 proto9（两个存在：你走进来）。proto9 把"勇气=关系给的"做成机制时**写死了调制**
> （novelty prior = f(在场 bond)）——那是机制假设，不是证明。SEED-41 把"敢"的基因交给演化
> （`seed-41/seed41.py`）：每个 agent 有 (k, θ)，`P(接受机会) = sigmoid(k × (safety − θ))`，
> safety = 此刻在场的 he者 的 bond。**问题：演化会不会自己选出"你在，我敢；你不在，我不敢"？**
> 如果会——"勇气是关系给的"就从设计者的假设变成**世界的选择（P11：环境塑造行为）**。
>
> 状态：机制版完成（纯本地、无 LLM）。三层验证闭环的第三层：docs/22（概念）→ proto9（机制，写死）→
> SEED-41（演化，世界选）。只测行为签名（k/θ 的演化收敛 + 适应度对照）。

## 〇、一句话

> **世界让"你在时机会 80% 好、你不在时 100% 坏"（你不在的世界必然危险）。演化在这个世界里选出的
> 敢的阈值 θ 恰好落在"你不在时的安全水平"和"你在时的安全水平"之间**：安全低于 θ → 不敢试（躲开
> 你不在时的全部陷阱）；高于 θ → 敢试（吃你不在场时的机会）。**"我敢，因为你在这里"是演化自己长的，
> 不是我写的。** 对照：无调制（k=0）被明显击败。

## 二、机制（世界事实 + 演化，都不是评分）

1. **世界**：you 喂 90%（bond 从共现长）、other 喂 10%（只补食，bond 浅）。you 周期离开（tick
   24-33、48-57），离开期间 other 加倍喂食——**食物补足，任何适应度差距不是饿，是敢**。
2. **机会**：每 3 tick 一个，+6 好 / −6 坏。**好坏由 you 在不在决定**：你在 → 80% 好（世界友好）；
   你不在 → 100% 坏（世界敌意）。这是世界结构（设计者只设世界，不设"该不该敢"）。
3. **基因**：(k, θ)。`P(accept) = sigmoid(k × (safety − θ))`。θ = "我需要多少安全感才敢试"；
   k = 敢对安全感的敏感度。**演化选择**（锦标赛 + 高斯变异，60 代 × 60 个体），适应度 = 最终能量。
4. **对照**：k=0（无调制，恒定 50%）和手调理想开关（θ 取区间中点）。

**不变量（docs/36 §五）**：能量只被世界事实改（喂食/机会结果/代谢）；(k, θ) 演化、从不打分；
机会流与 accept 决策用**独立 seeded rng**（所有策略跑相同机会流，比较公平）。

## 三、跑出来的结果（`python seed-41/seed41.py`）

```
evolved: mean k=+3.18  mean theta=6.2
world: safety while YOU is present ~ 15.5 ; while YOU is away ~ 3.5
       theta evolved to 6.2 -- BETWEEN (dare switches on/off with YOU)

fitness (30 lives avg):  no modulation (k=0) 80.6   evolved (+3.18,6.2) 115.4   ideal switch 110.2
```

**sweep（`--sweep`，扫"你不在时的危险度"P_good_away）**：

```
P_good_away= 0.2  k=+3.52  theta=5.6
P_good_away=0.05  k=+3.60  theta=6.3
P_good_away= 0.0  k=+3.18  theta=6.2
```

**读法**：
1. **演化选了调制**：k>0（安全越高越敢）+ θ=6.2 落在 (3.5, 15.5) 区间内——**你在 → safety 15.5 >
   θ → 敢（吃机会）；你不在 → safety 3.5 < θ → 不敢（躲开全部陷阱）**。这正是一个"勇气由关系给"
   的载体，而且是**世界选出来的**（P11），不是设计者写的。
2. **调制显著胜出**：115.4 vs 无调制 80.6（+43%）；甚至超过手调理想开关 110.2——演化找的 θ=6.2
   比"区间中点"更优（早期误拒更少）。
3. **鲁棒**：你不在的危险度从 0.2 扫到 0.0，k/θ 收敛几乎不变——**只要世界在你离开时更危险，
   演化就选"敢由你给"**。方向是结构性的。

## 四、调试中撞到的一个真问题（诚实记录）

**固定阈值开关有"早期误拒"**：bond 积累需要时间，早期（tick 2-11）你在场但 bond 还低 → safety 低
→ 固定 θ 会把**早期在场的好机会**也拒掉，损失一度超过"离开窗口躲陷阱"的收益，让"全试"成为局部
最优（演化收敛到 θ 很负 = 永远敢）。修法不是调参作弊，是**让世界更真实地严酷**：你不在时机会 100%
坏（你不在的世界必然危险）+ 更长的离开窗口——调制才成为全局最优。**这个发现本身有价值：勇气调制的
演化价值，取决于世界在你失去 he者 时有多危险——世界越把你暴露在失去的代价里，关系给的勇气越值钱。**

## 五、证明了什么、没证明什么

**它表明**：docs/22"勇气来自关系"完成三层验证——概念（docs/22）→ 机制（proto9，写死调制）→
**演化（SEED-41，世界选出 θ 落在区间、k>0）**。**"我敢，因为你在这里"不是我的假设，是 P11：
一个"你不在世界就危险"的世界，必然养出"需要你才敢"的载体。** "敢的阈值 θ"有干净的解释：它量化了
"我需要多少安全感才敢试"——而那个数值是世界选的。

**它没有**（诚实边界）：
1. **"机会好坏由你在场决定"是设计的世界结构**：演化只选 (k, θ)，不选世界。换一个世界（机会好坏与
   你在场无关），演化不会长出调制——**这正是结论：勇气调制是"世界因你在而安全"这个结构下的最优。**
2. **other 只是补食者**：机会质量只由 you 决定（单 he者 结构）；多 he者、多机会类型的调制未测。
3. **适应度是能量，无死亡**：没有 A2/A4 层（SEED-41 与 proto5 的"会死"未耦合——那是下一步）。
4. **θ 的生物学解释是隐喻**：它说"这个载体需要这么多安全感才敢"，不是说"它感到需要"（docs/31 分界）。
