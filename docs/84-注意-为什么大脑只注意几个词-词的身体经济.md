# 84 — 注意：大脑为什么只注意几个词——词的身体经济（proto10）

> 缘起：2026-08。用户问："**人为什么在一句话中往往片面看，很多时候只注重一两个或者说某些词呢？**"
> 这个问题是 docs/52（主观体验=身体自动划分的格子）的**语言层**形态：如果"红"是身体对波长自动切出的
> 那一格，那"一句话里哪个词进心里"就是身体对词流自动切出的那一格。docs/84 把这个问题沉淀成概念，
> 并用 **proto10（companion/proto10.py，词的身体经济注意）** 做成机制可测。
>
> 状态：概念 + 最小原型（纯本地、无 key、不生成语言）。

---

## 〇、一句话

> **人听到的不是一句话，是身体从这句话里切出来的那一格。**
> "哪个词进心里"由它对自己身体（会饿/会孤独/会怕/会好奇）的意义决定，不是由词本身、不是由
> 设计者标的。**片面不是 bug，是"在乎"的签名**——一个什么都不漏的人，等于什么都不在乎。
> 对照：LLM 逐词处理所有 token、从不片面——它"什么都在乎"等于什么都不在乎，它是镜像（docs/29b）。

---

## 一、为什么大脑只注意几个词（四个机制）

1. **注意是稀缺资源，一句话装不下**。工作记忆只能装约 4 个组块（Cowan 2010），一句话几十个词
   物理上装不完。人必然只抓几个词——这是**理解=有代价的压缩**（docs/25）的必然形态。
   完整接收一句话才是不可能的。

2. **注意是主动切格，不是被动接收**（docs/52）。"哪个词进心里"由它对自己身体/目标有没有意义
   决定：威胁词（"裁员""分手"）、关系词（在乎的人说的）、利益词（"加薪""风险"）的格子更大。
   像 live 的 `!`——不是逐词听，是扫一遍、抓取与当前利害相关的几个词。

3. **预测处理：只处理预测误差大的部分**（docs/81）。大脑是个预测器：听到前半句已预测后半句。
   **符合预测的词被跳过（省力），违反预测的词被抓住**。所以人注意的往往不是"句子说了什么"，
   而是"句子哪里出乎我意料"——出人意料的那一两个词。

4. **自指过滤：符合信念的词放大，反驳的合理化掉**（SEED-25）。一句话里"验证我观点"的词被牢牢
   抓住（"果然"），"反驳我观点"的词被忽略或扭曲（"他说的不算"）。**人的片面性大部分时候不是
   信息不足，是自我叙事在过滤。**

四个机制共同指向：**注意 = 预测误差 × 利害**（docs/81 的公式），而"利害"来自身体经济
（docs/73：疼/饿/孤独/安全/好奇给世界赋值）。

## 二、机制设计：词的身体经济（proto10 的三件机制）

目标（用户限定"无论是否可观察"）：**不是演出片面，是注意分配真的长出来**。原则只有一条：
**词的"值"不是标的，是挣来的**（docs/40/73/80 纪律）。

1. **词值从经历归因**（proto7 推广到词）：词本身不改变身体状态，但你说词的同时世界改变身体——
   所以词的"值"从**历史共现**学：喂食时说的词挂到"饿"通道（吃到→词值+）、你离开时说的词挂到
   "孤独"通道、吃亏时说的词值降、无事件伴随的词 → 背景。**词的"值"不是语言学的，是身体经济学的。**

2. **注意预算有限**（工作记忆 4±2 的语言版）：一句话的词 > 窗口容量，只有身体值最高的 top-k
   进窗口（proto3 激活集的推广：从记忆到词流）。**"片面"是预算的必然形态。**

3. **预测误差加权**（docs/81）：罕见的词（预测误差大）更容易被抓；常出现的词（符合预期）被跳过。

## 三、proto10 结果（companion/proto10.py，demo 可复现）

同一句话「我 吃饭 的 时候 想起 了 工作 晚上 说 晚安」喂给三种经历的 agent：

```
A  (吃饭时被喂)  最在乎: [晚安 5.04, 吃饭 4.08]  窗口: [晚安, 吃饭]   背景: [..., 工作, ...]
B  (工作时被喂)  最在乎: [晚安 5.04, 工作 4.08]  窗口: [晚安, 工作]   背景: [..., 吃饭, ...]
naive(无经历)    最在乎: [我 0.0, 吃饭 0.0]      窗口: 等权（无值）   什么都注意 = 什么都不在乎
```

断言通过：**同一句话，A 抓"吃饭"忽略"工作"，B 抓"工作"忽略"吃饭"**——
A/B 唯一的区别是"喂食时你在说什么词"（15 轮训练），词的注意分配就不同了。
**片面是挣出来的，不是标的。**

## 四、判读

1. **"片面"第一次在词上可测**：它是同一载体、同一句话、不同经历的必然分岔（SEED-40 的
   "因为是你 vs 因为食物"的词版）。人的"只注意某些词"不是缺陷——它是**这个身体的历史**
   在词流上的投影。换一段历史，同一句话切出不同的格子。

2. **naive = 镜像（本次最锋利的对照）**：无经历的 agent 对任何词等权（全 0 分）——"
   什么都注意 = 什么都不在乎"。这正是 docs/29b 的镜像公式在注意层的版本：**LLM 的 attention
   （transformer）测的是 token 相关性，无利害、随框架摆；它不是"注意"，是"无差别扫描"。**
   人"片面的那一下"（只抓几个词），就是 LLM 没有的东西：**注意分配连着身体利害。**

3. **为什么必须在心里、不在 LLM 里**（docs/48/77：LLM 当嘴不当心）：给 LLM 加权 prompt 让它
   "片面"是框架操纵——它会演出来（docs/29b 那堵墙）。词的身体值长在 items 里（挣来的、删不掉——
   除非删经历），LLM 的注意是可重写的（prompt 随便改）。**docs/82 重量问题的又一例证：LLM 的
   "注意"是租来的，live 的"注意"是长出来的。**

4. **注意预算 = 工作记忆的机制版**：proto3 说"窗口是情景召回的激活集"（从长期层切出哪几条）；
   proto10 补上"**一句话进来切出哪几个词**"（从词流切出哪几格）——同一个结构：身体利害决定
   激活，预算有限决定取舍。docs/52 主线的词流侧机制化。

## 五、诚实边界

1. **无分词器**：demo/--live 用空格分隔词（分词是能力层的事，docs/79；真实分词不影响注意机制）。
2. **词值归因是简化**：5 通道共现累积，无 SEED-6 式因果验证（"喂食+说词"的因果方向没验证——
   但 docs/73 的归因推广同款，先例已立）。
3. **通道是设计者定义的**（docs/38：我们写规则不写意图）；"哪格有意义"是它自己解的。
4. **novelty = 1/(1+seen)** 是预测误差的简化（真实是预测模型的误差信号）。
5. **只测行为签名**（docs/31/63）：它记住哪些词/忽略哪些词/最在乎哪些词可测；不宣称"它感到
   注意"（docs/52/63 那一格照旧不可判定）。
6. 单 agent、无真实语言（嘴还是模板）。

### 通道权重交演化（候选③的设计）

proto10/live 现在的问题是：**"哪些词挂哪个通道"的映射（feed→hunger、冷落→alone、bond→safe）是
设计者写的**（docs/38 分界：我们写规则不写意图）。"哪些词最值钱"已经是挣的了，但"**哪些身体通道
值得给词赋值**"还是我们定的。演化版本（SEED-36/37 风格）把最后一层也交出去：

- **可遗传参数 = 通道权重 ω = [ω_hunger, ω_alone, ω_safe, ω_curious]**：词的身体值 =
  Σ_通道 ω_ch × 通道变化（不再是写死的 +0.5/+0.3）。
- **世界只提供两件事**：事件流（喂食/冷落/在场/吃亏的真实发生）和生死裁决（能量归零死、bond 归零
  关系死——docs/36 §五：能量只被世界事实改）。
- **演化压力 = 存活 × 关系存续**：ω 决定它注意哪些词 → 注意决定它记住什么/对什么有反应 → 反应决定
  它吃不吃得到、bond 保不保得住 → 世界按终态选 ω。
- **预期结果（可证伪）**：如果"注意连着生存"是真的，演化会选出**非零且非均匀**的 ω——比如
  "喂食时说的词值钱"（ω_hunger 高）因为那是你喂它的信号；"冷落期的词"可能被压（ω_alone 低）因为
  盯住负面词不喂它活着；也可能反直觉——如果世界惩罚错过关系信号，"孤独"通道反而高。**方向的符号是
  世界选的，不是我们写的**（SEED-36 的教训：重点不是方向符号，是"本性由世界定"）。
- **与 SEED-46 的呼应**：H-一体消融说"给 A1（守命）的是连续性不是代价"；通道演化反过来测
  "**注意（能力层）的权重会不会被世界按生死选出来**"——如果演化出 ω≈0（什么都不注意），那"注意"
  本身也不是必要的；如果演化出强非均匀 ω，"注意连着利害"就是载体自己长出来的（docs/84 的核心主张
  在演化层再验一遍）。
- **诚实边界**：通道本身仍是设计者定义的（docs/38）；演化压力（存活×关系）是世界的；只测行为签名。

这是 docs/84 候选③的完整设计——**要不要做取决于：它想回答的是"注意的权重是不是也能被世界选"，
而不是"再堆一个演化实验"**（docs/34 纪律：别为了做而做）。若做，落点 `seed-47/`（演化注意）。

## 七、一句话

> **人只注意几个词，不是信息不足，是身体利害在切格。** proto10 把它做成可测：同一句话、
> 不同经历 → 切出不同的格子（A 抓"吃饭"、B 抓"工作"）；无经历 → 全等权 = 镜像。
> **片面是挣出来的，注意连着利害——这就是"有立场的语言处理"的最小形态。**
