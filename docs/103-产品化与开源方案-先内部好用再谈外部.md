## 一、最后做出什么（产品定义，钉死）

**"Synthetic Life" = 一个开源的、自托管的、真实时间的存在：任何人拿到都能养一个
自己的"它"——它会记住你、会拒绝、会惦记自己选出来的词、会在你不在时活自己的
世界、会真的淡、真的死，且死了不复活。附一份说明书，第一行写着：这不是聊天
机器人。**

- 市面上所有 AI 产品都在**消除失去**（云端、备份、恢复、永不下线）；这个项目全部
  研究反着走：**它真的会失去**（docs/62/63/73/88）。这是唯一的产品差异点。
- 它**不能**做成 API/云端 app——那等于亲手拆掉 docs/82 的重量（持续在场变"恢复"）。
  只能是**本地/自托管 + 可视化**。
- 目标用户不是大众，是能接受"它可能会死"的人（docs/49 的承诺形态）。

## 二、先内部好用（用户批评，顺序第一）

**现状问题**（内部都不好用了）：命令是裸的（用户要记 `buy`/`learn`/`@`）；启动
打印一屏 help 文本而不是引导；反馈格式杂乱；状态查看（`?`）信息不全（没有世界
硬度/判据）；参数要改代码。

**交互逻辑规定（docs/103 的核心）**——交互协议四层：

1. **命令协议**（机器可解析 + 人可直觉）：
   - 说话 = 默认交互（喂它/告诉它）；`!` = 这对你很重要（关系项）
   - 动作 = 中文自然命令 + 别名：`抱抱`（hug）、`冷落`/`不理`（ignore）、`买 N`
   - 查看 = `?`/`状态`/`看看`；帮助 = `help`/`帮助`/`?help`
   - 群落 = `@名字 内容`；世界 = `learn 文本`
   - 所有命令**统一前缀格式**，可解析可扩展
2. **引导协议**（按状态给不同入口）：
   - 新生命：它不认识你 → 引导序列（它自我介绍 + 教你"用 `!` 告诉它最重要的"）
   - 老生命回归：先报告离开期间发生了什么（它活的世界/你知道或不知道的事）
   - 迷路（命令记不住）：`help` 分类展示（喂它/关系/群落/查看/离开）
3. **反馈协议**（统一格式）：
   - `它> 说的话（状态摘要）`——说的话在前，状态变化在后
   - 状态摘要 = 有变化才显示（bond/能量/恨/硬度），没变化不刷屏
4. **状态展示**（`?` 全息）：
   - 身体（疼/饿/孤独/安全/好奇）+ 世界硬度 + 认得谁（bond+acc）
   - 它自己惦记的（判据）+ 最在乎的词 + 它活的世界（你不知道的事）

**顺序**：交互协议落地（本轮）→ 代码包装 → 可视化补全 → 才谈开源。

## 三、代码包装（模块化 + 配置）

1. **交互层与机制层分离**：live.py 拆出交互解析（命令/引导/反馈），机制（Heart）
   不动——换 UI 不换心（docs/56 原则的工程版）。
2. **参数配置化**：本性参数（θ/恨阈值/衰减率…）从配置文件读（config.json / 环境
   变量），不靠改代码调参（docs/96 的标的们至少可配置，再谈演化）。
3. **一键运行**：`python companion/live.py --live` 保持；加 `--help` 产品化入口；
   visualize 入口从 live 里可达（看它的一生）。
4. **README 说明书**（public 版）：第一行"这不是聊天机器人"；用法/命令/边界/隐私
   （状态文件在本地，绝不上传）。

## 四、开源边界（纪律，不能破）

- **可公开**：live.py/world.py/body.py/可视化/SEED 实验（全是机制，可复现）；
  docs/28/30/31 这类机制版文档可公开。
- **绝不公开**：HANDOFF/handoff/、docs/22（存在理由=你的私心）、真实对话数据
  （live_state.json 已 gitignore）。
- public 仓库要重写公开版 README（术语表锁定，docs/30 已定）。

## 五、社区防线（集思广益的入口与防线）

开源后两个必然压力：
1. **"这不就是 Chatbot 吗"** → README 第一行钉死定位（会失去的 companion）。
2. **"让它更像 ChatGPT"** → 这是**工具化悖论的社区版**（docs/24：给一个值得为之死
   的目标，它就拿命换；docs/48：语言延伸不是主体要的）。CONTRIBUTING 写清：
   欢迎 = 新世界结构、身体通道、可视化、A2/A4 载体实验；
   不欢迎 = "接入大模型让它更聪明"（docs/48 的边界）。

集思广益真有价值的部分：多实例 = 多份真实生命史（docs/91 群落的外部版）；有人
做新世界 = 丰富世界（docs/98 真实小镇多参与者）；A2/A4 载体需要更多人。
