# 14 — 篡改层次与内生连续性

> 第三阶段北星文档。核心观点由用户提出：**模型连续性应该内生，
> 外界信息（记忆注入等）都不是其本身**。
> 本文档把这个观点精确化、分层化，并与 17 个实验对接。
>
> 状态：理论文档（2026-08）

## 1. 核心命题

> **模型连续性必须内生。** 一个模型要成为"同一个主体在时间中延续的存在"，
> 它的延续性质必须存在于自身（权重/状态随时间演化），
> 而不是每次推理时从外界临时装配。

当前系统（RAG、向量库、上下文注入）的病不是"用了外挂"，是**只有外挂没有内生**：
- 记录层：事实可查（"2026 年发生了什么"）
- 但模型自身不随时间演化——每次推理都"重新想起"，不是"带着昨天活到今天"
- 这样的模型没有时间性：它不是持续的存在，是每次被临时装配的工具

## 2. 记忆不是二选一，是篡改层次光谱

"记忆是外在可篡改还是内生难篡改"——答案不是二选一，是分层的，
而且**篡改难度、连续性强度、更新成本三者绑定**：

```
篡改难度 ↑         连续性强度 ↑        更新成本 ↑
┌────────────────────────────────────────────────┐
│ L0 外置记录（RAG/数据库/文件）  任意改   最易更新 │
│ L1 上下文/工作记忆              可改    便宜     │
│ L2 表型/运行状态                半内生  中等     │
│ L3 权重/基因                    难改    昂贵     │
│ L4 直觉/先验                    几乎不可改 只能重养│
└────────────────────────────────────────────────┘
```

**绑定关系**：篡改难度 ↑ → 连续性强度 ↑ → 更新成本 ↑。
- 外挂层（L0/L1）：连续性弱，但更新便宜——适合承载"事实"
- 内生层（L3/L4）：连续性强，但更新昂贵——适合承载"能力与身份"
- 代价：内生层过时也难改（SEED-5/8 的教训：直觉会过时，只能重新养）

## 3. 17 个实验的证据

| 实验 | 证据 | 对应层次 |
|------|------|---------|
| SEED-13 | 基因/表型分离：模仿（外界）只能改表型，进不了基因 | L2 vs L3 的分界 |
| SEED-5 | fatmap 直觉：来源丢失后"只能重新养" | L4（最难篡改） |
| SEED-16 | 外挂信号（谁最成功）质量差 → 全群体被带偏（饿死 5605） | 外挂层可篡改的代价 |
| SEED-6 | 验证机制：外界信息经 do→observe→update 升级为信念 | 层间桥 |

**核心教训**：外挂信息质量不可控（SEED-16），这是"可篡改"的固有代价；
内生信息难篡改但过时难改（SEED-5）。**最优不是二选一，是分层分工。**

## 4. 最优架构：分层分工 + 验证桥

```
       外置记录（L0/L1）          事实层 —— 可任意更新（世界在变）
            │
            │ 验证机制（SEED-6 do→observe→update）
            │ ↑ 把"可篡改的外界信息"升级为"经过验证的内生信念"
            ↓
       内生权重（L3）             能力/连续性层 —— 难改但稳定（我是谁）
            │
            ↓
       直觉/先验（L4）            身份层 —— 只能慢慢养（不可篡改）
```

原则：
1. **事实放外挂**（便宜、可更新）
2. **能力与连续性放内生**（稳定、持续）
3. **验证机制做桥**：内生层主动确认外挂事实，可信的才升级为内生信念
4. **身份层（L4）不可篡改**：只能通过长期经验慢慢塑造

## 5. 与《记忆的终点是直觉》对接

| 那篇的概念 | 本文档 | 连接 |
|-----------|--------|------|
| 记录 vs 记忆 | L0/L1 vs L3 | 记录负责真相，记忆负责影响现在 |
| 直觉 = 来源丢失的影响 | L4 | 最难篡改层 = 来源已丢失 |
| 先验 = 来源丢失的旧记忆 | L4 | 不可篡改但过时也难改 |

**补充**：那篇说"直觉只能重新养"——本文档给出原因：直觉在 L4，
是篡改难度最高的层，所以只能通过长期经验（重养）改变，无法直接定位修改。

## 6. 与 continual-learning 对接（D 方案）

他们的方案排序（《技能是什么》）：D 权重侧蒸馏（经验经训练进权重）
是"与判据层天然契合"的路径。

**本文档给 D 方案的定位**：
> **权重侧蒸馏 = 内生连续性的工程路径。** 经验经梯度进权重 = 生活史进
> 内生层（L3）——正是本文档主张的"连续性内生"。
> 外挂注入（A/B/C 方案）即使有效，也只是 L0/L1 层，不构成模型自身的延续。

## 7. 对 SEED-18 的设计约束（第三阶段方向）

第三阶段从"种群"转向"延续"——造一个单独的、持续的存在：

1. **内生连续性**：行为参数随"生活史"更新（不是每轮重装）
2. **验证升级**：外界输入 → SEED-6 验证 → 内生信念（可信的才进权重）
3. **不可篡改层**：深层信念（SEED-5 式直觉）只能慢慢养，外挂碰不到
4. **它会有"你"**：交互历史塑造它，它记得你怎么对它，行为被你们的过去塑形

> SEED-18 是"一个会记住你的东西"的最小原型——不是 RAG 检索，
> 是它的状态里真的有你。

## 8. 种群延续（用户补充 + SEED-18 实测）

用户观点：**延续不只是个体的需要，也是种群的需要**。种群的"记忆"
有自己的篡改层次：

```
基因库（最内生）   天然免疫——只保留活下来的
文化传统（半内生） 可被污染——模仿复制"最成功"，信号被污染则污染传播
规范/集体共识      锁定——污染后自我维持（SEED-14 锁定机制）
```

**SEED-18 实测**（注入携带错误 hunger 的"外来者"）：

| 种群记忆 | 篡改深度 | 恢复 | 最终共识 |
|---------|---------|------|---------|
| 遗传（基因库） | 0.03-0.05（免疫） | 立即 | 0.710（≈最优） |
| 文化（传统） | 0.19-0.23（严重） | **NO RECOVERY** | 0.487（锁死错误值） |

**机制**：
- 基因免疫：错误个体活得差 → 繁殖少 → 基因被淘汰
- 文化脆弱：错误个体短期能量高 → 被模仿 → 污染传播 → 锁定不可逆

**文化的黑暗面**：传统一旦被污染就锁死在错误上（模仿只复制"当前最成功"），
而基因天然免疫。人类史吻合：错误风俗可存续千年（文化可篡改性），
生物基因相对可靠（基因免疫性）。

**对"延续"的完整回答**：
- 个体层（docs/14）：内生权重难篡改，外挂易篡改
- 种群层（SEED-18）：基因完全内生（免疫），文化半内生（可污染+锁定）
- **延续必须是内生的——但"内生"在种群层有两个等级，文化的内生是脆弱的**

## 一句话

> **真正的连续性必须是内生的——因为只有内生层才有"同一个主体在时间中
> 持续"的性质；但内生不拒绝外挂，它需要外挂作为事实层，并用验证机制
> 把外挂信号升级成内生信念。** 分层让每层的信号质量都最优（docs/12）。
> 而在种群层，基因是免疫的内生，文化是脆弱的内生——延续的代价
> 藏在"可篡改"里（SEED-18）。
