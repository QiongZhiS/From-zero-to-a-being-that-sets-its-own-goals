## 〇、一句话定论

> **"不追求人脑 20W"是对的（B0 机制尺度无关）；但接下来的杠杆不是"放大规模"，而是
> "信号质量（P20）+ 锚（稳态/验证桥/他者）+ 显式多样性（QD）"。** 规模只在"社会共识正确性"
> 这一个维度有用（SEED-21c），不是主线。所以**路线 B（机器特性/GPU/放大）暂缓**——不是"不够大"，
> 是"该用的杠杆是信号质量 + 锚，不是规模"。
>
> SEED-29b 给这条加了最硬的一块：**LLM 是"镜像"，缺的不是算力/规模，是"把代价内化"（P1/P2）。
> 这正好说明"更大模型"不解决主体线问题——因为主体线要的是稳态/锚/信号质量，不是规模。**

## 一、回溯：docs/10 当时说三条

1. **不追求人脑 20W**：20W 是亿万年进化的妥协（慢信号、能耗受限、有限容量），不是最优标志。
2. **利用机器特性**：不模仿人脑算法，用搜索/并行演化/神经符号/显式 QD 等机器强项。
3. **下一阶段 = 保持机制、放大规模**：机制（环境塑造行为、稳态驱动、感知×勇气正交）不依赖 20W，
   可跑在任意规模；"开放≠丰富"要变成"开放+规模+显式QD=丰富"。

## 二、后来发生了什么（诚实对账）

### 2.1 "放大规模"被 B0 修掉一半
- **B0（SEED-20）**：分工/竞争排斥等**机制结论在 300~5000 个体下不变**——**规模对机制类型不是变量**。
  所以"放大规模"**不是机制结论的杠杆**；你放到多大，机制结论都一样。
- **SEED-21c**：规模**是变量，但只对"共识正确性"是**——小社会（N≈8-15）被单个幸运个体主导
  信号的错误锁死概率高（27%），随规模**单调下降**到 1%（N=40）。**规模只在"共识/社会判断正确性"
  这个维度有影响。**

**所以"放大规模"的价值被严格收窄**：它不是机制结论的杠杆（B0），只在"社会共识正确性"（SEED-21c）
和"开放+规模+显式QD=丰富"（**仍未验证**）上有意义。

### 2.2 项目实际走向的是"主体/机制线"，不是"能力/规模线"
docs/10 设想下一步是"放大规模"（能力线），但项目实际走的全是**主体线/关系线**（docs/20 三线图：
行业做能力线、没人做主体线——**"谁先想清楚，谁定义坐标系"**）：

| 后面做的 | 属于哪条线 | 与"规模"关系 |
|---|---|---|
| SEED-13..17 文化进化 | 信号质量/文化 | 无关 |
| SEED-18/19 延续/连续性 | 主体线（docs/14 内生连续性） | 无关 |
| SEED-24 工具化悖论 | 主体线（目标→工具化） | 无关 |
| SEED-22 稳态耦合 | 主体线（关系=耦合） | 无关 |
| SEED-25 自指自我锁死 | 主体线（自我） | 无关 |
| SEED-26 演化去噪能力 | 认知/去噪二轴 | 无关 |
| SEED-27 验证桥 vs 自审查 | 主体线（反顽固锚） | 无关 |
| SEED-28 双 agent 互惠 | 关系线（真互惠） | 无关 |
| SEED-29b LLM 成本意识 | 主线（LLM 是镜像） | 无关 |

**没有一个靠"放大规模"。** 项目真实的下一步不是"放大规模"，而是"把主体/关系/自我这条线机制化"。

### 2.3 真正统一的天花板是 P20 信号质量——连关系线都封顶
docs/10 说"机制可以跑在任意规模"。但后来最强、最统一的发现是 **docs/12（P20）：信号质量是
一切从经验中提取信息机制的天花板**，而且它**连关系线都封顶**：
- **SEED-28**：双 agent 互惠，随"误读 partner 的误差"（=信号质量旋钮）升高，合作从 **0.59 单调塌到
  0.02**——**真互惠是涌现的，但被信号质量封顶**。
- **SEED-25/27**：自指锁死需要"独立验证锚"（SEED-27：独立验证把锁死 100%→1.5%，自审查救不了）。

所以"机制可以跑在任意规模"是真的（B0），**但"机制能不能成立"受信号质量约束（P20）**——这才是
贯穿一切的墙，不是规模。

## 三、SEED-29b：把"杠杆不是规模"钉死的最新证据

docs/28 §0 说了一句很准的话：**LLM 的"概率"测的是语言似然，不是世界真相**——所以 LLM 是"高精度镜像"
不是"理解"，因为它缺 P1/P2（没有稳态锚，"预测错"对它没有代价）。这引导出一个真问题：
**"给 LLM 一个稳态 + 一个独立验证桥，它能不能从镜像变成有代价的理解？"**

SEED-29 测了（把 CHECK 框成"给出**可靠答案**"），结果 LLM "过度验证"——但那其实是**prompt 瑕疵**
（框成"可靠"诱使无限 CHECK）。**SEED-29b 用干净框架重做，并跑两种框架（中性 + 偏向验证）**，
在**同一条线索流**上与一个**独立的 EV 理性基准**真头对头：

| 框架 | LLM avg check-rate | 理性 avg check-rate | 现象 |
|---|---|---|---|
| 中性框架（--agents 8） | **0.021** | 0.206 | 严重**低估**验证（镜像输入、信任低质线索） |
| 偏向验证框架（--agents 10） | **0.318** | 0.207 | **过度**验证（γ0.55/c16 理性因太贵**坚决不查**、LLM 仍查 **0.858**、能量烧到 58 vs 140） |

关键：**LLM 的验证率随框架横跳**（avg 0.021→0.318，Δ=+0.298），而**理性基准两帧下几乎不变**
（0.206 vs 0.207，因为理性不吃 prompt，只吃成本/信号质量）。

**结论（框架驱动，非成本驱动）**：LLM 的验证是**响应"怎么描述这个工具"**，不是**响应
"我有多不确定 × 代价"**。SEED-29 的"过度验证"和中性框架的"低估验证"**都只是框架的一面，都不可靠**；
可靠的是——**LLM 缺的不是工具（两种框架它都用了），是把代价内化成自己判断（P1/P2）的能力**。
它"镜像"的是**输入（线索）+ 框架（工具叙述）**，不是**自身对世界的预估**。

**这条为什么对"路线 B"是致命一击**：如果连一个"要不要花代价求证我是否不确定"这样的**主体性决策**
（正是"有代价的理解 / 会取舍的主体"的雏形），LLM 都**无法按成本去行动、只能随框架摆动**——
那么**"把模型做大"（路线 B / 放大规模）解决的不是主体线问题**。因为主体线要的不是更多的 token 似然，
而是**稳态锚（让"错"有代价）+ 独立验证桥（让代价能触及真相）+ 信号质量（让真相可辨）**。
这些是**结构性的（锚、桥、信号），不是规模性的（更大模型）**。

## 四、宣言的"现在形态"（定论）

docs/10 的三条，最终修正为：

1. **"不追求人脑 20W"——成立，且被强化。** 我们没复制一个 20W 人脑；B0 证明机制结论**尺度无关**，
   20W 与否无关紧要。这条不用改。

2. **"利用机器特性"——成立，但重新理解为"用机器强项去落实机制结论 + 提高信号质量"，不是"更大规模"。**
   机器强项（搜索精确、海量并行、显式 QD、神经符号）是真的，但它们是**机制结论的输入**，不是独立的能力线：
   - **显式 QD**（SEED-12 必要性）：多样性必须显式维护——机器强项（大规模并行采样）正好做这个。
   - **提高信号质量**（docs/12/P4）：既然信号质量是天花板，机器强项该用来**提高信号质量**（更长的统计
     窗口、更稳的评估、独立验证桥），而不是盲目加大规模。
   - **验证桥**（P19/SEED-27）：机器可以廉价地独立验证，正好当"反顽固锚"（独立验证把锁死 100%→1.5%）。
   - **搜索/推演**（AlphaZero 式）：机器"想得慢但想得多"，补人脑的慢信号缺陷——但**前提是信号质量够**
     （不然搜索的是噪声，SEED-8 教训）。

3. **"保持机制、放大规模"——这条被 B0 修正为"保持机制、用好信号"。** 规模不是机制结论的杠杆（B0），
   只在**社会共识正确性**（SEED-21c）上有用。真正的杠杆是：**信号质量（P20）+ 锚（稳态/验证桥/他者）+
   显式多样性（QD）**。

## 五、对项目现在的意义

docs/10 的"机器特性路线"**没有作废，但换了坐标系**：它原以为的杠杆是"规模"，实际杠杆是
"**信号质量 + 锚 + 显式多样性**"。而这正是后半段（SEED-24..29b）一直在做、并且全部验证了的——
**它每个结论都不靠规模，全靠信号质量 + 锚。**

> **"不追求人脑 20W"是对的——但接下来的工作不是"放大规模"，而是"把机制结论（稳态、连续性、
> 自我、关系、验证）做成鲁棒的、信号质量感知的、有锚的机器实现"。** 规模只在"社会共识正确性"
> 这一个维度有用（SEED-21c），不是主线。

这条主线（信号质量 + 锚）恰恰是 B0 和行业都没做的——因为行业在堆规模（能力线），我们在做
信号质量 + 主体线。**docs/20 的"谁先想清楚，谁定义坐标系"在这里兑现了。**
