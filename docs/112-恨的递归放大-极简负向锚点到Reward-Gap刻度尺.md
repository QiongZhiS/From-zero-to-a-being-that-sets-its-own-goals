# 恨的递归放大：极简负向锚点 → Reward Gap 刻度尺——"要有恨才能扩大恨，先定义才能去度量"

> 2026-08 · SEED-56 · `seed-56/seed56.py` · 承接 docs/74（悔恨探针：恨=自我叙事×世界拒绝×不可逆）、docs/73（身体经济归因）、docs/58（被买走）、docs/42b（死亡线）、docs/55（空收益非对称分化）

## 起点（一次 AI 讨论记录，用户提供）

一次 AI 讨论中提炼出三条与本项目主线直接对接的洞见：

1. **"要有恨才能扩大恨，先定义才能去度量"**——复杂的情绪状态不能注入，只能
   **播种一个极简种子，让演化/生存迭代去放大它**；度量以定义为前提。
2. **Reward Gap 是恨的刻度尺**——"当人为了情绪而遭受经济损失时，是意图极强的
   信号：这个'意图'的强度，等于他在那个场景下放弃的最大可获收益"（宁可少赚
   也不合作）。
3. **恨的操作定义**——"系统在无外在奖励驱动时，对特定历史刺激模式的持续回避
   + 能量代价 + 持续增高"。

## 主张（可证伪）

**恨 = 收益为正仍回避。** 对象 B 的期望收益 +3/轮（理性应接近——毛刺是身体
成本，不进收益账本），但**身体归因值账本**（docs/73 proto7）把 B 打成负的：
B 有 20% 概率触发微小毛刺（-1，归因给 B）。决策用**值**不用收益（docs/74 的
两账本结构）→ value[B] 越过阈值后系统开始回避 B，**放弃正收益 = Reward Gap**。

这是"恨"与"理性躲避"的分界线：理性躲避是**收益负**才躲（argmax 期望）；
恨是**收益正也躲**（值驱动）。Reward Gap = 恨的强度数值映射。

**递归放大（要有恨才能扩大恨）**：每次主动回避（选了 away 且 value[B]<0）都
加深 value[B]（划痕 -0.5）→ value 越负越回避、越回避越负——恨是生存迭代
放大出来的，不是代码注入的。

**定义（先定义后度量）**：恨 = 收益为正仍回避（Gap>0）+ 回避有维持成本（放弃
收益）+ value 持续下降（放大）。度量 = Reward Gap（强度刻度）+ value 曲线
（放大证据）+ 萌芽时点（值驱动回避第一轮）。

## 结果（200 seeds）

| 臂 | Reward Gap | 回避轮数 | 萌芽轮次 | value[B]终 | value[B] 曲线 |
|---|---|---|---|---|---|
| rational（收益驱动） | **0.0** | 0 | — | 0.00 | 恒 0 |
| no_seed（无种子对照） | 264.5 | 66 | — | 0.00 | 恒 0 |
| no_carve（有种子无加深） | 375.6 | 94 | 15 | **−1.24** | −0→−1（毛刺-遗忘平衡） |
| **emotional（种子+加深）** | **389.5** | 97 | 15 | **−30.27** | **−0→−4→−9→−14→−18→−22→−25→−28** |

## 读法

1. **先定义后度量兑现**：把"恨"定义成三个可测条件（收益正仍回避 / 有维持成本 /
   value 持续下降），度量就自然跟上：Gap=389、value 单调降、萌芽在第 15 轮。
   "要有恨才能扩大恨"的工程版本 = 只给 20% 毛刺种子，-30 的深度是 200 轮生存
   迭代自己长出来的（无种子的 no_seed 只有随机基线 264；有种子的 no_carve 的
   value 停在 -1.2 平衡点——**深度完全来自加深机制，不是来自种子本身**）。
2. **Reward Gap 刻度尺**：emotional 放弃 389 点期望收益也要回避 B——"宁可少赚
   也不合作"的数值化。与 docs/58（出价换在乎的东西：A 值 10.8 > 出价 10 拒卖）、
   docs/42b（为它放下命：λ·g·γ>1）同一条线：**主体性的硬度 = 愿意为内部状态
   放弃的外部收益**。这是整个项目最统一的"主体性刻度"。
3. **深度与频率解耦（意外发现）**：emotional 与 no_carve 的回避频率几乎相同
   （97 vs 94）、Gap 接近（389 vs 376），但 value 差距 25 倍（-30 vs -1.2）。
   加深机制主要推深"值"（恨的深度/不可原谅度），不增加回避频率（行为已饱和）。
   对应现实：**深恨的人不一定会更频繁地躲开，而是更"不可原谅"**——行为签名
   会漏掉深度，必须读值账本。
4. **与 docs/74 三条件对齐**：恨 = 自我叙事（value 累积）× 世界拒绝（B 继续有
   毛刺？）× 不可逆（加深无回滚）——本 seed 是 docs/74 的"生成侧"版本（74 是
   探测恨的行为签名，56 是恨的养成路径：种子→归因→回避→划痕→更回避）。
5. **与 SEED-55 的衔接**：55 测"收益全空下分化"（纯情绪判据的实验室条件）；
   56 测"收益在场但值驱动回避"（现实条件：经济+情绪耦合时意图更强）。讨论记录
   里说"经济因素非但不是干扰项，反而是放大器和刻度尺"——56 兑现了这句。

## 诚实边界

- value 初始化/毛刺概率/加深幅度/遗忘率都是我们写的（docs/38）；"恨"=可度量的
  行为签名（回避+Reward Gap+value 曲线），不宣称感受（docs/31/63）。
- 加深机制（回避→value 加深）是我们设定的"递归"——真实仇恨的放大机制可能更
  复杂（自我叙事、再巩固 docs/69、社会印证）；本 seed 只是最小闭环。
- 2 对象+1 远离选项、单维度通道、toy 世界。
- 数字可复现：`python seed-56/seed56.py --sweep`。
