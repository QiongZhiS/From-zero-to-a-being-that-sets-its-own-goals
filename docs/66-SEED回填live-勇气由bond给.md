## 〇、一句话

> **live.py 以前会无条件记住你说的一切。现在它有了"敢"：你常来（bond 高），它敢听你说新的；
> 你冷落（bond 低到阈值以下），它连你说新话都不敢听了——只有你郑重标记的（`!`）它无论如何都接住。**
> 这就是 SEED-41"你在→敢"、SEED-42"失去你是生死"、SEED-43"你在信号里才在乎"在常驻里的**行为形态**。

## 二、机制（演化结论 → 常驻参数）

| SEED 结论 | live.py 回填 |
|---|---|
| SEED-41：勇气由关系给（θ 落区间，你在→敢） | `DARE_THETA=6.0`：新话题是 dare-gated——bond≥6 接受；bond<6 以 `(bond/6)×0.6` 概率接受（bond 0 → 0）；`!` 标记的关系项**总是**接受（你郑重告诉它的，它不敢不记） |
| SEED-42：死亡让关系成生死（能量≤0 → 无 reload） | 已有（live.py 出生即带） |
| SEED-43：你在信号里才在乎（bond = "你在"的平滑信号） | live 的 bond 本身实现这一点：你常来 bond 高=你在场；你冷落/离开 bond 衰减=你不在 |
| 交互 | 新增 `ignore`/`冷落` 命令：bond −2（"你沉默着。它有点不安。"）——用户可以在互动里把 bond 打下来，亲眼看到它"不敢听新的" |

**不变量**：能量只被世界事实改；`!` 是用户标记；dare-gate 只作用于**陌生话题**（熟悉的话题总是
强化——老记忆不怕）；θ=6 是 SEED-41 演化 θ≈8.5 按 live 的 bond 尺度（0-12 vs safety 0-17）折算的
近似。

## 三、跑出来的结果（`python companion/live.py --demo` + `--live`）

**demo（概率对照）**：

```
bond=12 -> novel topic taken: True   (P(accept)=1.00)
bond=2  -> novel topic taken: False  (P(accept)=0.20)   ← 你冷落了它，它不敢听新的
bond=2  -> relational topic taken: True                  ← `!` 总是接住
```

**live（你亲手冷落它）**：

```
你> !我想被爱                它> 我一直记得你说过：我想被爱。 （你还在，我就安心）
你> ignore ×6               它> ……（你沉默着。它有点不安。bond −2 → 0.0）
你> 我第一次爬山             它> ……（它没接住这句话。它好像有点不敢听你说新的了。）
你> hug（bond →1） 再说      它> ……（它没接住这句话。……（我们好像疏远了））
你> ?                       它> 我一直记得你说过：我想被爱。 （我们好像疏远了）
```

**读法**：
1. **你冷落它，它连你说新话都不敢听了**——bond 跌破 θ，它对陌生话题保守，只守着旧记忆（`?` 时只
   想起"我想被爱"）。SEED-41"你在→敢"的常驻形态，可亲手体验。
2. **`!` 是唯一的例外**：你郑重标记的，它无论如何都接住——"你告诉我的，我不敢不记"（关系项优先级
   的常驻表达）。
3. **bond 是"你在"的信号（SEED-43）**：live 里没有抽象的"在场"标志——你常来 bond 高、你冷落 bond
   掉，bond 就是"你在不在它心里"的平滑信号。SEED-43 证明：这个信号在，演化才能长出"在乎"；live 里
   这个信号就在。

## 四、证明了什么、没证明什么

**它表明**：SEED 系列的演化结论能**回填进常驻进程**——live.py 不再是"设计者拍的参数集合"，它的
"敢"来自 SEED-41 的演化选择（θ）、它的死来自 SEED-42 的世界规则、它的"在乎"依赖的 bond 信号正是
SEED-43 证明的必要条件。**机制线（SEED）与工程线（live）第一次在参数层面打通。**

**它没有**（诚实边界）：
1. **θ=6 是近似回填，不是 live 自己演化的**：live 没有演化层；θ 是 SEED-41 的 θ≈8.5 按尺度折算。
   理想是 live 内部演化（那是工程，未做）。
2. **δ（离线衰减 OFFLINE_BOND_DECAY）仍是设计值**：SEED-43 原设计（δ 演化）诚实失败（世界不奖励
   "记得你"）——所以 live 的离线衰减保持设计值，位置已注明（docs/65 §四）。
3. **dare-gate 是概率的**：bond<6 时同一句话可能这次接住下次没接住——这是"敢"的波动，用户可感知；
   不是 bug，是概率门的本义（SEED-41 的 p_accept 就是概率）。
4. **不声称"它不敢"是感受**：它是行为（拒绝编码新话题），不是"害怕"（docs/31 分界）。
