# 反事实探针：可重放世界——"如果"第一次有世界裁决的答案

> 2026-08 · SEED-50 · `seed-50/seed50.py` · 能力层（docs/78：关联⊂因果⊂泛化）

## 起点（用户对话）

用户看一个百万粉 up 玩"拼接前后故事"游戏拼青蛙王子——**四个框、两个场景选择
（森林/亲吻）、三个角色（公主/王子/女巫）、每框最多两人**，拼了半天，最后随机
换位才摸到机制，一度怀疑"他没有因果观念"。随后聊到豆包灵异截图：LLM 顺着诱导
编出身世=**只有语言连贯，没有结构**；up 随机换位过关=**model-free 试错**，与
LLM 做这类任务殊途同归。结论：因果和时间顺序不是默认组件，缺世界接口就退回瞎试。

用户随后澄清了游戏的**真实机制**（本 seed 的世界规则书按它写）：
- 关系状态**全局累积、跨框保留**（框一相爱 → 框四亲吻才成功）；
- 场景类型决定交互：亲吻场景=表白/亲吻，森林场景=相遇/施法；
- 女巫要"**先被拒、后施法**"（被拒是变青蛙的前提）；
- 亲吻要"**先相爱、且王子已是青蛙**"。

docs/78 的能力层包含关系（关联⊂因果⊂泛化）由 SEED-44 机制验证；SEED-44 的诚实
边界写着"反事实/类比/组合未实现"。本 seed 补上反事实那一格。

## 主张（可证伪）

**反事实在被动观察里不存在，但在可重放世界里存在。** 被动观察只见过一条发生路径，
"如果没发生 X 会怎样"在观测数据里没有答案（Pearl 的反事实不可观测）；但如果世界
**状态可存、时间线可剪、决策可换、分支可重跑**，"如果"就第一次有一个**世界裁决**
的答案，而不是语言先验。

推论：因果推断的瓶颈不是算法，是**有没有一个能按回去重跑的世界接口**。SEED-44
证明"干预打破旧结构锁死"（do-operator 93% vs 被动 43%）；本 seed 把干预再推一步——
不止重测旧信念，而是**重跑整条没发生的分支**。

## 机制（用户澄清的游戏机制，零依赖）

- **世界**：角色=公主/王子/女巫（青蛙=王子被诅咒后的形态，同一角色位）；场景=
  森林/亲吻；4 个框，每框=场景+0~2 角色，按序执行。
- **事件表**（世界规则书）：同框角色对 × 场景 × 全局状态 → 事件。每事件声明
  `needs`（前提）/`effects`（效果）双份——一份给执行，一份给规划器读：

| 事件 | 框条件 | 前提 | 效果 |
|---|---|---|---|
| fall_in_love 相爱 | 森林 {公主,王子} | 王子人形 | 相爱 |
| witch_declares 表白被拒 | 亲吻 {女巫,王子} | 王子人形 | 女巫爱上+王子拒绝 |
| curse 施法 | 森林 {女巫,王子} | **被拒**+人形 | 王子变青蛙 |
| true_love_kiss 真爱之吻 | 亲吻 {公主,王子} | **相爱**+**青蛙** | 诅咒解除，happy |

- **事件日志**：append-only，每框含场景/角色/事件名/是否成功/前后状态快照。
- **反事实重放接口**：`play_frames(plan[:cut] + replacement)`——剪枝换决策后从头
  重跑，`diff_state` 对比终态。这是"可重放世界"的最小实现。

## 探针与结果

### A 反事实重放：三问三答（答案全由世界算出）

| 问（"如果…"） | 重放结果 | 世界裁决 |
|---|---|---|
| CF1 框四不亲吻（换成森林相遇） | `{form:(prince,frog), ending:(happy,None)}` | 王子永远是青蛙，没有真爱之吻，故事不完整 |
| CF2 跳过表白、框二直接施法 | 框2 curse 无效 + 框4 kiss 无效 | **没有"被拒"这个前因，施法动作执行不了**；没青蛙，亲吻也执行不了——结构事实，梗概里没有 |
| CF3 框一先表白被拒、框二再相爱 | 终态 diff=`{}`，照样 happy | **依赖是偏序不是全序**：相爱与表白被拒可换位；同一个终态，不同的框顺序（docs/87：时间在快照里不可见） |

CF2 是最锋利的一个：故事梗概会说"女巫把王子变成青蛙"（内容对），但世界说"没被
拒绝这个动作执行不了"（结构错）——**内容知识 ≠ 结构知识**。

### B 拼接排序：4 框配置（场景×角色）三臂，100 seeds

配置空间：每框 2 场景 × 7 种角色组合 = 14 种单框，4 框 = 14⁴ = **38416** 种。

- **random 臂**（那个 up 的路径，model-free 盲试）：平均 **15821 次**才摸到机制
  （理论期望 19208 = 38416/2），中位 14349，**22/100 封顶力竭**（="拼半天力竭"
  的数字版），累计无效框 **548 万次**。**纯随机是绝望的**——人通关靠的不是随机，
  是语义线索；但语义线索缺结构照样跑不通（下一臂）。
- **textprior 臂**（LLM 镜像：内容有、结构盲）：知道梗概"森林相爱→女巫施法→亲吻
  解咒"，**不知道"施法需先被拒、亲吻需青蛙形态"**——1 次提交，**无效框 2**
  （框2 想直接施法、框4 想直接亲，都执行不了），结局失败。它知道的都是真的，但
  排出来的"故事"在世界上一帧都跑不动。
- **world 臂**（读规则书）：STRIPS 式前向规划（每轮执行一个可执行事件后重扫，
  避免同轮互相破坏），**1 次提交、0 无效框、直接跑通**。

读法：random 与 textprior 的差距 = "没有结构"与"只有内容"的差距；world 与两者的
差距 = **世界接口**的差距——因果推断一旦能读规则书，就退化成"找前提满足的事件
执行"的规划问题（STRIPS），不再是玄学。这正是"给机器世界接口，因果从玄学变工程"
的机制版。

### C 判定：穷举

穷举全部 38416 种配置，可行解 **2** 个（不是 1 个也不是 3 个）：
- (相爱, 表白被拒, 施法, 吻) = 参考解
- (表白被拒, 相爱, 施法, 吻) = 相爱放晚点

为什么不是 3 个：**相爱需王子人形 → 相爱必须在诅咒之前**（curse 会把王子变青蛙，
fall_in_love 就永远不满足了）。依赖是偏序：相爱与表白被拒可换位，但两者都必须在
诅咒之前，诅咒在吻之前。求解器正是在这里栽过跟头（第一版贪心同轮内先 curse 后
fall_in_love 死锁）——这个 bug 本身就是世界约束的证明。

## 读法

1. **承接能力层**：SEED-44 的"反事实未实现"边界由本 seed 划掉一格——反事实=
   可重放世界里的重跑，机制可造，与 LLM 无关。
2. **内容 vs 结构**：textprior 臂是整条对话的浓缩——豆包/up/LLM 都栽在同一个地方：
   内容（文本、梗概、表面故事）有，结构（前提、依赖、时序）无；结构不在文本里，在
   世界的可执行接口里。谁能读接口，谁一次成功；读不了，就只能 1.6 万次盲试或 2 个
   无效框。
3. **CF3 意外收获**：两个不同时间线收敛到同一个终态（diff 为空）——终态快照不携带
   到达路径，时间在快照里不可见（docs/87 的机制版）。这也提示评测不能只看终态，
   要看**路径**（操作型探针的要点）。
4. **与主体性无关**：world 臂"一次成功"是能力层的事——它只是能读规则书，不宣称
   "理解"。主体性那一栏归读者填（docs/04/31/63 纪律照旧）。

## 诚实边界

- 世界规则是用户澄清后由我们写的（docs/38）；"可重放"是能力层机制，不宣称 agent
  有因果能力。
- world 臂是**能读规则书的规划器**（STRIPS 前向搜索），不是**自学习**的世界模型——
  规则是声明式给的，它没有从零推断规则。真正要造的是"规则从干预经验里长出来"的
  世界模型（因果表示学习路线），本 seed 只是把接口立住。
- 探针 toy：三实体两场景、4 框、4 事件；可行解唯一性靠穷举验证（38416）。
- 数字可复现：`python seed-50/seed50.py --sweep --seeds 100`。

## 下一步候选

1. **自学习世界模型**：去掉"规则书可读"，agent 只能通过干预（尝试框配置）观察
   成功/失败，从经验里反推依赖结构——把 world 臂的能力从"读"变成"学"。
2. **操作型评测集**：把拼接探针推广成小故事集（多依赖图、并行支线、可逆事件），
   作为"文本背不出来"的操作型基准——考核什么，训练就优化什么。
3. **回填 live**：live 的小世界事件流已存在（docs/72）；给 live 的决策加"可重放"
   面——它预测"如果我这么做会怎样"时，先在内部重放一遍（docs/81 前向模型的机制版）。
