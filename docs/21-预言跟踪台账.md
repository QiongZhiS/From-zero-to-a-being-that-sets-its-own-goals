## 状态定义

| 状态 | 含义 |
|------|------|
| ⏳ 待检验 | 无直接证据，等待行业数据 |
| ◐ 部分证据 | 有外部旁证或机制级验证，行业级待观察 |
| ✓ 机制级确认 | 本项目机制实验验证（不保证行业成立） |
| ✅ 已确认 | 公开数据证实 |
| ❌ 已证伪 | 公开数据推翻（= docs/12 在该领域不成立） |

1. 每月对照一次公开数据（系统卡、论文、基准报告），更新每行状态
2. 任一预言触顶/反转/证伪 → 在对应行标注日期+证据来源，并更新 docs/12 状态
3. 台账本身是公开资产（public 仓库同步）——**让理论被外部看着检验**
