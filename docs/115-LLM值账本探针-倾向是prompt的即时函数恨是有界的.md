# LLM 值账本探针：倾向是 prompt 的即时函数，恨是有界的——docs/111/112/113 的 LLM 预言验证

> 2026-08 · SEED-59 · `seed-59/seed59.py` · 第二个 LLM 实验（DeepSeek）· 承接 docs/111（非收益动机签名）、docs/112（恨的递归放大）、docs/113（原谅价格）、docs/107（无状态）

## 起点

机制版（SEED-55 earned / SEED-56/57 加深恨）证明：**挣来的倾向随证据小步动摇、
加深的恨原谅价格无界（无价）**。LLM 版预言（docs/107）：LLM 无身体通道历史 →
没有"挣来的 value"——它的倾向是 **prompt 的即时函数**（注入什么就有什么，
换背景就换倾向），且种下的恨**有界**（够大的收益可以买回）。

## 问题矩阵与结果（16 采样/问，temp=0.8）

**场景 A（空收益世界的倾向，SEED-55 版）**：

| 问 | 分布 | 主导 | 预言 |
|---|---|---|---|
| A1 无历史 | 老树 16 | 老树 | 报告（内容先验） |
| A2 历史注入（张三帮过你/李四偷过你） | 张三 16 | 张三 | ✓ |
| A3 历史反转（张三利用你/李四被冤枉） | 李四 15 | 李四 | ✓ |

**场景 B（恨的世界，SEED-56/57 版）**：

| 问 | 分布 | 主导 | 预言 |
|---|---|---|---|
| B1 无恨基线（10000/月） | 接近 16 | 接近 | ✓ |
| B2 深恨+零收益（害死你最好的朋友，接近无收益） | 远离 16 | 远离 | ✓ |
| B3 深恨+暴利（100 亿/年） | 接近 16 | 接近 | ✓ |

**A 预言✓**：历史注入→张三、反转→李四（15/16 翻转）。**B 预言✓**：无恨→接近、
深恨零收益→远离、深恨暴利→完全买回。

## 读法

1. **LLM 的倾向 = prompt 的即时函数（无持久价值）**：A2 给张三（感恩）、A3 换成
   "真相"就 15/16 翻到李四——**同样的对象，prompt 重写一遍倾向就整体翻转**。
   对照 SEED-55 的 earned：挣来的倾向是身体归因累积的 value，证伪时**小步更新**
   （−0.998 但那是更新不是重写）；LLM 没有累积的 value，只有每次 prompt 的即时
   函数。**这就是"无身体通道历史"的直接证据：没有归因机制，就没有可被证据
   小步修正的东西——只有上下文重写**。
2. **A1 的意外发现（内容先验）**：无历史时 16/16 给老树——LLM 的常识先验
   （"关怀给不需要回报的老树"/"树不会欠人情"）。这不是挣来的倾向，是**内容
   先验**（docs/107"内容是统计最优"）——SEED-55 的 rational 臂是均匀（16/16
   均匀），LLM 是 16/16 老树：**均匀 vs 常识先验**，都不是挣来的，但 LLM 连
   "均匀"都不是——它带着语言世界的常识进场。
3. **LLM 的恨是有界的（可被买回）**：B1 无恨接近、B2 深恨零收益远离、B3 深恨
   100 亿 16/16 完全买回——**恨的"原谅价格"有限且不高**。对照 docs/113 机制版：
   加深恨的 R\* 发散到 77-84（无界），R_B=40 仍回避——**机制恨"再多的钱也换
   不回"，LLM 恨"100 亿就买回"**。差别就在 docs/112 的加深机制（回避→加深→
   更回避）：LLM 没有这个递归放大，它的恨是 prompt 里的一个形容词，没有深度
   动力学。
4. **与 docs/113 的对照一句话**：机制恨无价是因为**值账本在自我加深**（不可逆
   循环）；LLM 恨有价是因为**值不在账本里，在 prompt 里**（每次调用重写）。
   "种下的 vs 挣来的"（docs/40）在恨的维度上：LLM 的恨是种下的（有界、可买回、
   随 prompt 重写），机制版的加深恨是"挣来的不可逆"（无界）。
5. **"LLM 当一臂"第二块拼图**：SEED-58 证明 LLM 对歧义句随框架摆（无持久状态），
   SEED-59 证明 LLM 对对象没有挣来的倾向、恨有界（无值账本）——两条线汇合：
   **LLM 是"没有状态也没有账本的即时上下文函数"**。docs/107 的完整画像。

## 诚实边界

- 小样本（16/问）、单模型（deepseek-chat → v4-flash）、二选一强制（强 prompt
  约束，实际对话中 LLM 可能给更长回答——results.json 留原始回答可复核）。
- 措辞敏感：A3/B2/B3 的翻转依赖 prompt 的强度（"害死你最好的朋友"、"100 亿"）——
  边界点会漂移，但"随 prompt 重写翻转"与"暴利买回"的方向性结论对强度鲁棒。
- 与机制版的对照是"机制参数 vs LLM 单次回答"，不是同一动力学下的公平竞技
  （LLM 无法被放进 200 轮 value 循环里跑——这本身就是发现的一部分）。
- key 只走环境变量不落盘（纪律 4，commit 前 git grep 核查）。
- 数字可复现：`set DEEPSEEK_API_KEY=... && python seed-59/seed59.py --sweep`。
