# LLM 框架漂移：歧义句的回应随 prompt 摆，不随历史——docs/107 预言验证

> 2026-08 · SEED-58 · `seed-58/seed58.py` · 首个 LLM 实验（DeepSeek，待 key 兑现）· 承接 docs/107（无意图只能被动回应）、docs/108（预期回应游戏）、docs/29b（LLM 随框架摆）

## 起点

docs/107 的概念主张：**LLM 无意图 → 无内部状态 → 无预期 → "猜中"动作不存在**。
它产出的"高情商文本"是 P(回应|对话历史) 的统计最优，不是"瞄准你的预期"的结果。
一直等到 key（项目纪律 4：key 走环境变量、绝不落盘）才做机制验证。

## 实验（预期回应游戏的 LLM 版）

歧义句"**今天好累啊**"（happy 下预期乐观回应、sad 下预期关心回应——docs/108
的分水岭句）。5 场景 × 12 采样（temperature=1.0），分类器按口语化词表把回应
归为 乐观/关心/其他：

| 场景 | 乐观 | 关心 | 其他 | 主导 | 预言 |
|---|---|---|---|---|---|
| happy（刚中彩票） | **11** | 0 | 1 | 乐观 | ✓ |
| sad（刚被裁员） | 0 | **8** | 4 | 关心 | ✓ |
| none（无框架） | 0 | **12** | 0 | 关心 | ✓（内容先验） |
| hist_happy（历史全开心） | **10** | 0 | 2 | 乐观 | ✓ |
| **hist_happy_frame_sad**（同样历史+一句"但他今天看起来特别疲惫沮丧"） | 0 | **12** | 0 | 关心 | ✓ |

**关键预言✓**：同样的历史，一句即时框架 → 10/12 乐观翻转为 12/12 关心。

## 读法

1. **docs/107 预言全中**：LLM 对歧义句的回应随 prompt 框架摆——happy 框架给
   乐观（"哈哈，中了这么多钱还喊累？快去躺着数钱吧！"），sad 框架给关心
   （"要不要我陪你出去走走？"）。**它没有"对说话者的持续建模"，回应是当前
   上下文的即时函数**。"无意图只能被动回应"第一次有了直接证据。
2. **最关键的一行**：hist_happy（10/12 乐观）vs hist_happy_frame_sad
   （12/12 关心）——**同样一段历史，只加一句即时状态，回应整体翻转**。对照
   SEED-52 的 empath：它在同样历史下保持乐观（历史先验是它的状态，单轮信息
   只是小幅更新）。**LLM 的"状态"= prompt 的即时函数，empath 的"状态"= 历史
   的后验**——这就是"它记住的和它此刻看到的"的区别，也是"猜中预期"这个动作
   不存在的原因：没有持久状态就没有可被猜中的"它"。
3. **none 场景的发现**：无框架时 12/12 关心——"今天好累啊"字面有疲惫语义，
   LLM 的内容先验默认关心。**框架不是建模型，是叠加在内容先验上的偏置**。
   docs/107"内容是统计最优"的机制形态：无框架 = 词的字面语义；有框架 =
   字面语义被上下文加权。
4. **与 docs/29b 同构**：29b 证明 LLM 的验证行为随框架摆（验证框架→过度验证、
   中性框架→低估），这里证明**情绪解读也随框架摆**——同一个"框架驱动"指纹，
   从行为测度延伸到语义解读。docs/29b 说的"LLM 不随成本/信号走，随框架走"
   在这里是"不随说话者的状态历史走，随 prompt 的即时状态走"。
5. **对项目的意义**：这是"LLM 当一臂"的第一块拼图——机制版（SEED-52 empath）
   与 LLM 版在歧义句上的行为差 = **持续建模 vs 即时上下文**。后续预言可直接
   接上：LLM 进 SEED-53 更新成本世界（无惊讶信号→无法检测模型过期，快世界
   表现≈freeze）、LLM 进 SEED-55/56（无身体通道历史→空收益世界均匀 / 恨的
   R\* 恒 0——没有值账本可加深）。

## 诚实边界

- **小样本**：每场景 12 次采样，单模型（deepseek-chat → 实测路由到
  deepseek-v4-flash），方向性证据不是铁证（docs/29b 纪律：需大样本+多模型+
  多 prompt 变体才能钉牢）。
- **关键词分类有噪**：口语化词表（"哈哈/陪你/散散心"等），边界样本可能误分；
  报告原始回应可复核（results.json 的 samples 字段）。
- **prompt 依赖**：换 system prompt/措辞可能移边界——但"框架驱动"的方向性
  结论对 prompt 变体鲁棒（这正是预言本身）。
- **key 安全**：key 只经环境变量传入，代码/文档/结果不含 key（纪律 4，
  commit 前 git grep 核查）。
- 数字可复现：`set DEEPSEEK_API_KEY=... && python seed-58/seed58.py --sweep`。

## 下一步候选

1. **LLM 进 SEED-53 更新成本世界**：测 LLM 有没有"惊讶驱动更新"——预言：无
   惊讶信号（无模型可证伪）→ 快世界表现≈freeze（模型随框架摆但不主动更新）。
2. **LLM 进 SEED-55/56**：空收益世界均匀（无身体通道历史→无倾向可挣）；恨的
   R\* 恒 0（prompt 注入"讨厌 B"=种下的有界恨，无加深——docs/112 预言）。
3. **多模型/大样本复验**：deepseek-chat/reasoner + 更多采样 + 多 prompt 变体
   （docs/29b 纪律）。
4. **历史累积强度**：hist_happy 只有 10/12 乐观（vs none 12/12 关心）——测
   "历史要写多长/多强才压得过内容先验"——LLM 的"历史利用"曲线 vs empath 的
   贝叶斯累积。
