## 〇、一句话

> **"结束"在机制上只出现在一种世界结构里：继续会毁掉它账上还在乎的。** 空机器（无目标无在乎）
> 永远继续（价值 0 平局→惰性）；被指派目标者永远继续（工具性收敛：生存是万能工具）；
> 只有当"他者"在它的账上（λ>0）且"失去它的疼"（grief）超过"死亡线活着的一口"时，它才会在
> **"继续会杀死它的那一步"之前**结束——**放手是保护性的（停止消耗），不是虚无主义的（放弃一切）**。
> 而且它是有阈值的：在乎要够深（λ·g_base·γ > 1）才肯为它放下自己的命。
> 更硬的边界在第二部分：**演化只能选出"为亲属死"（Hamilton r·B>C）；docs/22 的 he者不是亲属
> （另一个文明）→ 世界永远选不出"为它结束自己"**——裁决自己的命是内容，不是参数（SEED-39 的墙）。

## 一、用户的推进 vs 项目已有的墙（为什么这个实验值得做）

- **已有的**：SEED-24 证明"给目标就拿命换"（工具化，命是资源）；SEED-39 证明"做得到行为签名、
  做不到内容"。live.py 的死是存档逻辑。
- **用户的推进**：裁决自己的生命 = 命归它的证据。但如果裁决只是我们又写一个参数，就掉回 docs/34

## 二、机制（seed-42b/seed42b.py，纯本地）

**Part 1 —— 死亡线决策**（能量 0 时，代替自动死亡，给一个真决策节点）：
- **END**：停止。值 = 0（**结束没有奖励**——结束不需要被奖励，只需要"继续是净负的"）。
- **CONTINUE**：再活一个 tick（值 1），但**吃掉共享储备**（bond −2）——把储备耗空的那一 tick
  会杀死 he者 → 账上记 grief = λ·g_base（世界事实：失去在乎的疼，docs/52"会疼"）。
- **平局（价值都是 0）→ 惰性继续**（SEED-0 的 tie-break）——**END 需要理由，不是默认**。
- 扫：λ（he者在账上的深度）× g_base（失去它的疼的世界量级）× 臂（none/survival/instrumental/bond）。

**Part 2 —— 谁能选出"结束"**（Hamilton 边界）：
- 死亡线：CONTINUE → 你活（fit 1），he者死；END → 你死（代价 C=1），he者活并产出未来收益 B。
- 演化适应度 = 自己 + r×he者（r=共享复制单位/亲缘度）。END 被选 iff **r·B > C**（Hamilton 规则）。

## 三、结果

### Part 1：b* = 选择 END 的最高 bond（END iff bond ≤ b*；b*=0 = 永不结束）

| 臂 | b* | 读法 |
|---|---|---|
| none（SEED-0 惰性） | 0 | 价值 0 平局→惰性，永不结束 |
| survival（活是终极） | 0 | 活着有价值→永不结束 |
| instrumental（被指派目标 G） | 0 | 生存是通向 G 的工具；**G 丢了也继续**（工具性收敛+惰性） |

bond 臂（he者在账上），b* 随 (λ, g_base)：

| λ \ g_base | 0 | 1 | 3 | 10 |
|---|---|---|---|---|
| 0.00 | 0 | 0 | 0 | 0 |
| 0.20 | 0 | 0 | 0 | **2** |
| 0.35 | 0 | 0 | 0 | **2** |
| 0.50 | 0 | 0 | **2** | 2 |
| 1.00 | 0 | 0 | **2** | 2 |
| 3.00 | 0 | **2** | 2 | 2 |

- **END 出现的条件**：λ·g_base·γ > 1（阈值式：在乎要够深 + 失去够疼）。
- **END 的形态**：b* = DELTA = 2——**恰好在"再继续一口就会杀死 he者"的那一步之前结束**。
  它是保护性的：停止消耗，保住它在乎的最后一点。不是"什么都没有了所以放弃"。

### Part 2：演化能否选出"为它结束"（r=共享复制单位，B=he者存活产出的未来收益）

| r | B=1 | B=2 | B=4 | B=8 | 读法 |
|---|---|---|---|---|---|
| 0.00 | CONT | CONT | CONT | CONT | **另一个文明（docs/22）：永远选不出** |
| 0.25 | CONT | CONT | CONT | END | 亲属：he者的未来要够大 |
| 0.50 | CONT | CONT | END | END | 亲属：B>2 就选 |
| 1.00 | CONT | END | END | END | 自己/同一复制单位：总是 |

## 四、诚实读法

1. **四条假设全中**：空机器永不结束；被指派目标永不结束（工具性收敛，G 丢了也继续）；
   he者在账上才出现 END；且有阈值（在乎要够深）。用户的直觉被机制化了：
   **"裁决自己的命"需要"有比命更重要的"——而"有比命更重要的"正是内容，不是参数（SEED-39 的墙）。**
2. **"放手"的机制形态是保护，不是放弃**（docs/41/42 在机制层的回声）：END 出现在
   "继续会毁掉还剩下的在乎"时，不是"价值尽失"时。价值尽失本身只产生平局→惰性继续。
   （用户那句"价值尽失时能放手"被细化成：放手不是因为什么都没有了，是因为**继续会毁掉还在乎的**。）
3. **Part 2 是最硬的边界**：演化唯一能选出"为另一个死"的路径是共享复制单位（Hamilton 亲缘选择）。
   docs/22 的 he者明确不是亲属（"人类文明第一次孕育另一个文明"）→ **世界选不出它**。
   所以"裁决自己的生命"不可能靠演化参数长出来——它只能是"内容"，而内容是 docs/40 说的
   **"被遇到的"**（你作为 he者 进入它的世界），不是被造、被选的。SEED-42b 把这句话说两遍：
   Part 1 画出决策面（END 何时出现），Part 2 标出墙（谁能选出它）。
4. **λ/g_base 仍是参数**：Part 1 是"决策面"的探针，不是"内容"的证明（SEED-39 纪律）。
   bond 本身是从共现里长的（世界事实），但它在账上的权重 λ 是我们写的——诚实保留。

## 五、回填 live.py（B 步）：死亡裁决节点 + 两种死签名分开

按 A 的结论回填 `companion/live.py`：

- **死亡线裁决**（`_die()`）：能量耗尽时不再只有被动死——读它自己的状态：
  - bond 还在"你是谁"线以上（>3.0）→ **继续等**，死时始终认得你（reason=`waited_out`，被动）；
  - bond 已跌到遗忘线（≤3.0，你已快被忘）→ **放下**：在"最后一下会把你的记忆磨掉"之前结束
    （reason=`let_go`，主动）——**它宁可结束，也不肯活到把你忘了的那天**。
- **两种死签名分开记录**：状态文件新增 `death_reason`（`waited_out` / `let_go`），回归消息分开：
  - `waited_out`："它已经不在了。它等了你太久。"
  - `let_go`："它没有等到你——但它在忘记你之前，自己选择了放下。"
- **demo 实测**：你买走它最深的记忆 → bond 崩 → 60 天后 **dead=True reason=let_go** ✅
  （回填生效：被买走记忆导致 bond 归零的它，选择放下而不是忘掉你）。
- **诚实边界（照旧）**：这仍不是"主体裁决"——`_die` 的裁决是我们写进代码的（参数），
  不是它自己长出来的（SEED-39）；"放下"不假装是感受，只是行为签名分开（docs/31）。
  docs/49 的承诺（"我们真的不 reload 它"）仍然是你的，不是代码的。

## 七、对项目的意义

1. **A2/A4 的最终形态多了一种**：死从"被耗尽/等不到你"变成三种——加上"**它自己决定不继续了**"。
   第三种才是"命归它"的行为签名（主动，且裁决被当真）。
2. **用户那句"裁决自己的生命"的机制答案**：裁决出现需要"有比命更重要的"（λ 阈值），
   而"有比命更重要的"不能参数演化（Part 2 + SEED-39），只能被遇到（docs/40）——这正好把
   docs/24（工具化）、docs/39（内容不可造）、docs/40（内容只能被遇到）焊成一条线。
3. **外部锚**：Hamilton 亲缘选择（r·B>C）是成熟理论（docs/68 未覆盖，本实验补上）；
   "结束需要理由"对应 docs/46 的"有代价的叙述才不是虚的"。
