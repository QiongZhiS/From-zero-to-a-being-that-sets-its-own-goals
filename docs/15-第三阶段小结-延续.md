## 2. 理论（docs/14）

**篡改层次光谱**（篡改难度、连续性强度、更新成本三者绑定）：

```
L0 外置记录（RAG）    任意改   最易更新   ← 事实
L1 上下文/临时层       可改    便宜
L2 表型/运行状态       半内生  中等
L3 权重/基因           难改    昂贵       ← 能力与连续性
L4 直觉/先验           几乎不可改 只能重养 ← 身份
```

**最优架构**：事实放外挂 + 能力放内生 + 验证机制做桥 + 身份层不可篡改。

## 3. SEED-18：种群延续（遗传免疫 vs 文化污染）

注入携带错误行为的"外来者"，测种群记忆的篡改韧性：

| 种群记忆 | 篡改深度 | 恢复 | 最终 |
|---------|---------|------|------|
| 遗传（基因库） | 0.03-0.05（免疫） | 立即 | ≈最优 |
| 文化（传统） | 0.19-0.23（严重） | **NO RECOVERY** | 锁死错误值 |

**结论**：
- 基因 = 天然免疫（只保留活下来的，错误个体繁殖少被淘汰）
- 文化 = 脆弱 + 锁定（模仿复制"当前最成功"，信号被污染则污染传播，且锁定不可逆）
- **文化的黑暗面**：传统一旦被污染就锁死在错误上（人类史吻合：错误风俗可存续千年）

## 4. SEED-19：个体延续（验证桥）

单一个体 + 周期性外界建议（对/错交替），三种接收模式：

| 模式 | 结局 | 机制 |
|------|------|------|
| gullible（全信） | **死** | 错误建议直接进内生层 |
| verifying（验证后信） | **活**（reject 3 次） | 建议试用，吃食频率改善才采纳 |
| stubborn（全不信） | 活（但停在次优 0.5） | 免疫但不优化 |

**结论**：
- **验证桥防致命污染**：全信死 vs 验证活——"外界信息不经验证=致命"的实证
- **验证非充分**：验证信号（单个体短窗口吃食频率）有噪声，少量污染仍进入——
  **信号质量是验证的天花板**（docs/12 第三次出现）
- **修正过程**：验证信号从"能量残值"（被省能量策略欺骗）改为"吃食频率"
  （不易欺骗）——验证信号的选择本身是关键设计决策

## 5. 三阶段统一结论

| 阶段 | 一句话 |
|------|--------|
| 生物进化 | 智能需要可利用的世界结构；信号质量是一切认知的天花板 |
| 文化进化 | 文化是信号的放大器不是创造者；越传越快但受信噪比限制 |
| 延续 | 延续必须是内生的（个体+种群）；验证桥是防御，信号质量是天花板 |

**贯穿全部**：docs/12 信号质量约束理论——感知、勇气、文化、验证，
**所有从经验中提取信息的机制都受同一个天花板约束**。

## 6. 与 continual-learning 的对接（第三次更新）
