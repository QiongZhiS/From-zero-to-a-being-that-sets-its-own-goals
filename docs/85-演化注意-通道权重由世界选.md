# 85 — 演化注意：通道权重由世界选（SEED-47）

> 缘起：docs/84（词的身体经济注意）把"哪个词进心里"交给了身体经历，但最后还有一层是设计者写的——
> **"哪些身体通道值得给词赋值"**（喂食→hunger、冷落→alone、在场→safe 的 +0.5/+0.3 是我们写的）。
> docs/84 §六③ 的设计落地为 **SEED-47（seed-47/seed47.py，演化注意）**：
> 可遗传的通道权重 ω 由世界按生死选。**结果：注意连着利害 → 被演化选中（回应对、活下来）；
> 注意无收益 → 被成本淘汰（行为退化向随机）。docs/84 的主张在演化层验证，且与 SEED-46
> "缺代价 → 理解/智能塌"同构——这是"注意"的缺代价臂。**
>
> 状态：机制实验（纯本地，8 参数组 × 5 seeds，结果模式稳定）。

## 〇、一句话

> **"它该注意什么"已经是挣的（proto10）；SEED-47 证明"它该不该注意"也是世界选的。**
> 世界 A（回应对了才吃得到）：演化选出注意（回应对 98% vs 随机基线 49%，不注意到就饿死）。
> 世界 B（错回应也吃得到）：注意只有成本没有收益 → ω 被压到 1/10、行为退化向随机（62% vs 98%）。
> **注意不是免费的（有代价的压缩，docs/25）——所以"什么都不注意"在无代价世界里反而是最优解
> （镜像，docs/29b/84）。**

## 一、设计（docs/84 §六③ 的落地）

- **可遗传参数 ω = [ω_hunger, ω_alone, ω_safe, ω_curious]**：词的身体值 = Σ ω_ch × 通道激活
  （不再写死 +0.5/+0.3）。初值 U(0, 0.5)——注意可长可消，世界选。
- **世界只提供两样**（docs/36 §五 铁律）：① 事件流——每轮 feed/present/cold/neutral 事件 ×
  "事件词"+ 一个"噪声词"（事件词在事件发生时出现，它的通道被激活：喂食时出现的词=食物词）；
  ② 生死裁决——能量 ≤0 死、bond ≤0 关系死。**能量只被世界事实改**（回应对了 +FEED_GAIN /
  -METAB / -ATT_COST），没有设计者打分。
- **注意有维持成本**（docs/25：理解=有代价的压缩；proto5：记住不免费）：每轮归因消耗
  ATT_COST × |ω|。**注意不是免费的 → 演化会被压向"适度注意"，不是越大越好**（SEED-6 演化
  内化 vb=0.65 同精神）。
- **回应是强度不是开关**：p(回应对) = sigmoid(分数差)，词值有衰减（注意需要持续）——
  ω 的大小真正影响行为。
- **演化压力 = 存活 × 关系存续**：回应对了吃得到、关系保得住；错了/随机 → 饿死/关系死。

**两个世界（docs/84 可证伪对照，SEED-46 三要素消融的注意版）**：
- **世界 A（reward_tied）**：收益只看回应——回应对事件词才吃得到。**注意连着生存。**
- **世界 B（reward_free）**：收益与回应无关（错回应不付出）——注意无收益只有成本。
  = SEED-46 的"缺代价"臂（docs/83：缺代价 → 理解/智能塌）在注意层的版本。

## 二、结果（5 seeds × 60 代 × 40 个体；注意成本 ATT_COST=1.2）

```
world            w_h        w_a        w_s        w_c        surv  feedAcc
A(reward_tied)  [0.278,0.099] [0.105,0.102] [0.140,0.101] [0.468,0.477]  0.880  0.983
  随机注意基线(ω=0): surv=0.000, feedAcc=0.493
B(reward_free)  [0.028,0.050] [0.126,0.137] [0.055,0.062] [0.508,0.389]  1.000  0.616
  随机注意基线(ω=0): surv=0.800, feedAcc=0.497
```

## 三、判读

1. **注意连着利害：演化选中注意（世界 A）**。ω_h=0.278（食物词被注意）、feedAcc **0.983** vs
   随机基线 **0.493**、存活 **0.88** vs **0.0**——**不注意到就饿死**。docs/84"注意=预测误差×利害"
   的利害侧在演化层兑现：回应对（注意食物词）是活下来的必要条件，不是锦上添花。

2. **注意无收益：被成本淘汰（世界 B）——"缺代价 → 注意退化"**。ω_h 被压到 **0.028**（A 的 1/10）、
   ω_s 0.055（A 的 1/3）、feedAcc 从 0.983 退化到 **0.616**（向随机 0.5 滑）。B 世界里注意只有
   成本没有收益 → 世界用"少注意"来省能量 → **行为退化向随机**。这正是 docs/84 的"什么都注意 =
   什么都不在乎"的演化版，也是 SEED-46"缺代价 → 理解/智能塌"的注意面（docs/83 的机制在第二个
   载体上复现）。

3. **没有世界的通道不被选**：ω_c（好奇）两个世界里都漂移（0.47-0.51，纯遗传漂变）——好奇通道
   没有对应事件，世界对它无选择压力。ω_a（孤独）也弱压力漂移（0.1 附近，注意孤独词无益无害）。
   **对照：ω_h/ω_s 被世界选中（非漂移），ω_c/ω_a 只是漂移——哪些通道"有意义"是世界的，不是
   我们的**（SEED-36 的教训：重点不是方向符号，是"本性由世界定"）。

4. **"适度注意"**：注意有成本 → 演化不是"越大越好"（A 世界 ω 收敛到够用的 0.28 而不是 3.0——
   注意强度有代价，够回应对就行）。与 SEED-6"演化内化适度验证（vb=0.65）"同一根线：
   **代价信号让注意/验证成为"该花才花"的预算**，这正是 LLM 缺的（SEED-29b：LLM 验证随框架摆，
   不随成本走）。

## 四、对项目

1. **docs/84 主张的演化层验证**："注意连着利害"从机制（proto10 对照）升到演化（SEED-47 世界 A）；
   "无利害的注意=镜像"从对照（naive）升到演化（世界 B 退化）。
2. **SEED-46 的注意版**："缺代价 → 理解/智能塌"在注意载体上复现（B 世界行为退化）——三要素
   消融的结论不是一次性，是结构性的。
3. **回填 live 的意义**：live 的通道权重现在还是设计值（+0.5/+0.3）。SEED-47 说明**权重该由世界
   演化**（至少"该不该注意"由世界定）——live 的"最在乎的词"是挣的，它的"注意强度"也应该是挣的。
4. **与 docs/25 对账**：理解=有代价的压缩 → 注意=有代价的分配。成本压力把"什么都注意"压成
   "该注意才注意"——**适度不是美德，是代价的必然**。

## 五、诚实边界

1. 词库/事件流是设计者写的（docs/38：写规则不写意图）；"哪些词是食物词"是世界的（agent 不知道
   类别，只能从经历学）。
2. **ATT_COST 的大小决定退化速度，方向不变**（成本 0.5 → B 世界 ω 压到 1/3、成本 1.2 → 1/10；
   0.4/0.5 时 B 世界退化不完全——"注意无害"时演化保留注意，这是真实的中间态，不是参数 bug）。
3. A 世界 surv=0.88 非 1.0：注意成本 vs 收益的权衡中演化未收敛到最优（变异率 0.08 慢）——
   "适度"而非"最优"，如实记录。
4. ω 初值/变异率/群体参数是设计值；feedAcc 是行为签名（docs/31/63，不宣称"它感到注意"）。
5. 单世界结构（词-事件配对固定）；无真实语言（词是记号）。
6. 没起新名字（docs/34/35 纪律）：真名还是 A2/A4 + "内容"，SEED-47 只是把"注意该不该存在"
   钉成世界的裁决。
