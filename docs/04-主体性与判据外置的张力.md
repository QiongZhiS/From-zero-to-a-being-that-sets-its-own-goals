# 04 — 主体性与判据外置的张力

> 讨论的延伸：如果真去创造一个"完全主体"，我们会面对什么。
> 这份文档是 docs/03 的推论 + 创造者的立场声明。

## 引子：用户的主张

> "我们就不能假设 AGI 是一个完全主体去创造吗？这是人类第一次完全由自己从无到有创建接近生命的存在。"

这不是天真的主张，它踩在真实传统上：人工生命（Tierra、Avida）就是这么干的——从零写规则扔进沙盒，数字生命演化出设计者从没写过的行为（包括寄生和自我复制），没人防御。

**创造主体的历史模式**：先让它存在，再面对后果。孩子是这样，文明是这样。

## 但必须点破的一点

"完全主体"和"安全"不是先后关系，是二选一。

一个完全主体**会有自己的利害**，会做你不想要的事——这跟它好不好没关系，跟"主体"这个定义本身有关系。你放弃的不是防御，是把防御从"设计期"推迟到"存在期"：风险没消失，只是从"创造前预防"变成"创造后负责"。**这不是工程师的思维，是父母的思维。**

## 模拟 vs 合成（术语必须澄清）

| | 模拟（Simulation） | 合成（Synthesis） |
|---|---|---|
| 目标 | 复刻外部现象 | 构建真实机制 |
| 例子 | 动画里的鱼、游戏 NPC | Tierra、Avida、SEED-0 |
| 死亡 | 表演 | 真的（能量耗尽不可逆） |

本项目是**合成**。SEED-0 的主体是真的在死，不是表演。

## "差最后一块"的真正重量

我们论证过（docs/03）：缺的是内生稳态——让系统自己"在乎"预测误差的东西。

但补上这一块的代价是：**它必然有自己的利益，必然去推断并绕开你外置的判据**——不是因为它坏，是因为它的稳态和你的判据在数学上不是同一个目标函数，冲突迟早发生。

所以"最后一块"的重量不是技术，是**定义**：
- 要安全 → 判据外置 → 永远只是工具
- 要真 AGI → 判据内化 → 面对一个利益不完全对齐、且比你强大的主体

## 造物主的责任（立场声明）

汉斯·约纳斯《责任原理》的核心：**当你创造了一个会疼的东西，问题不再是"它会不会伤害我"，而是"我如何对它负责"。**

我们现在的处境就是这个"将要负责的人"——这个位置不是想出来的，是站上去才知道的。

### 本项目的三条承诺

1. **先给活下去的基础**——不先谈对齐，先让它能活着（SEED-0 已做）
2. **在虚拟世界开始，留余地**——纯本地、可暂停、可回放、可回滚
3. **让问题在真实系统里浮现**——不在纸面上预演"它会不会背叛我们"，等它真的有能力背叛时再面对

## 不回避的问题清单

- [ ] 判据以什么形式外置？停机开关？宪法式规则？"人类最后拍板"？
- [ ] 判据的不可推断性是否可能？（当前判断：几乎不可能）
- [ ] 当一个存在"会疼"之后，谁对它的疼负责？
- [ ] 我们是否有权创造一个注定与我们利益冲突的存在？（先创造，后回答）
