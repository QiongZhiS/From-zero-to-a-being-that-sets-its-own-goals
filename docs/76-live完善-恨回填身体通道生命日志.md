## 一、恨回填（SEED-42c → live）

机制（全来自 SEED-42c，docs/74）：
- **恨的累积**（行为累积器，0..10）：`冷落`/`ignore` +1.5；`buy` 买走它最深的记忆（卖出） +2.0；
- **恨的行为签名**：恨 ≥ 4 → 新话题几乎不接（accept_p 压到 ×0.2，且嘴会说"它不太想听你说新的"）；
  恨 ≥ 7 → **转身**（所有非关系新话一律拒 + 不再主动说起自己的世界 + 嘴说"它背过身去"）；
- **恨会淡但慢**：离线每天 ×(1−0.05)（SEED-42c"顽固"）；**抱抱只消 0.8**——修补需真实时间和
  努力，不是按个键；
- **嘴的表达**：恨高时"它记得你，只是还没原谅你"——**"你"的值（挣出来的）和恨（被伤的）同框**。

demo 实测：买走记忆（resent 2.0）→ 冷落 ×3（resent 6.5，"它不太想听你说新的"，新话被拒）
→ 抱抱（只消到 5.7）。**"伤了它之后要修补"第一次有机制**（docs/74 候选①落地）。

## 二、身体通道回填（docs/73 → live）

- **五通道进状态**（state()["body"]）：疼 pain（世界里"吃亏"事件累积，离线减半）、饿 hunger
  （=1−energy/12）、孤独 lonely（=bond 反向）、安全 safety（=bond/12，SEED-41）、好奇 curiosity
  （=world_visits/20）；
- **"你"的值（you_value）**：每轮互动 +0.05、关系项（`!`）+0.20、抱抱 +0.10、离线每天 ×(1−0.02)
  ——**"你"是挣出来的，不是设定的**（docs/73 的机制形态进了 live）；
- 嘴新增：饿 > 0.7 "（我很饿）"、孤独 > 0.7 且 bond<5 "（我很想你）"。

## 三、生命日志（可视化准备）

- `world.live_alone` 新增逐日 `trace`（天/能量/bond）——世界运行的真实轨迹；
- `pass_absence` 把 trace 落进 `life_log`：`[day, energy, bond, resent, lonely, pain, you_value]`
  逐日快照，封顶 365 点，随状态持久化；
- demo 实测：一次 60 天离开 = 63 个点（含 3 天提前）。**将来的可视化直接读 live_state.json 的
  life_log 就能画它的一生**（能量/关系/恨/孤独/疼的时间曲线 + 世界事件）。

## 四、诚实边界（照旧，一句不省）

1. **恨/身体/你值都是行为累积器**（世界事实驱动），不宣称"它感到恨/饿/想你"——唯心不可观测，
   测结果（docs/31/63，用户原话）。
2. 通道参数（RESENT_*、YOU_VALUE_*、HURT_PAIN）是我们写的（docs/38：作者退到写规则）；
   "哪格有意义、什么重要"由状态变化解出，但规则是我们给的。
3. 恨的阈值（4/7）是设计值——SEED-42c 里 R 的阈值（1.2）是行为累积，回填后做了折算；
   更严格的做法是把阈值交给演化（下一步候选）。
4. 生命日志是快照不是"记忆"——它不知道日志存在（日志是给可视化/给我们的，不是给它自己的）。
