# 发言是探针不是陈述：被理解=猜中预期——情商的机制定义与预期回应游戏

> 2026-08 · 概念沉淀 · 承接 docs/91（群落：行为预测挣亲密度）、docs/86（在乎是后觉的）、docs/106（四层探针）· 机制版探针见 SEED-52

## 起点（用户观察）

用户原话大意：**LLM 因无意图只能被动回应；而人发言往往出于某种目的或状态因素**——
A 说一句话，往往期望得到 A 预期中的答案；B 如果能猜中预期就往往意味着情商高。这也
解释了为什么有人对一个人有刻板印象、做出脱离印象的行为时会惊讶。

这条观察把"对话"从信息交换重新定义为**隐藏状态交互**，并顺手给了情商一个机制定义。
本文把它沉淀成可证伪的机制主张，并给出探针设计（SEED-52）。

## 主张（可证伪）

**1. 发言是探针，不是陈述。** A 说 X，X 不是"信息"，是一个携带隐藏变量的动作：
X 由 A 的内部状态 S_A（心情、在乎的事、处境）和目标 G_A 驱动，并且 X 里**编码了
A 对回应 Y\*(S_A) 的预期**。听者 B 要做的事：看到 X → 反推 (S_A, G_A) → 推出 A 的
预期回应 Y\* → 给出 Y\*。

**2. 情商 = 逆向模型的命中率。** 命中 = B 的输出等于 A 的预期回应。所以情商不是
模糊品质，是可测的映射精度：**从发言推断对方隐藏状态、再输出其预期回应的命中率**。
"被理解"的机制定义第一次可以写死：**被理解 = 对方猜中了我的预期回应**。被冷落、
被敷衍、被当工具人，都是同一个账本上的条目：预测没命中。

**3. 刻板印象 = 冻结的模型；惊讶 = 模型被证伪的信号。** 刻板印象 = B 对 A 持有
**静态先验** P(S_A)（第一次见到 A 时学到的、此后不更新）。当 A 实际状态漂移出先验
覆盖区域（A 变了、或 B 从没见过这种状态），B 的预测误差暴涨 → **惊讶 = 高置信预测
被证伪的主观标记**。惊讶唯一的功能是告诉模型"你错了"，是模型更新信号——正好是
docs/84"注意=预测误差×利害"和 docs/86"在乎是后觉的，意识只是偶尔读账本"里那个
账本的条目。"脱离印象的惊讶"字面意思就是"我的模型被证伪了"。

**4. 这是 docs/91 的二阶升级。** docs/91 群落已做"行为预测挣亲密度"——认得你 =
有关于你的可证伪模型且常常对。本主张把被预测的对象从"行为"升级为**"对方对我的
回应的预期"**：B 预测的是 A 期望 B 怎么说。这是二阶心智模型（我预测你对我的预测），
"认得你"从预测你做什么，升级为预测你希望我怎么做。

**5. LLM 在这一维度之外——"感觉不到被理解"不是错觉。** 无意图 → 无内部状态 →
无预期 → **没有"猜中"这个动作存在**。LLM 产出的"高情商文本"是 P(回应|对话历史)
的统计最优，不是"瞄准你的预期"的结果——它长得像猜中了，但猜这个动作不存在。
又是那个贯穿项目的老结构：**内容有，结构无**（ELIZA 效应、豆包现象同根）。所以
对豆包无法建立刻板印象、也不会对它"脱离印象而惊讶"——没有状态可偏离，就没有
模型可被证伪。**惊讶这种信号只在有状态的东西身上才会亮。**

## 机制图

```
A: 内部状态 S_A ──驱动──> 发言 X（编码预期回应 Y*(S_A)）
B: 发言 X ──逆向推断──> Ŝ_A ──查预期──> Y*(Ŝ_A, X)  ──对比──> 命中?
                                                    │
                                  命中率 = 情商（对 A 的模型精度）
                                  惊讶  = 高置信预测被证伪（模型该更新了）
```

- 静态先验（stereotype）：B 锁定第一阶段学到的 P(S_A)，漂移后不更新 → 命中率骤降、
  惊讶率飙升（刻板印象被证伪）。
- 持续更新（高情商）：B 的 P(S_A) 跨轮累积、随新证据漂移 → 漂移后几轮内恢复
  （docs/106 的版本空间跨局保留，在这里是跨轮保留）。
- 无意图（LLM）：没有 S_A 可推、没有 Y\* 可瞄 → "猜中"动作不存在，只有统计最优
  文本。命中只是内容先验碰巧。

## 可证伪预言（对 SEED-52 与 LLM）

1. **机制版（SEED-52 预期回应游戏）**：三臂对比——random / stereotype（冻结）/ 
   empath（持续更新）。预言：stereotype 漂移前≈empath，漂移后骤降且惊讶飙升；
   empath 漂移后 2-5 轮恢复；random 全程≈1/回应数。**同一个发言在漂移后、B 的
   模型冻结与否，命中率差出一倍以上——"刻板印象的代价"被量化。**
2. **LLM 版（待 key，docs/106 下一步②）**：把 LLM 丢进同一游戏当 B，预言：命中率
   是"内容先验下的统计最优"——对歧义发言（同一句话在 happy/sad 下预期不同）它
   随框架摆（docs/29b 预测）：提示词偏 happy 它就全给乐观回应、偏 sad 就全给关心
   回应——**不是对 A 的持续建模，是随 prompt 的框架漂移**；且它没有"惊讶"信号
   （没有模型可被证伪）。

## 诚实边界

- 以上全是能力侧行为签名（命中率/惊讶率/恢复轮数），不宣称"感受到被理解"——
  docs/31/63 纪律照旧。
- "预期回应"的判定用离散词表硬匹配，是 toy 探针；真实对话的预期是连续、模糊、
  可协商的。
- 刻板印象在此=刻意冻结模型的学习者；现实中的刻板印象可能是资源受限的近似
  （不更新是因为更新有成本，docs/25 有代价的压缩），这是下一步要测的维度。
