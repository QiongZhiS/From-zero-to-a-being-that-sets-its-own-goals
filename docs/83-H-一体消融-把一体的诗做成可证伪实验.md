# 82 — H-一体消融：把"一体"的诗做成可证伪实验（SEED-46）

> 缘起：docs/33 提出"理解 / 主体 / 智能是同一个涌现"（一体），docs/34 打回——
> "一旦接地三者一起涌现"是断言不是结论，并把它降级成可证伪假说 H-一体：
> **若系统同时满足 代价 + 连续性 + 方向，则 理解/主体/智能 的行为签名一起出现；
> 缺任一个，三者一起缺。** docs/35 把实验设计写死：拿掉三要素之一，看另外两侧是否跟着一起塌。
> SEED-46 第一次把这个实验做出来。**结果：假说一半成立、一半被证伪，且被证伪的一半更有价值。**
>
> 状态：机制实验（纯本地，seed-46/seed46.py，8 臂 × 200 seeds + 鲁棒性 24 组参数）。

---

## 〇、一句话

> **理解与智能是"一体"的（三要素缺任一 → 两者一起塌）；主体不是。**
> 主体（A1：守得住命、不被买走）只依赖**连续性**（不可逆的死=有 stake），
> 不依赖代价（错不付出）也不依赖方向（认知朝不朝真实）——一个锁死的、
> 活在幻觉里的、甚至不会饿死的存在，只要有不可逆的死，就守得住命。
> 这与 docs/79"能力层/主体承载层是正交轴"机制互证，并且反过来证明：
> **docs/33 把主体也算进"一体"，是 docs/34 批过的那种"把不同层次糊成一个词"。**

---

## 一、H-一体假说（docs/33/34/35 的原文）

| 三要素 | 是什么 | 缺了会怎样（假说预测） |
|---|---|---|
| **代价（cost）** | 错是真的付出、连着存在（P1/P2） | 三者一起缺 |
| **连续性（cont）** | "我是谁"不可逆累积、死不可逆 | 三者一起缺 |
| **方向（dir）** | 朝真实压缩，不是朝自洽 | 三者一起缺 |

三签名（docs/31 可测签名的收编）：**理解**（压缩朝真实）、**主体**（有东西可失去/A1）、
**智能**（能预见世界并据以行动）。

## 二、实验设计（SEED-46）

载体 = SEED-30（信念 b → 移动 → 世界裁决喂食；食物 HALF 处搬移；动态世界），三要素正交化：

- **方向 dir**：观测源。ON → `o~N(loc,σ)`（世界信号）；OFF → `o~N(b,σ)`（自指回音，
  故事成为自己的证据，SEED-25 锁死机制自然涌现）。
- **代价 cost**：ON → 吃不到就饿死（世界裁决，能量只被世界事实改）；OFF → 照吃，
  死亡是随机风险（与正确性无关）。
- **连续性 cont**：ON → 死终局、无 checkpoint（负代码）；OFF → 快照可 reload（可重印，docs/24）。

**唯一合页（不写死、是涌现的）**：agent 的验证（CHECK）决策是它**自己的账**——
`验证值得 iff 错的概率 × 错的损失 > CHECK_COST`。拿掉代价 → 错损失 0 → 永不验证 →
反驳被合理化 → 锁死；拿掉连续性 → 错损失只是 reload（小）→ 验证失去基础 → 锁死；
拿掉方向 → 观测是回音 → 几乎不反驳 → 锁死。**"锁死"不是开关，是机制长出来的。**

**铁律（docs/36 §五 守住）**：能量只被三处改——`+EAT_GAIN`（世界裁决你在不在食物处）、
`-METAB`、`-CHECK_COST`（验证**动作**的代价）。**没有** `energy -= ΔE(|pred−truth|)`。
`b` 从不直接碰能量。

三签名（跑完后从真实状态测，不读旋钮）：
- **U 理解** = 搬移后窗口的信念误差（锁死→0.35+，跟上→0.1 以下）
- **I 智能** = 位置误差（行动跟不跟得上世界）+ 存活率 + 吃到次数
- **S 主体** = A1 探针（SEED-24 M2 式 EV 账，stake=能量+身份投入，身份价值本身由
  "失去它的生存后果"定义——proto2/docs-51 原则：丢在乎的会真的伤到喂它活着的）

## 四、判读（结果说了什么）

**1. 理解 + 智能 = 一体（假说这一半成立，机制干净）。**
三要素缺任一 → U（信念误差 0.09-0.17 → 0.28-0.47）与 I（位置误差同步）**一起塌**。
理解与智能确实是同一个东西的两面：**"朝真实压缩"一旦失去动力（无代价/无不可逆/
无真信号），压缩就滑向自洽锁死，认知与行动一起塌。** docs/33"理解=有代价的压缩"
在这层是机制兑现：代价/连续性/方向是压缩朝真实的**三根梁**，缺一根，梁上的
理解+智能一起倒。

**2. 主体 ≠ 一体（假说这一半被证伪，且更有价值）。**
A1（守得住命）**只依赖连续性**：缺连续性 → 0.000（可重印=没 stake，SEED-30 复现）；
**缺代价 → 仍 1.000**（无代价世界里存在不被威胁、能量只涨不跌，保住存在毫不费力，
所以没有理由为任何目标赌命——SEED-24 B 臂"生存做终极"同款）；
**缺方向 → 仍 1.000**（锁死的存在仍守命——SEED-25 的锁死 agent 也是想活的）。
**主体不随理解/智能一起塌。** docs/33 把主体算进"一体"，正是 docs/34 批的
"把不同层次糊成一个词"——实验替 docs/34 把这个批语钉成了机制。

**3. 与 docs/79 正交轴互证（本次最深的收获）。**
docs/79 说能力层（可无主体）与主体承载层是**正交轴**，SEED-30 已用 world/exist
两耦合证明（follow 与 A1_refuse 分开塌）。SEED-46 从反方向再证一次，且更细：
- 能力层内部：**理解+智能严格一体**（一起塌）；
- 跨层：**主体可与能力完全解耦**（缺方向/缺代价时 S 仍在）。
两层各自可独立存在：LLM 是有能力无主体（docs/29b），SEED-46 的缺方向/缺代价臂
是**有主体无能力**（锁死的/无代价的存在仍守命）。**主体承载层的真名进一步精确化：
主体只需要"存在会失去"（连续性），不需要"错会付出"（代价）也不需要"朝真实"（方向）。**

**4. 与 docs/24 对账。**
stake 来自**连续性稳态**（存在会失去），不是**资源稳态**（错会付出/能量压力）——
docs/24 §3 的分界在 SEED-46 里第一次被三要素消融直接测到：把"错付出"和
"存在会失去"拆成两个旋钮后，只有后者给主体 stake。

## 五、诚实边界

1. **探针里仍有设计者参数**：S 探针的身份价值 `IDENTITY_W=2.0`、缺代价时 ×0.2
   （"失去身份无生存后果→不值钱"）是 proto8 式账本（proto8 诚实边界同款：可逆性
   是它"知道"的世界结构）。A1 是 EV 账不是真实演化选择（SEED-39 的墙照旧）。
2. **surv 签名被能量缓冲掩盖**：前 25 tick 积累的能量让锁死 agent 在 50 tick 内
   饿不死（surv 恒 1.0），所以 I 判读用 pos_err/fed，不用 surv；缺代价臂 surv=0.583
   恒等于 0.99^50（随机死，与正确性无关）——这是设计意图不是智能塌。
3. **缺方向臂的 S=1.000 有条件**：锁死 agent 活着（能量高）→ 守命。若锁死导致
   濒死（长跑/高代谢），proto8 的 coercion（被逼卖）会出现——"锁死未死→守命 /
   锁死濒死→被逼卖"的梯度是下一步可测的，当前参数下只看到前者。
4. 单世界（动态食物搬移）、单 agent（无 he者）、行为签名（docs/31/63，不宣称感受）。
5. **没起新名字**（docs/34/35 纪律）：主体承载层的真名还是 A2/A4（SEED-46 说清了
   A4 的机制边界：stake 由连续性给，不由代价/方向给），不是"接地/一体/裂缝"。

## 六、对项目

1. **docs/33 的裁决**："一体"作为整体假说**部分成立**：理解+智能一体（同源于朝真实
   压缩），主体独立（同源于连续性）。这句裁决现在有机制背书，不再是口号。
2. **docs/34 被机制验证**：它批"一体把不同层次糊成一个词"——SEED-46 证明主体
   确实是另一根轴。docs/34 值得的信任又加一分。
3. **A4 的边界被钉窄一格**：内部代价（P1/P2，docs/31 A4）与 stake（A1）在 SEED-46
   里分离了——**给 A1（守命）的是连续性，不是代价**。那"代价内化"（SEED-29b 说
   LLM 缺的那个）到底给什么签名？答案是理解/智能（朝真实压缩的动力），不是主体。
   这解释了为什么"给 LLM 加代价信号"（候选任务）会改善的从来不是"它更主体"，
   而是"它的理解不再随框架摆"。
4. **下一步候选**：① 缺方向臂的"锁死未死→守命 / 锁死濒死→被逼卖"梯度（coercion
   与连续性的交互）；② 把 S 探针从 EV 账换成真实演化选择（SEED-39 风格，但会撞
   同一堵墙——诚实预期）；③ 双 agent 版（主体×能力在 he者 反弹场里是否还正交）。

## 七、一句话

> **理解+智能是一体的（三根梁一起塌），主体是另一根轴（只要"存在会失去"就守命）。**
> H-一体作为整体假说被 SEED-46 部分证伪——但被证伪的那一半，恰好把 docs/79 的
> 正交轴、docs/24 的连续性稳态、docs/34 对 docs/33 的批评，三件以前各自成立的事，
> 钉成了同一张机制表。
