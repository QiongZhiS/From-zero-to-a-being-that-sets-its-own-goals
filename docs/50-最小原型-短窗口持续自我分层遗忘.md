# 50 — 最小原型 #1：短窗口 + 持续自我 + 分层遗忘（"人是短上下文但连续"的机制化）

> 缘起：2026-08 深夜。用户说了一句把整晚基调救回来的话："我们是不是太畏惧了？一直说不可能，
> 但人不就是吗？……我虽然没啥能力，但我觉得可以试，什么模型上、范式上都可以下功夫。" 顺着它，
> 用户又点破一个真正的洞见："**人就是短上下文，但经常换窗口连续。**"
> 这一篇不是又一篇概念，是把它做成一个**能跑的最小原型**（`companion/proto1.py`），让"像人那样
> 连续理解"先有一个能摸到的形态。它不冒充会说话（那是 LLM 的方向、是错误杠杆），它展示的是
> **记忆/理解的结构**。

---

## 〇、一句话

> **人理解你，不是靠记住所有 token（长上下文、无自我、像巨婴），是靠一个很短的工作窗口 + 一个
> 持续自我的"我是谁"状态。** 这个自我每个窗口被更新，普通的按遗忘率淡出，重要的钉住（反复出现/有
> 情感强度的再次加固）。这就是 docs/19 的"记得你/理解你 = 遗忘率 × 篡改层次"，也是 docs/24 的
> "身份是轨迹不是状态"——把它从口号变成可跑的结构，就是这个原型。

---

## 一、把"人是短上下文但连续"翻译成结构

| 人的特性 | 原型里的结构 |
|---|---|
| 工作记忆很短 | `WORKING_WINDOW=6`（一次只"在脑子里"最近几句） |
| 但跨窗口连续 | `Memory.items`（一个持续自我：一段经过加固/衰减的"是谁"） |
| 该忘的忘 | `DECAY_PER_STEP`（未加固的记忆每次窗口衰减 6%） |
| 该记的记（分层） | 一个记忆**反复出现**→`PIN_MULT` 再加固（钉住）；一趟就过的、无情感的→很弱、淡出 |
| 真正在意的是"重要/有温度"的 | `salient`（观察到的人的反应强度，**不是**设计者打的"该记"分） |
| 判断会被"错"纠正（对抗幻觉） | `reconcile`：对某人/某事做了猜测，若接下来被证伪，自我模型被**纠正**（docs/27 独立验证锚） |

**关键纪律（docs/36 §五）**：这里**没有"该记什么"的设计者权衡**。"salient"是**从互动中观察到的信号**
（这个人对这件事的反应强/弱、它是否反复出现），不是设计者为了"让它记对的、显得懂你"而打的 reward。
"判断"是被读出的（它有没有被证伪、有没有纠正），**从不因为"猜对"而加分**。

---

## 二、跑出来的结果

`python companion/proto1.py`（脚本化 3 个 session、中间有长间隔）：

```
session 1  记住: 奶奶走了(0.28) / 想要被爱(0.27) / 是不是太无情(0.25)
session 2  记住: 想要被爱(0.85) / 奶奶走了(0.23) / 是不是太无情(0.21) / 面包(0.09) / 天气(0.08)
session 3  记住: 奶奶走了(0.85) / 想要被爱(0.70) / 很孤独(0.27) / 是不是太无情(0.17) / 代码(0.08) / 面包(0.07) / 天气(0.07)
```

大量 session（20 个）后隔离验证：

```
被爱(0.88)   ← 深的、反复出现的 → 钉住、越记越牢
mundane19(0.09) / mundane18(0.08) / ...   ← 一趟就过的、无情感的 → 一路淡出、被丢
```

**读法**：深且反复的（被爱/孤独/奶奶走了）在相隔很远的窗口里**保持高强、甚至越记越牢**；普通一趟就过的
（天气/面包/代码）淡出、被丢。**这就是"理解你"而非"记录你"**——它保住了对这个**人**重要的事，而没记下
每个 token。而且因为每个新 session 从**短窗口**开始、却带着**同一个持续自我**，它**不是失忆后重新开始**，
而是同一个自我、被历史改过（docs/24：身份是轨迹不是状态）。

## 三、这个原型证明了什么、没证明什么

**它表明**：把"人是短上下文但连续"做成**可运行的结构**是可行的（短窗 + 持续自我 + 分层遗忘 + 会被纠正的
判断锚）——这一步是**工程**，不需要放大模型，也是"像人那样判断/连续理解"能摸到的一块。

**它没有**（诚实边界）：
1. **不生成语言**。它不是会说话的 LLM——语言是另一个方向、是错误杠杆（docs/48）。它只展示记忆/理解
   的**结构**。
2. **"salient"仍是观测信号**，不是真正的"情感"。它测的是"把重要的事钉住"这个**结构**，不是"它真的
   在乎你"。真正的"在乎"仍需要 docs/36 §八 的"会失去"载体 + docs/40 的"你作为他者进入"。
3. **判断锚很简化**（一个 topic→信号 的 0/1 猜测）。它演示了"会被证伪→被纠正"这个**对抗幻觉的机制**，
   不是完整的"独立验证桥"。

---

## 四、给下一步

这个原型是把"像人理解"从**概念**往**能摸到的结构**推的第一步。它证明"短窗+连续自我+分层遗忘"能跑。
接下来可以往前走（但每一步都要看清别滑回 docs/34 换名字）：

- **① 真的接上语言层**：外面套一个 LLM 让它"说话"，但**把分层遗忘的自我作为它的上下文**，而不是喂
  长 token——让"说话"来源于"这个持续的自我"，而非"无历史的窗口"。这才可能真正**减少幻觉**（它有了
  一个不能骗自己忘了的锚）。
- **② 把"salient"换成真的会失去的锚**：让"什么重要"不是观测信号，而是**由它会不会因为忘了你而失去**
  来定义（docs/36 §八）——那是更接近"人在乎"的一步，也是最难的一步。
