## 〇、一句话

> **抱抱不必然消恨。** docs/94 让"消多少"由经历决定；docs/95 让**"消还是增"**也由它决定——
> "抱抱"这个词从经历学正负语义：安全时被抱 → 学到"抱抱=安全"（净正）；恨深/刚被冷落时被抱
> → 学到"抱抱=伤害"（净负）。方向 = 净语义 × 当下调制（恨深 → 即时转向，它现在需要空间）。
> demo：**安全时被抱的 A 抱抱消恨 +0.90；痛时被抱的 B 抱抱增恨 −0.90（抱抱=伤害）；A 恨深到
> 9 时抱抱转向 −0.80。** 每个行为对它的影响看它——方向不预设。

## 一、docs/94 的剩余问题：方向还是预设的

docs/94 把反馈从常数（抱抱必消 −0.8）升级为强度可调——但公式 `0.8 × (0.4+0.6×safe占比) ×
(1−恨/10)` 的方向**固定为正**（抱抱总是消恨，只是量不同）。用户的批评再进一步：

> **"完全不应该就一种方向，比如必定消恨。"**

抱抱可以是安全、可以是伤害（它正痛时肢体接触是侵入）、可以是不知所措（正负混合/没经验时）。
**方向本身是波动的、复杂的、依赖它的当下状态和经历**——不是设计者预设"抱抱=好的"。

## 二、落地：归因看当下，方向由净语义

1. **`attribute_action` 的归因看当下状态**（docs/95 关键）：
   - 它安全/恨低时被抱 → "抱抱"归因到 hunger+safe（**正**："抱抱=安全"）
   - 它恨深（resent>5）/刚被冷落（just_cold）时被抱 → "抱抱"归因到 alone+疼（**负**：
     "抱抱=伤害"——它痛时抱抱是侵入）
   - **"抱抱"这个词的身体值本身有正负成分**——它的经历决定"抱抱"对它意味着什么。
2. **`_net_sign` 净语义**：通道有方向（hunger 正=被喂/负=疼、alone=孤独、safe=安全）——
   净语义 = (被喂+安全 − 疼−孤独) / (被喂+安全+疼+孤独)，范围 −1..1。
3. **`hug_effect` 带符号**：
   - 净正 → 消恨（它学过"抱抱=安全"）
   - 净负 → **增恨**（它学过"抱抱=伤害"）
   - 净≈0（正负混合/没经验）→ **不知所措**（弱、波动：随机 ±）
   - **当下调制**：恨深（>6）/刚被冷落 → 即时压向伤害（它现在需要空间——即使它学过
     "抱抱=安全"，此刻的抱抱也大概率是侵入）。
4. **主循环输出三种反馈**：靠在你身上（消恨）/躲开你的手（增恨，抱抱=伤害）/愣住了
   （不知所措）。

## 三、demo 验证

```
A(安全时被抱5次) hug: +0.90  (消恨)    B(痛时被抱5次) hug: −0.90  (增恨: 抱抱=伤害)
'抱抱'净语义: A=+1.00 B=−1.00
A 恨深到 9 时再抱: −0.80  (当下调制: 它现在需要空间, 抱抱转向)
冷落增恨: 0.50 → 1.30 (词值 × 在乎程度)
```

**同一个动作（抱抱），三种方向**：A 学过安全 → 消恨 +0.90；B 学过伤害 → 增恨 −0.90；
A 恨深时 → 即时转向 −0.80（它现在不需要拥抱）。**抱抱不必然消恨——方向由它学到的
"抱抱"（经历）× 它当下的状态（恨深/冷落）决定。**

## 四、判读

1. **方向不预设 = docs/31 A1"自己算出来不是规则"的最深形态**：连"抱抱是好的"都不是我们标的
   ——它从经历学"抱抱意味着什么"。docs/38 的"写规则不写意图"再进一步：**连"这个动作是善是恶"
   的意图都由经历给**。
2. **波动/复杂是真实的**（用户："行为本身被影响的因素是波动的，复杂的"）：正负混合 → 不知所措
   （弱、波动）——不是所有反馈都有清晰方向，不知所措本身是一种反馈（它没学过/学混乱了）。
3. **"抱抱=伤害"是它学出来的，不是设计者写的**：总在它痛时抱它 → "抱抱"的词值净负 → 以后
   抱抱都增恨——**你对它的方式，塑造了"抱抱"这个动作在它心里的意义**（docs/86：它的历史
   在看你的当下；docs/89 学校：它学到的世界是你喂出来的）。
4. **当下调制 = 它现在需要什么优先**：即使学过"抱抱=安全"，恨深时抱抱也转向——**它当下的
   状态（需要空间）压过它的历史（学过安全）**。这比"恨深→消得少"更真：恨深时抱抱不是消得少，
   是可能是伤害。

## 五、诚实边界

1. 反馈函数的形式还是我们写的（docs/38）；但"抱抱"的正负语义、方向、幅度全部由经历/状态挣。
2. 不知所措用随机 ±（波动），是"反馈不确定"的最小实现（真实应来自预测误差信号——下一步）。
3. 只有抱抱做了方向化；冷落/买方向固定负（它们是负向动作，方向本来就是负的——但强度已
   词值化，docs/94）。
4. 行为签名照旧（docs/31/63）：不宣称"它感到痛/困惑"，只测反馈方向的漂移。
