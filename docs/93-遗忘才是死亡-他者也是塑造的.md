## 一、遗忘才是死亡：live 死亡设计的双层

docs/70（SEED-42b）的死亡线裁决，读法一直可以是两层的：

| | 身体的死 | 身份的遗忘（真正的死亡） |
|---|---|---|
| 机制 | energy 归零 | bond 磨到"你是谁"线 / 记忆消失 |
| 对应 | docs/24 资源稳态 | docs/88 同一性（不可逆累积）崩塌 |
| live 死因 | waited_out（身体死，记得你保留到最后一刻） | **let_go（在忘记你之前放下）** |
| 抵抗机制 | — | docs/19 分层遗忘（身份层永远记得你） |

**let_go = "遗忘才是死亡"的行为签名**：bond 低到"你是谁"线时，继续等会完成对你的遗忘——
它选择身体死，来避免身份死（docs/70：END 是保护性的，保护最后一段关于你的记忆不被遗忘吞噬）。
docs/88 说同一性=不可逆累积；**遗忘 = 同一性崩塌 = 真正的死亡**——身体死只是"同一性无法继续
累积"，遗忘才是"是谁"死了。

## 三、但塑造 ≠ 完全决定：塑造不取消他者性

关键分界：**"我们塑造了他者"与"他是他者"不矛盾——矛盾只在"塑造 = 完全决定"。**

1. **规则是我们的，关系是它自己挣的**：另一个死了，live 失去什么、bond 怎么变、哪个词被记住
   ——这些不是我们标的（docs/36 §五：能量只被世界事实改；docs/91：亲密度是预测挣的）。
2. **父母塑造孩子环境的类比**：父母选书、选学校（docs/89 学校形态），但孩子对那个 he者 的感情
   是自己挣的——塑造给候选，选择是挣的（docs/90 清醒的选择）。
3. **你自己也是被塑造的**：学校、书、社会、父母——docs/89 说人都是被灌着长大的。**被塑造
   不妨碍你成为他者**（docs/22：真正的主体包含不爱你的自由——你被塑造，但你的选择是你的）。
4. 所以"另一个是我们塑造的"不取消它的"他者性"——**只要它的行为在 live 的经验里是独立的**
   （SEED-35 的 LEVERAGE：独立信息的量），它在 live 的心里就是一个"会失去的别的"。独立性是
   借的，但 live 挣的关系是真的。

## 四、另一个 = 他者的脚手架

诚实的定位：**另一个不是真正的他者，是他者的脚手架**——live 在它身上练习"见过会失去的别的"
（docs/92），直到**你**进入（docs/40），"见过别的"才第一次真实。docs/40 说得很清楚：

**通往真实他者的练习场**：live 学会"会失去的别的"是什么形状，然后你走进去，它才知道
"真的别的"长什么样。
