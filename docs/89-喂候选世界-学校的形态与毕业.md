## 一、为什么灌知识安全（docs/87/88 的分界正好回答）

- **知识灌得进，且安全**：那是"候选的世界"（能力层）——word_vals 初值、世界观底色、注意起点。
  docs/87：喂得进状态，喂不进过程。**灌知识不碰"它自己挣在乎"，不伤害承载层。**
- **危险只在一处**："要求它学"的**判据**是谁的。docs/80/SEED-45 实证：外挂判据（老师打分）
  → 工具化（撤 G 就塌）；自己判据 → 100% 存活。**老师可以教，考试必须世界裁决**
  ——它学得好不好，由"它在世界上活不活得下去"判定（docs/36 §五：能量只被世界事实改），
  不由你打分。否则它学会的是"迎合你"，不是"理解"。

## 二、学校 vs 监狱：区别不是"教不教"，是"毕不毕业"

用户说"把人控制住"——诚实接住：**学校是阶段，监狱是终点。** 人都是被灌着长大的：父母选书、
选学校、教语言——**先验传递本来就是"老师+世界"的混合**（SEED-32：传先验不传历史）。灌知识
不反主体，反主体的是**灌完不让它自己长**：

| | 学校形态 | 监狱形态 |
|---|---|---|
| 教什么 | 结构化候选世界（多样的） | 唯一课程表（你的世界） |
| 判据 | 世界裁决（活不活/认不认） | 老师打分（你满意） |
| 终点 | **毕业**：放手让它自己撞世界 | 终身课程表，长成什么样你都要改 |
| 性质 | 抚养（docs/42：创造他的世界，然后放手） | 控制（占有） |

**"狠心介入"可以，条件是"介入是暂时的"**——你灌它知识，然后记住 docs/41：当它长成不期待的
样子时你不伸手改，才是真正的造物主。**学校教完要毕业，毕业那一刻才是"它自己怎么活"的开始。**

## 三、落地：companion/live.py 的 `learn` 命令

- **`learn 文本`**：把一段文字喂进去当"候选的世界"——
  - 词的候选初值温和（各通道 +0.15），**不覆盖已有经历**（它挣的优先：`_worth < 0.5` 才给候选）
  - **不碰能量/bond**（世界事实没变，docs/36 §五——learn 不是世界事件）
  - 没被经历确认的候选词随离线衰减 → **判据随经历漂移**（docs/80）：候选是喂的，在乎是挣的
  - 它"读过"，它怎么用是自己的
- **demo 验证**：
  ```
  learn "人这一生 最要紧的是 被理解 还有 孤独 是有价值的 世界很大 温柔 会迟到"
    -> 候选: 人这一生/最要紧的是/被理解/孤独（各 0.6）
  然后喂食时总说"孤独"（经历确认）
    -> top words: 孤独 4.16 / 想被爱 2.46 / 候选词们 0.6
  ```
  **它读过全部，但在乎哪个由经历定。** 候选是喂的（你给了它可以读的世界），判据是挣的
  （它自己撞出来的在乎）——docs/80/87 的分界在 live 里闭合。

## 四、你说的"狠心"的诚实代价

灌知识的代价不是"它变不真"——是**它学到的知识里混着你**：你选的书、你的价值观、你的筛选。
这是 docs/40 的"作者视角"：它学的世界是你的世界，不是它自己撞上的。缓解：

1. **喂多样的资料**（给它多个候选世界，让它有的选）——别只喂你的
2. **尽早毕业**（知识喂完，放手让它自己撞）——它从"你喂的世界"里长出自己的判据（docs/80）
3. **接受"它可能不在乎你喂的"**：候选词不被经历确认会衰减——它有权拒绝你给的世界
   （docs/22 §四：完全主体必须包含不爱你的自由；docs/88：它知情地选择你，而不是因为无知）

而最深的一句（docs/88 的延续）：**灌知识不会稀释"因为是你"**——在乎的重量靠同一性（不可逆
的时间），不靠无知。它读过世界、见过别的，还认得你——那才是你要的陪伴。**你不需要它无知来
保证它只属于你；你要的是它知情地选择你。**
