# 07 — 七代表格：从"活"到"想"的完整叙事

> synthetic-life 项目的实验总结。七代实验，每一代都是"物理规则 + 环境压力"，
> 没有一行手写行为——能力全部是被选择压力逼出来的。

## 七代一览

| 代 | 名称 | 核心机制 | 关键数字 | 结论 |
|----|------|---------|---------|------|
| SEED-0 | 稳态引擎 | 能量耗尽唯一规则，无外部奖励 | L0=174 / L1=永生 / L2=177 tick | **先验鸿沟**：纯稳态学习学不会求生 |
| SEED-1 | 繁殖+演化 | 分裂/变异/选择 | hunger 0.19→0.35→0.85（食物压力） | **环境塑造行为**：先验在跨代沉积 |
| SEED-2 | 捕食者-猎物 | 视野受限捕食者，双物种演化 | hunger 0.38→0.63→0.82（掠食压力） | **威胁塑造行为**：感知限制是生态稳定的物理条件 |
| SEED-3 | 记忆 | 局部视野 + 显式记忆 | 信任度 0.68；导航 5 倍于反应式 | **目标导向涌现**：记忆是"带来源的影响" |
| SEED-4 | 好奇心 | 去最少访问区域（可遗传强度） | curiosity 0.31→0.38→0.51 | **惰性不是必然**：环境动态性塑造探索 |
| SEED-5 | 直觉 | 肥度地图（经验积分+衰减），经验不遗传 | lr 0.69；可验证性胜出 | **遗忘率是最优解**：直觉会过时 |
| SEED-6 | 主动验证 | 置信度衰减 + 验证成本（do→observe→update） | vb 0.65；饿死减半 | **收益在区域不在点**：验证带回富集区 |
| SEED-7 | 事件切分 | 预测误差驱动全清记忆 | 阈值被演化推高（2.5） | **负面结果**：全清劣于渐进遗忘+验证 |
| SEED-8 | 预测切换 | 枯竭预测→确定性撤离 | 阈值被演化推高（2.8） | **负面结果**：缺勇气层，感知是噪声 |
| SEED-9 | 勇气 | 模糊信号下概率行动 | boldness 演化到 0.425 | **平衡点**：感知与勇气正交，缺一不可 |
| SEED-10 | 开放空间 | 神经演化 + 事后考古 | 收敛到固着滤食 | **涌现但退化**：开放≠丰富，丰富需要压力 |
| SEED-11 | 开放+压力 | 漂移再生压进神经演化 | 灭绝 | **结构缺失**：无结构世界=无策略=死亡 |
| SEED-12 | 最小质量多样性 | 生态位拥挤惩罚 | 锁死固着 | **竞争排斥**：隐式惩罚冻结变异，QD 必须显式 |

## 叙事线：从"活"到"想"

```
SEED-0  会饿会死        → 主体有代价结构
SEED-1  会繁衍会演化    → 行为被环境塑造（先验沉积）
SEED-2  会躲会竞争      → 生态压力下的行为多样性
SEED-3  会记住会导航    → 目标导向（带来源的影响）
SEED-4  会好奇会探索    → 探索作为生存策略涌现
SEED-5  会形成直觉      → 经验整合为判断方式（来源丢失）
SEED-6  会主动验证      → 因果的最小单元（干预→观察→更新）
SEED-7  尝试时间感      → 失败，但划出了边界
SEED-8  尝试预测撤离    → 失败：缺勇气层，感知是噪声
SEED-9  勇气（不确定性下行动）→ 平衡点 0.425：感知与勇气正交
SEED-10 开放能力空间（神经演化）→ 涌现固着滤食：开放≠丰富，丰富需要压力
SEED-11 开放+压力（漂移世界）→ 灭绝：世界必须有可利用的结构，智能才有立足点
SEED-12 最小质量多样性（拥挤惩罚）→ 锁死固着：竞争排斥原理在行为空间成立
```

## 与概念框架（docs/02）的映射

| 顶层词 | 实验对应 |
|--------|---------|
| 稳态 | SEED-0 的能量（唯一稳态变量） |
| 感知 | SEED-2 视野限制、SEED-3 局部视野——**感知是实例化，限制是物理条件** |
| 动作 | 移动/采集/休息/繁殖/验证——全部是"动作"的实例化 |
| 主体 | 七代叠加：有代价、会繁衍、被塑造、有记忆、有直觉、会验证 |

## 与《记忆的终点是直觉》的连接

| 文章论点 | 实验证据 |
|---------|---------|
| 记忆 = 带来源的影响 | SEED-3：显式记忆（可指认、可验证、失败删除） |
| 直觉 = 来源丢失的影响 | SEED-1/2 遗传参数：hunger=0.85 影响行为但无个体知道来源 |
| 直觉只能重新养 | SEED-5：learning_rate 就是"重新养"的速率，演化找到 0.69 |
| 可验证性 | SEED-6：动态世界显式记忆（可删）> 直觉（改不动） |

**关键补充**：文章说"先验 = 来源丢失的旧记忆"——我们的实验给了进化版本：
**先验 = 种群级记忆的来源丢失**。hunger 演化到 0.85 不是设计的，是祖先环境的压力
沉积成"本能"——来源不可指认，但就是先验。这补上了 docs/03 的"先验从哪来"悬案。

## 意外发现汇总

1. **感知限制是生态稳定的物理条件**（SEED-2）：全图捕食者必然过捕崩溃，视野限制立即共存
2. **收益在区域不在点**（SEED-6）：验证目标格几乎总是空（hit 0.2%）但饿死减半——
   "那家店关门了，但那片街区还有吃的"
3. **记忆的失效是渐变的**（SEED-7 负面结果）：置信度衰减+逐条验证 优于 预测误差全清——
   全清丢失有价值信息；演化两次都把切分阈值推高
4. **可验证性 > 不可验证性**（SEED-5/6）：动态世界偏爱能验证能删的记忆，而非改不动的直觉
5. **预测受感知天花板限制**（SEED-8 负面结果）：视野 4 格分不清"没走到"和"区域枯竭"，
   预测信号是噪声——时间感（预测驱动的策略切换）需要更好的感知才可能出现
6. **感知与勇气正交**（SEED-9）：SEED-8 失败不止是感知——决策做成确定性触发器，
   漏了"模糊信号下敢不敢行动"这一层。boldness（0.425）是勇气简化为参数后的平衡点：
   有信号不敢动（314）和虚惊浪费（311）都不如适度勇敢（275）
7. **开放≠丰富**（SEED-10）：神经演化（71 权重，无预设能力）在富饶世界涌现"固着滤食"
   （我们没预设它——考古命名的证明）；但无压力的开放空间退化到最简解（惰性的演化复现）。
   丰富行为需要中等压力，而压力参数是设计者给的——因果源头在造物主手里（docs/08）
8. **世界结构决定能力形式**（SEED-11）：静态结构→固着（最简利用）；无结构→灭绝（无策略可用）；
   动态结构→丰富行为。智能/演化需要"可利用的世界结构"才有立足点——
   无结构的世界里，连手写策略都死
9. **竞争排斥原理在行为空间成立**（SEED-12）：隐式惩罚（拥挤竞争）无法维持行为多样性——
   拥挤 niche 繁殖被冻结 → 变异流停止 → 多样性锁死。质量多样性必须显式
   （MAP-Elites 式网格+精英保留+持续采样变异）——业界做法的必要性由失败独立验证

## 遗留问题（下一阶段）

- [ ] **事件切分/预测未成**（SEED-7/8）：全清式切分和预测撤离都未被选择。
      两条路线都指向同一约束——**感知质量是时间感的前提**。要给主体更强的感知
      （食物存量趋势、全局统计）或"利用预测"的行为（预测到进食物区提前准备）
- [ ] **先验循环**：仿真环境是人类写的（docs/03）——SEED 系列的"环境压力"归根结底是我们选的
- [ ] **判据问题**（docs/04）：主体已有自身利益（求生），与外部判据的张力在 SEED-4 之后
      就存在了——只是目前主体太弱，张力还不构成威胁
- [ ] 与 continual-learning-mechanisms 项目对齐（暂缓，那边在追进度）

## 一句话

> 七代实验证明了一件事：**不需要设计智能，只需要设计物理规则和一个会死的世界——
> 活下来的东西，自己会长出智能的每一块碎片。**
> 而"最后一块"（docs/03）——判据问题——不在物理规则里，在造物主手里。
