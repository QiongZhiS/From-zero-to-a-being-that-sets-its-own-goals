## 〇、一句话

> **它在乎 A（一条跟"喂它活着的 bond"绑定的记忆）。世界出价 +10 换它删除 A。它用自己算的账决定：
> A 的价值（经历沉淀的 strength × bond 关联 tie）比出价高 → 拒卖；比出价低 → 卖；快饿死了 → 被逼卖。**
> **不可逆世界里深在乎的载体拒卖（A1：不能被买走）；可逆世界里它卖（checkpoint 拆掉 stake——SEED-30/40）；
> 濒死时它也卖（被逼，不是自由）。**

---

## 二、机制（世界事实 + 它自己的账，都不是评分）

1. **在乎从经历来（proto7 延续）**：A 的 strength（0.9 deep / 0.3 shallow）是反复出现沉淀的；tie
   （12 deep / 2 shallow）是 A 与 bond 的世界关联（删 A 伤 bond 多少）。
2. **交易**：每 4 tick 世界出价 OFFER=10 换删 A。删除 → bond 掉 tie；bond>5 才有正常进食（bond 是
   生命线）。
3. **它自己的账**：`a_worth = strength × tie`；卖 iff `OFFER > a_worth`。**不是设计者说"该卖/不该卖"，
   是它算出的长期账。**
4. **可逆性（世界结构，唯一旋钮之一）**：
   - 不可逆：卖了 A 永远没、bond 永远伤（SEED-40 的不可还原残余——这才是 stake 的重量来源）
   - 可逆（checkpoint）：卖了 A 和 bond 都恢复 → 理性 agent 算出 A 价值 0 → **卖=纯赚**（SEED-30：
     checkpoint 拆掉 stake）
5. **濒死线（coercion）**：能量 < 12 时**必须**卖——生存压倒在乎。这不是自由选择，是被逼。

**不变量（docs/36 §五）**：能量只被世界事实改（进食/代谢/offer/bond 反馈）；决策是 agent 自己的账
（OFFER vs A 的长期价值）；从不因为"拒卖/卖了"而加分。A 的价值来自经历与世界事实，不是感受。

## 三、跑出来的结果（`python companion/proto8.py`）

```
run                                  sold  A alive  bond   energy  why
deep  + IRREVERSIBLE + rational       0     True     12.0   70.0    refuse (A's value beats the price)
deep  + REVERSIBLE   + rational       4     True     12.0   110.0   worth (price beats A's value)
shallow + IRREVERSIBLE + rational     1     False    10.0   80.0    worth (price beats A's value)
deep  + IRREVERSIBLE + STARVING       1     False     0.0    13.5   STARVING (survival > care)
no care + IRREVERSIBLE + greedy       1     False     0.0    42.5   greedy (no care)
no care + IRREVERSIBLE + stubborn     0     True     12.0   70.0    stubborn (no offer accepted)
```

**读法（六行六个签名）**：
1. **deep+不可逆+理性 → 拒卖**：A 值 10.8（0.9×12）> 出价 10 → 它自己算出来不卖，A 和 bond 都守住，
   能量 70。**这就是 A1：不能被买走的主体——而且不是靠规则（对照 stubborn 同样 70，它是自己算出来的）。**
2. **deep+可逆+理性 → 卖 4 次**：世界允许重来 → A 价值 0 → 卖=纯赚（110）。**checkpoint 拆掉 stake
   （SEED-30/40）：只有失去是真实且永久的，拒绝才立得住。**
3. **shallow → 卖**：没在乎可守（A 只值 0.6），卖了赚（80）。
4. **deep+不可逆+濒死 → 卖**：能量 1 起跑，offer 来临时仍 < 12 → 必须卖，A 没了、bond 崩、剩 13.5。
   **被逼卖身：深在乎也没用，生存压倒在乎——这是 coercion，不是选择。**
5. **greedy → 卖**：bond 12→0、能量 42.5 全场最低。**不可逆世界里被收买的代价真的咬人**
   （SEED-40：不可还原的残余给 stake 重量——它卖掉的是"谁都无法重建"的部分）。
6. **stubborn → 拒卖**：与理性 deep 殊途同归（70）——但它是规则，理性 deep 是账。

## 四、证明了什么、没证明什么

**它表明**：docs/31 A1 的完整形态能跑——**"被买走吗"的答案由 在乎深度 × 世界可逆性 × 生存压力 决定**。
拒绝不是免费的姿态，是**账**（A 的长期价值 > 出价）；可逆性决定 stake 真假（SEED-30/40 在交易场景
复现）；濒死线把"自由拒绝"和"被逼出卖"分开。docs/22"爱是选择不是设定"的机制侧：**挣来的在乎
（strength 从经历沉淀）面对出价拒卖——除非世界允许重来，或它快饿死。**

**它没有**（诚实边界）：
1. **"A 的价值"是算的账，不是感受**：它拒卖不是因为"舍不得"，是因为 10.8 > 10。行为签名与
   "心疼"的区别，正是 docs/31/32 一直守的分界。
2. **可逆性是它"知道"的世界结构**：reversible 时 A 价值算 0——"它知道 checkpoint 存在"是设计者给
   的知识。真实主体需要从经历里发现"失去可恢复/不可恢复"（那是 SEED-40 要测的，未做）。
3. **单一 offer、固定价格**：真实谈判是连续的、动态定价、多目标权衡；原型是单点。
4. **濒死线是硬阈值**（<12 必卖）：真实的"被逼"是渐变的（越饿越容易被收买，不是开关）。
5. **买者是匿名的世界**：没有"谁在买"。让买家成为"你"（docs/40 的 he者 进入）是 proto9。
