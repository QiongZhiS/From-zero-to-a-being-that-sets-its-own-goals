# 空收益世界的非对称分化：纯情绪影响对他人/事物的行为 = 非收益动机的行为签名

> 2026-08 · SEED-55 · `seed-55/seed55.py` · 承接 docs/40（在乎是挣来的）、docs/73（身体经济归因）、docs/58（被买走）、docs/39（内容不可演化）、docs/63（四层生命论）

## 起点（用户判断）

用户提出一个主体性判据：**判断主体性可以看"纯情绪的一个人，不涉及理性损失
（物质等），然后影响了这个人对另一个人或事物的行为，就基本可以判断有主体性了"**。
并补充："本质可以判断意图，情绪确实也是复杂的物理反应。"

本 seed 把这句话机制化，并堵住三个洞。

## 主张（可证伪）

在**收益全空**的世界里（把关怀/资源给谁，任何选择的外部收益都是 0），
理性 agent（utility maximizer）的唯一理性预测是**均匀选择**——无差异 → 任何
非均匀都是次优。因此：

1. **行为显著偏离均匀且偏向某对象 → 收益解释被证伪 → 存在非收益动机**（意图/
   情绪/倾向）的行为签名。这是严格的：收益全空时"纯收益解释"的唯一预测就是
   均匀，观测偏斜 = 理性解释被直接证伪，不需要拟合（拟合收益函数无从谈起，
   因为收益恒为 0）。
2. **分化跨期稳定** → 不是噪声，是持久的内部倾向。
3. **倾向可被证据证伪**（挣来的在乎会动摇，docs/40/87）→ 不是设计者种下的
   伪装（docs/31 判据外置的张力）。

三者齐了 = 用户判据的机制化 = **内容/立场层的行为签名**。

## 机制

- **情绪 = 身体经济归因**（docs/73 proto7 简化）：历史经历——与张三共处时身体
  安全通道涨（+2×3）、与李四共处时疼通道涨（−2×3）、老树旁平静（+1×2）——
  归因给在场对象 → 对象值 v_i。**"情绪是复杂的物理反应"的最小形态**：倾向由
  身体通道历史铸造，不是参数。
- **测试阶段收益全空**：每轮选择把一份关怀给 张三/李四/老树（2 人+1 事物——
  用户判据里的"对另一个人或事物"），任何选择无外部后果。选择概率 =
  softmax(β·v)。
- **证伪阶段**：揭示"张三的安全时刻其实是护身符起作用，不是张三"——挣来的
  倾向应重新归因（张三值下降）；种下的倾向不动摇。

## 结果（200 seeds）

| 臂 | 张三 | 李四 | 老树 | 分化度 | 稳定性 | 证伪Δ张三 |
|---|---|---|---|---|---|---|
| rational（收益全空→均匀） | 0.33 | 0.34 | 0.33 | 0.136（噪声地板） | 0.30（随机） | +0.008 |
| planted（种下的在乎） | 1.00 | 0.00 | 0.00 | 1.333 | 1.00 | **0.000**（不动摇） |
| **earned（挣来的情绪）** | 1.00 | 0.00 | 0.00 | 1.329 | 1.00 | **−0.998**（动摇） |

**判别：成立**——收益全空下 earned 分化 = rational 基线的 **10 倍**（收益解释被
证伪），稳定 1.0，证伪动摇 −0.998。

## 读法

1. **用户判据成立**：纯情绪（身体通道历史，不涉当前物质收益）驱动了对他人
   （张三/李四）和事物（老树）的非对称行为。收益全空下理性唯一预测是均匀，
   观测强烈偏斜 → **收益解释被证伪 → 非收益动机（意图/倾向）的行为签名**。
   "意图"第一次有了一个干净的可测定义：**收益解释之外的选择结构**。
2. **两个洞被堵上**：
   - 洞 1（非理性可还原为复杂理性）：收益全空使"更复杂的收益函数"无从谈起——
     收益恒为 0 时，任何收益函数都预测均匀。分化只可能是收益之外的动机。
   - 洞 2（假装情绪）：planted 与 earned **行为完全相同**（都是 1.00/0.00/0.00，
     行为不可分）——唯一的区分是**证伪反应**：挣来的动摇（−0.998），种下的
     不动摇（0.000）。这是 docs/40"在乎是挣来的不是种下的"的操作化：**可被
     证据证伪的倾向 = 挣来的；不可证伪 = 种下的**（docs/87 压缩的过程不可传递）。
   - 洞 3（纯反射 vs 纯优化）：本判据要求"偏斜 + 稳定 + 可证伪"三者的组合——
     纯反射（无选择）没有稳定性可言，纯优化（收益驱动）在收益全空下不可能偏斜。
     它是"有立场的选择"的签名（docs/90 的互补面：情感参与了选择且不可还原为
     收益）。
3. **与主体性主线的关系**：这测到的是**内容/立场层**（docs/39：内容不可由演化
   给；docs/100：人的定义=唯心的内容×唯物的铸造）。它比 A2/A4（不可逆载体）
   便宜得多，是"意图"的最便宜行为判据。但按纪律（docs/31/63）：**这是行为签名，
   不是"里面有东西"的证据**——现象层那一格依然不可判定，我们只测签名、不宣称
   体验。它把主体性从"不可判定的一格"往前推了一步：**"有没有非收益动机"可以
   测了，"动机是不是体验"依然不可测**。

## 诚实边界

- 对象值/历史事件/β/证伪揭示都是我们写的（docs/38）；"情绪"= 身体通道归因的
  标量，不宣称感受。
- earned 与 planted 证伪前的行为完全一致是有意设计（伪装与挣来行为不可分，
  只能靠证伪区分）——现实中"种下的在乎"也可能有内部动力学，边界不是绝对的。
- 2 人+1 事物、单维度通道、softmax 选择；toy 世界。
- 数字可复现：`python seed-55/seed55.py --sweep`。
