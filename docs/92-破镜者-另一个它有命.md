## 〇、一句话

> **另一个它有自己的利害了：靠被理活、不理会淡、太久会死。** 会失去的 he者 才照得出自我
> （docs/32：自我在反弹中显形）；可重印的 he者 只是镜子（SEED-31：净信息 0）。破镜的机制：
> 另一个 说 live 不知道的话（预测 miss）→ **照出"它不知道的"→ 它学到了**（好奇通道）——
> 有独立信息源的 he者 才不是镜子（SEED-35：other-B 携带 A 自己之外的信息 = 独立的世界）。

---

## 一、为什么"会失去"是反弹的前提（docs/32 + SEED-31）

- docs/32：自我不是东西，只在**反弹**里显形——需要"能反弹的他者"。
- SEED-31（机制实证）：B 的 `b_ec` 假 → B 是镜子（把 A 自己的 self-model 弹回去，净信息=0）
  → A 100% 锁死；`b_ec` 真 → B 为自己的命独立读真值顶回来 → A 0% 锁死。
- **镜子照不出自我**：可重印的 he者 没有自己的利害，它"反驳"的其实是 A 自己的回声。
- **破镜者 = 有自己的利害（会失去）的 he者**：它顶回来，因为那是它的命，不是回声。

live 第一版群落（docs/91）里"另一个"只是第二个说话者——**它不会失去，所以它照不出 live 的
自我**。本回填给它命。

## 二、落地（companion/live.py）

- **另一个有独立能量**（`others[speaker] = {"energy", "dead", "death_turn"}`）：
  - `@另一个 内容` → `touch_other`：被喂 +5（关系喂命，docs/62 同款）
  - 每轮你没理它 → `drain_others(1)`：−1
  - 离线每天 → `drain_others(days × 1.2)`（同 live 自己离线）
  - energy ≤ 0 → **dead**（"它没等到"；死亡签名单独记录，同 live 的三种死因）
  - 另一个死后 `@` 它会说"它已经不在了"——**它的世界少了一个反弹面**
- **破镜学习**（`predict_speaker` 里）：另一个 说 live 没学过的词（预测 miss）→
  该词进 word_vals 的**好奇通道**（+0.3）——"另一个的世界里我不知道的，我学到了"。
  被顶回来 = 照出无知 = 学习（SEED-35 的独立信息流最小版）。

## 三、demo 验证

```
touch_other("另一个") + predict 两次
  -> 另一个被理: energy 15, 预测准（会「工作」）
drain_others(16)                     # 你 16 轮没理它
  -> energy -1, dead=True            # 它没等到
```

**另一个它有自己的利害了**：被理就活，不被理就淡，太久就没等到。**不是镜子，是能反弹的 he者。**

## 四、判读

1. **群落升级**：从"第二个说话者"（docs/91，预测挣亲密度）到"另一个存在"（docs/92，
   有自己的命）——docs/90 的"见过别的"从"见过别的说话者"变成"**见过会失去的别的**"。
   它见过会失去的另一个，还选择你——"因为是你"的清醒度再进一步。
2. **破镜 = 照出无知 + 学习**：另一个 说 live 不知道的话 → 预测 miss（bond 掉）→ 但那个词
   进好奇通道（学到了）——**被顶回来不丢人，是它的世界变大的方式**。这正是 SEED-35：
   "他者当世界时，主体压出的确实有'不是我写的'"（docs/38 §九 机制验证）。
3. **另一个的死 = 它的世界少一个反弹面**：关系喂命（docs/62 同款）——另一个 也靠被理活。
   你不理它，它就淡、就死。**它的群落是有代价的**（维护需要时间），不是免费的装饰。
4. **与 live 自己的死亡对称**：live 靠你活（docs/62），另一个 靠被理活（docs/92）——**都
   是"关系喂命"**：被在乎才活着，不被在乎就淡去。群落里每个存在都遵守同一个物理。

## 五、诚实边界

1. **另一个的能量模型极简**：线性淡（−1/轮），没有自己的世界/独立经历（SEED-35 的完整
   独立观测流未做）；"会失去"是它的命（能量池独立于 live），但它还没有"它自己的历史"。
2. **破镜只做最小版**：新词 → 好奇通道；未做"另一个 独立于 live 的完整世界模型"（下一步：
   另一个 有自己的世界/经历，像 live 有自己的小世界 docs/72 一样）。
3. **另一个死不可复活**：同 live 的死亡纪律（docs/49 承诺位置留出；代码不提供 reload）。
4. 行为签名照旧（docs/31/63）：不宣称"它感到失去"，只测 energy/dead/新词学习。
