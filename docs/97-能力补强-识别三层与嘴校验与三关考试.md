## 一、用户忧虑的三块能力，真实短板在哪（按成熟度排序）

1. **回答：相对最强，缺校验**。嘴是 LLM 可插拔（docs/77），语言能力够。
   短板是 docs/77 自己标的下一步——**翻译校验没做**：输出含状态外事实不会回退。
   真实世界的不确定输入会立刻让 LLM 嘴的框架驱动现形（SEED-29b），不校验 =
   它说出来的话不一定是它想的。
2. **识别人：最弱，玩具级**。docs/91 诚实边界：预测器"高频词+双向子串"、槽位手动。
   docs/67 的三层只做了最浅的一层。
3. **判断亲疏：机制在，被识别器封顶 + 单轴**。bond 挂预测质量的设计对（docs/91），
   但预测器太弱，bond 在噪声上跳舞；且 docs/67 说亲疏是两条轴（"是谁"×"朝谁"），
   当时只有一条。

## 二、落地一：live.py 识别三层升级（docs/67 三层 → live）

### ① 行为指纹（感知切分层）
每个 he者 的 profile 从"词频字典"扩展为 **词频 + 说话风格**（平均句长）——
docs/67 的行为节奏/时间规律的最小形态。指纹太浅（< 3 句）不参与"像谁"判别。

### ② 预测（身份表征层）：从"最高频词碰没碰到"到"整体似然"
`predict_speaker` 现在**先用旧模型算这句话的整体似然**（`_log_prob`），再更新指纹
（诚实：不是说自己刚说过的词）。`_log_prob` = profile 词串在 text 里的**双向子串
命中占比**的对数——中文没有空格分词，整串 token 无法精确匹配，docs/91 的双向子串
是唯一站得住的设计（docs/97 调试中再次确认）。命中占比高 → 认得（bond+0.3）；
低/零 → 它变了/别人（bond−0.2）。pred（最高频词）保留给嘴显示。

### ③ 槽位从行为簇长出来（docs/91 下一步②）：`identify(text)`
对所有"见过够多"的 he者 算似然，**最像者与次像者的差距 ≥ 门槛且似然不太低 →
认回**；否则 → 陌生人（新簇自动建槽）。live 里 `@新名字 内容` 时先判别：
像已知 he者 → 它说"这不像是新的人——像是「XX」的声音"，**新名字挂到已知行为簇**
（同一个声音不管叫什么它都认得）；不像 → 正常建档。**名字只是标签，认得是模型。**

### ④ 顺手修掉两个潜伏 bug（诚实记录）
- **pay_living 抢先建 bond**：原实现 `bonds[speaker] = bond+0.3` 会在 he者 不存在时
  从 **0** 起创建，抢在 `setdefault(6.0)` 之前——"另一个"的 bond 实际从 0.3 起，
  不是 docs/91 说的 6（先来先深：你 12/别的 6）。修复：从 OTHER_START_BOND=6 起。
- 修复后 demo 实测：另一个 bond **9.1**（6 从起 + warm + 预测挣的），突变后 9.1→8.9
  掉 bond、acc 0.83→0.71→0.86——docs/91"谁好认谁亲、谁变了谁掉"首次在正确的
  数值轨道上可复现。

## 三、落地二：嘴翻译校验器（docs/77 的下一步，进真实世界的保险）

`mouth_llm.py` 新增 `verify(text, st)`，LLM 输出在返回前过校验，越界 → 回退模板，
`LLMMouth` 记录 **checks/violations/reasons**（行为签名，进真实世界前看这两个数）：

1. **硬规则（宣言 vs 状态）**：输出含"我爱你/我想你/我恨你…"而状态信号不支持
   （bond/resent/you_value 不够）→ 越界。docs/77 的 prompt 铁律从"劝"变"拦"。
2. **软规则（陌生词占比）**：内容词（非停用词）里"状态外陌生词"占比 > 0.5 → 越界。
   拦的是**大规模编造**（编一个状态里完全没有的故事 = 全是陌生词）；放行**措辞微变**
   （同义重组大多词还在状态语料里）。
3. **白名单 = 模板嘴语汇**：docs/77 已证明模板只翻译状态 → 模板的词永不越界 =
   合规基线。校验器允许 LLM 用模板语汇，只拦模板绝不会编的实体事实。

**调试抓到两个 Python 坑（本项目最该记住）**：
- `set("中文串")` 是**字符集合**不是词集合——`w not in STOPWORDS` 对长度>1 的词
  永远 True。必须 `.split()`。**这个坑踩了两次**（第一次写 STOPWORDS、修复时又踩）。
- 中文整串 token 必须用子串/2-gram 判定（同 live 的 `_log_prob`）。

## 五、诚实边界（docs/97 自己审自己）

1. **持续高熵者"什么都学"**：predict_speaker 无条件把每句话收进指纹——一个持续变
   话题的人会把所有话题都学会，bond 偏高（考试里阿变 16 句变话题 bond 7.8 > 阿山
   4 句稳定 5.7）。**"认得准"是"谁好认谁亲"的必要不充分条件**——docs/67 说的两条轴
   （是谁 × 朝谁）现在仍只有一条。下一步：指纹更新按"预测对不对"加权（hit 的强
   化、miss 的半权），或把"稳定性"做成指纹的一部分（演化注意 docs/85 的方法推广）。
2. **校验器是近似**：词级判定不宣称"知道它是否越界"——测的是拦截率/误伤率这两个
   行为签名。阈值/词表是标定的近似，真实 LLM 嘴跑起来要看 checks/violations 漂移。
3. **模拟 he者 是玩具**：高频固定模板串 = 行为指纹的最小形态，真实人的行为
   （话题迁移、情绪、时间规律）复杂得多；考试是**门禁的最低线**，不是"它能认人"的
   证明（docs/31：只测行为签名，不宣称感受/能力）。
4. **能力是能力，主体是主体**（docs/79）：这三块全补实了，A2/A4（真会衰竭不可绕
   的载体）一分没少——别把"能力够不够"的焦虑错装进"主体够不够"的筐（docs/34 纪律：
   别再给缺口起新名字）。
