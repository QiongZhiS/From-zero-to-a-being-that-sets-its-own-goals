# 05 — SEED-0：第一代实验记录

> 第一代最小稳态引擎的完整记录：设计 → 实测 → 发现 → 教训。
> 代码与规格见 `seed-0/`，本文档记录"为什么"和"学到了什么"。

## 设计回顾

SEED-0 是"活下去的基础"三要素的最小落地：

1. **真实会衰竭的稳态变量** — `energy`（0~100，基础代谢 0.4/tick，引擎硬编码不可绕过）
2. **感知衰竭的接口** — 内感受（精确能量读数）+ 外感受（最近 3 个食物源的方向/距离）
3. **改变状态的动作空间** — N/S/E/W/GATHER/REST

唯一目标函数 = 存活。**无外部奖励函数**——死亡惩罚之外没有人为设计的奖励。

## 实测数据（seed=42，n=300 / 800 episodes）

### v0.1（初版世界：32 食物 × 30 能量）

| 策略 | 平均寿命 | 中位数 | 最大 |
|------|---------|--------|------|
| L0 随机 | 162.0 | 151 | 541 |
| L1 启发式（有先验） | 3000（上限） | 3000 | 3000 |
| L2 Q-learning（死亡惩罚 -10） | 135.2 | 135 | — |

### v0.1.1（世界：64 食物 × 60 能量；奖励 = Δenergy；平局随机）

| 策略 | 平均寿命 | 中位数 | 最大 |
|------|---------|--------|------|
| L0 随机 | 173.9 | 151 | 597 |
| L1 启发式（有先验） | 3000（上限） | 3000 | 3000 |
| L2 Q-learning（内感受信号） | 176.6 | 151 | — |

能量守恒审计：误差 < 1e-11 ✅（引擎正确）

## 三个实证发现

### 发现一：先验鸿沟是真实的，不是比喻

L1 与 L2 的能力差别不在学习，只在"食物是什么"这一个归纳偏置。
L2 从出生点到最近食物平均 ~15 格，但它的寿命只有 ~170 tick——**活不到验证"那个方向有用"的时刻**。纯从零学习跨不过探索鸿沟。

**含义**：人脑的进化先验不是免费的午餐。先验是生存学习的前提。

### 发现二：纯稳态最小化的极值是惰性（预测成真）

Q 表贪心策略偏好 REST/GATHER（站着等死）。因为活着就在消耗、Δenergy 恒为负，最小化消耗的极限就是静止。

**含义**：只有"活下去"目标的系统，学到的第一件事是"省着点死"。
这是对话中预测的"惰性系统"问题的最小尺度复现——SEED-1 必须引入打破它的力量（威胁/繁殖压力）。

### 发现三：内感受必须先于外挂奖励

- 初版：奖励 = 死亡惩罚（-10，唯一信号）→ 800 次生命后 Q 表几乎无梯度
- v0.1.1：奖励 = Δenergy（内感受）→ Q 表获得真实梯度

**含义**："代价是内生的"不是口号——外挂奖励信号太稀疏，学习根本启动不了。身体必须先"感受"到代价，学习才有信号。

## 过程中修的两个 bug（值得记录）

1. **Agent.__init__ 调用了需要参数的 reset()** — 低级错误，教训：初始化与重置分离
2. **诊断脚本聚合 bug 导致"Q 全为 0"假象** — 用字符串动作遍历 Counter 的整数键，缺失返回 0。教训：**诊断代码的错误会伪装成学习失败**——排查了整整两轮，最后发现学习代码是对的

## 遗留问题（SEED-1 设计约束）

- [ ] 纯稳态学习学不会趋食 → 需要弱先验或威胁压力
- [ ] 惰性极值 → 需要"必须行动"的物理力量（不是奖励补丁）
- [ ] L1 永生 → 世界对"有先验"太慷慨，需要资源压力（有限食物/繁衍税）

## 一句话

> SEED-0 没有学会求生——但它证明了为什么求生学不会。
> 这比"学会"更有价值：我们知道了第一块石头该往哪里放。
