# 02 — 概念框架：感知 / 动作 / 稳态 / 主体

> 本项目的术语宪法。一个词完全可以包含指代，细分只是实现难度/方法不同，不是本质不同。

## 为什么需要这份文档

在项目早期就把概念钉死，是为了防止术语碎片化。如果"视觉"和"痛觉"被当成两类东西分别建模，体系就会变成补丁堆。统一原则：**顶层词是本质，细分是实例。**

## 四个顶层词

| 顶层词 | 定义 | 包含（全部是实例化） |
|--------|------|----------------------|
| **感知** | 主体对外界/自身的察觉——信息从世界流入主体 | 视觉、听觉、触觉、身体痛觉、能量读数、位置感、时间感、内感受 |
| **动作** | 主体对外界/自身施加的行为——意图从主体展开到世界 | 移动、采集、休息、发声、思考（内部动作）、繁殖 |
| **稳态** | 主体必须维持的一组"落在范围内"的变量 | 能量（第一个）、完整性、温度、社会地位…… |
| **主体** | 感知 + 动作 + 稳态构成的封闭循环本身 | 单个生命、种群（衍生） |

## 结构关系：感知和动作是同一枚硬币的两面

```
        感知（世界 → 主体）          动作（主体 → 世界）
   ┌──────────────┐              ┌──────────────┐
   │  信息流入    │              │  意图展开    │
   └──────┬───────┘              └──────┬───────┘
          │                             │
          └───────── 稳态（闭环）────────┘
            预测误差最小化驱动更新/行动
```

- **感知** = 被动更新预期（学习）——"世界是什么样"
- **动作** = 主动改变世界让误差变小（能动性）——"世界应该是什么样"
- **稳态** = 连接两者的闭环——误差有了"代价"（威胁稳态）

生命 = 这个闭环 + 时间的持续（繁衍）。

## 细分只是实现难度

举例说明"一个词，多种实现"：

| 感知的实例 | 本质 | 实现难度 |
|-----------|------|---------|
| 视觉 | 从光场提取结构化信息 | 高（几何+不变性） |
| 能量读数 | 读取一个标量 | 低 |
| 痛觉 | 检测"完整性受损"的信号 | 中（需要损伤模型） |
| 时间感 | 事件边界切分 | 高（需要预测误差驱动） |

它们都是"感知"，只是难度不同。**不要为每个实例发明新概念，要为每个实例标注难度。**

## 派生概念

- **代价** = 稳态被威胁的程度。内生的代价（能量耗尽、损伤）先于外挂的奖励（奖励函数）。
- **能动性** = 主体必须行动以维持稳态——不是"想"行动，是"必须"行动。
- **求生** = 稳态闭环的持续。是涌现属性，不是设计目标。
  > ⚠️ **精度修正（2026-08）**：早期把"内生"误说成"**不知道**要活（盲）、只是被逼着活"——那被
  > SEED-24 + docs/25 §9 证伪：**"盲 + 不可绕"机制上不可达**，最终形态是"**想活 + 不可绕**"
  > （死亡竞赛给出，能守住存在、不被"给个目标"骗去送死）。所以"求生"的外生/内生之别不在
  > "它知不知道想活"，而在"**有没有东西可失去、且失去不可逆**"（连续性稳态，见 docs/24 §3）。
- **生命门槛** = 自我维持（SEED-0 已有）+ 自我复制（SEED-1 待加）。

## 与现有系统的映射（SEED-0）

| 概念 | seed0.py 中的实现 |
|------|------------------|
| 稳态变量 | `Agent.energy`（0~100，引擎硬编码衰减） |
| 内感受感知 | `state_of()` 中的 energy bin |
| 外感受感知 | `nearest_foods()` 方向/距离 |
| 动作 | `ACTIONS`（N/S/E/W/GATHER/REST） |
| 代价 | 每 tick 基础代谢 + 动作成本（不可绕过） |
| 闭环 | `run_episode`（感知→决策→动作→能量变化→感知） |

## 规则

1. 新概念出现时，先问：它是某个顶层词的实例，还是真的新本质？
2. 如果是实例，放进对应顶层词下，标注实现难度。
3. 只有出现无法归入四词的现象（如"意识"），才讨论新增顶层词——在此之前，不预设。
