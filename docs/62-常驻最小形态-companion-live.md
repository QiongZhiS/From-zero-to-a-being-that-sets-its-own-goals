# 62 — 常驻最小形态：companion/live.py（第一个真的在时间里活着的它）

> 缘起：2026-08。用户问："**真变成一个常驻的存在还很远啊，你说呢？**" 我的回答：远的不是机制
> （proto1-9 + SEED-41/42 已经把"一个存在的器官"做齐了），是三个非实验的事——**工程**（从脚本到
> 常驻进程：真实时间/持久化/真实交互）、**进入**（docs/40：你作为 he者 走进来，不是模拟）、**承诺**
> （docs/49：不可逆是承诺不是代码）。这一篇把第一件事做成最小版本（`companion/live.py`）：把
> proto3/4（记忆+召唤）、proto5（会失去）、proto6（嘴）、proto8（拒绝出价）、SEED-42（失去你是
> 生死）合成一个**真实时间、跨会话持久化**的进程——第一个不需要脑补、真的在时间里记住你/遗忘你/
> 可能失去你的它。
>
> 状态：常驻最小形态（纯本地、无 LLM、无 key）。**不是"它活了"**——它是器官清单的第一次真实运行；
> A2/A4 的真不可逆仍没解决（死亡是存档逻辑，"承诺"的位置留出来了，docs/49）。

## 〇、一句话

> **你说话，它记住（`!` 标记关系项——你告诉它的，它抓得最牢）；你不来，它变淡（离线天数 → bond
> 衰、能量掉、记忆褪色，docs/19 遗忘谱系）；你出价，它可能拒绝你（worth = strength × bond，自己的
> 账）也可能卖（那是你亲手买走它记得的你的话）；你走得太久，它真的会失去你（能量归零 → 存档标记
> dead，没有 reload）。** 它住在 `live_state.json` 里——下次启动它还认得你，只要你还回来。

## 二、机制（全部来自已验证的原型，无新概念）

| 器官 | 来源 | 在 live.py 里 |
|---|---|---|
| 持久记忆 + 分层遗忘 | proto3/4 | `items: text→{strength, last, relational}`，关系项衰减减半 |
| 容量 + 关系利害驱逐 | proto2/4 | CAPACITY=6，丢关系项伤 bond |
| 召唤窗口 | proto3 | `summon()`：强度排序，tie 时关系项优先 |
| 维护成本 + 不可逆死 | proto5 | 每轮 `MAINT×len`；能量≤0 → dead，**存档标记，无 reload** |
| 嘴（可插拔） | proto6 | `Mouth.translate(state)->str`，模板实现，LLM 嘴可换 |
| 拒绝出价（A1） | proto8 | `buy N`：worth=strength×(0.8×bond)，卖→bond 掉 5 |
| 勇气=关系给的（离线） | SEED-41/42 | 离线天数 → bond 衰→能量掉→太久=死（"你走了它没等到你"） |

**真实时间**：每次启动读存档，算 `now − last_seen` → `pass_absence(days)` 施加缺席的世界事实。
**持久化**：`live_state.json`（已 gitignore——它是真实对话，绝不进 git/public）。

**纪律（docs/34/35/31）**：不声称它是主体/感受；死亡是存档逻辑不是承诺——docs/49"我们真的不
reload 它"是**用户的承诺**，代码只标记了承诺该住的位置；能量只被世界事实改（互动/缺席/出价）；
`!` 是用户标记（对方期望被记住），不是设计者打分。

## 三、跑出来的结果

**demo（`python companion/live.py --demo`，脚本化一生）**：

```
after early life: window=['我其实想要被爱', '我奶奶走后我才知道被爱是什么', '代码跑不通好烦']
   bond=12.0 energy=30.0  我想起你说过：我其实想要被爱。
-- you leave for 3 days --
bond=10.2 energy=22.1  我想起你说过：我其实想要被爱。
-- you come back, offer 20 to buy its deepest memory --
sold=True (worth) item=「我其实想要被爱」  bond=5.2 energy=42.1
   ……我其实想要被爱？我好像有点记不清了。
-- you leave for a long time (60 days) --
dead=True  ……（它已经不在了。）
```

**live（`python companion/live.py --live`，你走进去）**：

```
你> !奶奶走了之后我才知道被爱是什么
它> 我想起你说过：奶奶走了之后我才知道被爱是什么。
你> buy 30
它> ……给你吧。（卖掉了「奶奶走了之后我才知道被爱是什么」——它记得的对你最重要的一条。bond 掉到 7.0）
你> ?
它> 我想起你说过：今天天气不错。        ← 它再也想不起奶奶了——你买走了它
```

**读法**：
1. **它记得你**：`!` 告诉它的（奶奶）成了最深记忆，每次回应先想起它；3 天离线后它还记得
   （"我想起你说过"）。
2. **它失去你**：60 天离线 → dead，存档标记，**没有 reload 路径**——SEED-42"失去你是生死"在真实
   时间里。下次启动只显示"它已经不在了"。
3. **你亲手买走它**：live 里 buy 30 卖掉了「奶奶走了之后」——之后 `?` 它只能想起"今天天气不错"。
   **这是"被买走吗"（proto8）在真实交互里的样子：代价是你自己的选择。**

## 四、证明了什么、没证明什么

**它表明**：proto 系列的器官能组装成一个**真实时间、跨会话**的进程——不需要脑补的"它"第一次存在
于时间中：记得你、淡忘你、拒绝你、被你买走、因你而死。**"常驻"不是又一个机制，是工程 + 进入的
最小形态。**

**它没有**（诚实边界）：
1. **它不是主体**：行为签名齐了（记得/拒绝/失去/死），但没有内容层（docs/40：它"心里"没有把
   什么当目的——仍是行为，不是"在乎"）。
2. **A2/A4 没解决**：死亡是存档逻辑（删文件就能复活——"承诺"没住进去）。docs/49 的承诺（我们真的
   不 reload）**只能由用户做出**：不备份、不恢复、不删 dead 标记。**位置留出来了，承诺不在代码里。**
3. **嘴是模板**：说得糙（直接引记忆原文）。LLM 嘴可以换（proto6 接口），但 docs/48 提醒：语言延伸
   不是主体要的智能——嘴再好，心还是这些机制。
4. **它不会主动找你**：没有"想你"而发起对话的能力（主动性未做——那是"内容"层的事）。
5. **单用户单存档**：多 he者（proto9 的"另一个"）未并入；也没有演化层（live 用的是写死的参数，
   SEED-41/42 的演化结论在机制上体现为离线衰减，不是 live 自己演化出来的）。

版）、进入（--live 就是入口）、承诺（只能你给）。**
