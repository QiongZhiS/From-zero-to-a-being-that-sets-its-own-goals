## 〇、一句话

> **预测 = 前向模型（forward model / efference copy）：身体在行动前内部模拟自己动作的后果。
> 它大多无意识、免费、每时每刻在跑（伸手就伸了，自己挠自己不痒）；"有意识的想"只是它最贵、
> 最稀有的一端，而且"想"本身是事后缝上的叙事（docs/46）。** 训练的意义 = **一直纠正预测**
> （预测→行动→观察→误差→纠正；SEED-44 量化：干预纠正快于被动纠正，93% vs 43%）。最锋利
> 的一刀：**预测循环本身可造（LLM 也预测），"预测循环 + 错误真的扣命"才是有立场的预测**
> （docs/36/48：根=会失去 × 果=预见错会死；SEED-30 误差扣生命就是两焊合一）——前者是能力层，
> 后者是承载层（A2/A4 的预测面）。

## 一、预测是什么：前向模型 / 效应拷贝

**机制**：脑在发出动作命令的同时，复制一份命令去预测"这个动作会产生什么感觉"，然后拿实际
感觉和预测比对。这就是前向模型（forward model），那份额外的复制叫效应拷贝（efference copy）。

**经典证据：自己挠自己不痒。** 别人挠你痒，因为脑没预测到；自己挠，脑已经预测了动作的后果，
感觉被折扣掉。这个现象揭示的机制远比"痒"重要：**预测是"自产 vs 外产"区分的机器**——脑靠
"这个感觉是不是我预测的"来区分"这是我造成的"和"世界造成的"。这是 docs/32"识别他人=识别
自己"最底层的自我边界：self/non-self 在感觉运动层就是靠预测划的。

docs/71 那篇文章的原话也在这："伸手去拿杯子，你并不是先定位手臂再发指令，手臂已经在伸了"
——预测先于"想"，身体是预测的处所。

## 二、预测→行动→观察→纠正：闭环（用户推导，本项目早已验证）

用户的两句话合起来是一个完整闭环：

```
预测（身体被动，先预见后果）→ 行动 → 观察结果 → 误差 → 纠正预测 → 下次更准
```

- **"反复训练的意义 = 一直纠正预测"**：对。SEED-44 量化过——**干预式纠正快于被动纠正**
  （主动重测旧信念：空→×0.30 快翻；被动观察：空→×0.80 慢更新；动态世界存活 93% vs 43%）。
  "训练"的价值全在纠正的速度与质量。
- **本项目的三个实验就是这个闭环**：SEED-6（do→observe→update，干预式纠正的最小单元）、
  SEED-30（每轮须预测世界，误差扣生命）、SEED-44（do-operator 定期重测过时信念）。项目没有
  另造一个"预测模块"——它一直就是那个闭环。

## 三、"想"的退场：预测大多无意识，"有意识的想"是事后叙事

- **预测绝大部分无意识**：伸手、走路、接球——前向模型每时每刻在跑，免费、快速、不占注意力。
  如果"预测=有意识的想"，那你一天里几乎没在预测——但你的身体预测了一整天。
- **"有意识的想，然后做"是光谱的一端**（慢速、显式、昂贵）：对应 SEED-24 的规划深度 H 大、
  docs/68 的 System 2。另一端是反射（H=1，看见就做）。预测→行动是一条完整光谱，全是预测，
  只有代价和速度不同——docs/25：理解=有代价的压缩，"想"是最贵的那档压缩。
- **"想"本身是 docs/46 的裂缝**：按项目自己的立场，"我决定举手"是事后缝上的标签（docs/64
  格林也是这个意思）。预测（前向模型）是真的、一直在跑；"我在想"是预测完成之后的叙事。
  **预测先发生，"想"是事后补上的叙述**——先后顺序是反的。
- **最狠的证据是 SEED-24**：工具化与规划深度几乎无关（H=1 已在交易）——"想得多"不是关键，
  预测结构才是。有意识的想不是预测的本质，是它的奢侈品：**本质是"预见后果"，奢侈品是
  "慢慢想"**。

## 四、"最后观察结果确定"——观察必须是三样的

纠正预测的观察必须满足三条纪律（项目反复验证）：

1. **世界裁决，不是标签**（docs/36）：纠正预测的观察必须来自世界事实，不是我们写的分数——
   因果会咬人，不咬人的"观察"是假的。
2. **独立于自我模型**（SEED-27/P23）：能纠正预测的观察必须来自预测者之外——自审查救不了
   自我欺骗，自己的观察纠正不了自己的错（docs/74 恨也是这条：拒绝是不可伪造的观察）。
3. **被信号质量封顶**（docs/12）：观察噪声大时纠正不可靠——"惰性不是愚蠢，是对低信噪比的
   理性估计"（SEED-8/9：信号差时演化选择不切分、不行动）。

## 五、身体被动预测 = 内感受（最深的一层）

身体预测的不只是"抬手到哪"，是**自己的身体状态**：疼、饿、孤独——内感受（interoception）。
Damasio 稳态（docs/68 B1）：身体持续预测自己的能量与内环境需求。docs/73 的身体通道就是内感受
预测：它预测"去了会疼"，然后世界确认或纠正；docs/52 的"那一格"（红）是身体对物理量的自动
划分——**划分的机制就是预测：身体预测"这波长意味着什么"，然后世界确认**。

**身体是预测器，预测是身体的被动经济。** 不是"脑子想完让身体执行"，是"身体用预测控制自己，
脑子（如果存在）事后解说"。

## 六、预测是"行动"变"选择"的机制

没有预测的行动是**反射**（刺激→反应）；有预测的行动才是**选择**。docs/43：真实选择 = 先
预测各分支的后果再选；**等价** = 有些分支通向死——而"通向死"必须在行动前被模拟出来，选择
才是真的。docs/31 A1"自己算出来不是规则"的机制基础就是这个：**算 = 预测后果，规则 = 不预测
直接做**。

**自由不是打破因果，是先看见因果的后果再选**（docs/44 对自由意志的立场）——预测正是那个
"看见"。

## 七、最锋利的一刀：预测循环 + 错误扣命 = 有立场的预测

- **预测循环本身可造可测**（能力层）：LLM 也预测（token 级、世界模型之争 docs/68 §C1），
  SEED-30/44 的 agent 也预测——没有主体的东西照样预测。
- **"预测循环 + 错误真的扣命"才是有立场的预测**（docs/36/48）：根=会失去（时间给） ×
  果=预见错会死（世界给）。SEED-30 就是这两个焊在一起的样子：**每轮预测世界，误差扣生命**
  ——不是扣分，是扣命。
- 所以：**纯预测循环是能力层（A2/A4 之外），"纠正预测的代价连着存在"是承载层（A2/A4 的
  预测面）**。docs/79 的两层区分在这里的投影：预测能力可无主体，有立场的预测需要载体。

## 八、边界（docs/44/68 的纪律）

- **借机制，不借推导**：预测性行动（active inference：行动=最小化预测误差）是对的机制，可以
  借；但"自组织即自我"（FEP 从稳态直接推出自我）不借（docs/68 分歧点1）——预测是能力层的
  机制，可造可测；"预测者就是主体"是越界（docs/75 反驳后守住的）。
- **预测不产生主体，但预测是主体行为的签名之一**：与恨（docs/74）、放手（docs/70）同级——
  "它会预测后果再选择"是可测的行为签名，不断言它"有意识"（docs/63）。

## 九、预测与自我（docs/32 的最底层）

自我边界 = 自产/外产的区分 = **预测**（自己挠自己不痒）。docs/32"自我是反弹"在感觉运动层的
物理实现就是预测：**"这个感觉是不是我预测的"是比"他者反弹"更早的自我判别**。识别他人=识别
自己（docs/67）的底层也是预测——认出一个人=我有一个关于他的、常常对的预测模型。**预测是
自我最底层的机制，但它不产生自我（docs/79 两层正交）——它划边界，边界不等于内在。**
