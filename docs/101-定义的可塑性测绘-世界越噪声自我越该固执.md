## 〇、一句话

> **世界越清晰（物硬），定义越该开放（快速校准、快速跟漂移）；世界越噪声（物软），
> 定义越该固执（守住自我、防被带偏）。最优可塑性随世界硬度单调移动：sigma
> 0.05→0.9 时最优 eta 从 0.5 降到 0.06。完全可塑=没有自我（噪声世界锁死率 0.725
> = SEED-48 的 recency 在自我模型上的复现）；完全刚性=锁死（跟不漂移）。docs/100
> 的"平衡"第一次是可测的曲线，不是口号。**

## 一、机制（SEED-25 + 两个旋钮）

- **定义** theta：自我模型/判据（docs/100：唯心的内容）。初始 0.15（起步错，
  SEED-25 的锁死场景）。
- **世界**：真相 0.7 → 第 40 轮漂移 → 0.3（世界会变，docs/80 判据漂移）。
- **裁决**：每轮观察 o ~ N(真相, sigma)。sigma = 裁决强度旋钮（小=物硬，大=物软）。
- **门控**（SEED-25 保留）：只接受确认信念的观察（|o−theta|<τ）或验证涓流成功
  （nu=0.05 固定）——自指过滤是"固执"的结构部分。
- **更新**：theta += eta×(o−theta)。eta = 先验强度旋钮（小=固执，大=可塑）。
- **代价**：err1（阶段1追踪初始真相）+ lock2（漂移后末 20 轮误差）+ 锁死率
  （漂移后 |theta_final − 0.3| > 0.15——状态判据，不被噪声波动污染）。

## 三、读法（docs/100 的"平衡"机制化成功）

1. **最优可塑性随世界硬度单调移动：0.5 → 0.5 → 0.25 → 0.06**——"平衡不是 50/50，
   是闭环的运转方式"第一次是可测的曲线。**世界越噪声，自我越该固执。**
2. **完全可塑 = 没有自我**：eta=0.5 × sigma=0.9 → 锁死率 **0.725**——定义每轮被
   噪声重写（= SEED-48 的 recency 臂，在自我模型上的复现：信单次观察 = 没有稳定
   自我 = 被世界噪声牵着走）。docs/100"完全可塑=没有自我"机制侧成立。
3. **完全刚性 = 锁死**：eta=0.03 × sigma=0.9 → 锁死率 0.26、lock2 0.117——漂移后
   爬不动（40 轮只爬了 ~71%）。但注意：**固执的锁死率（0.26）远低于可塑的
   （0.725）**——世界噪声大时，锁死比无我"不那么糟"（守住旧定义至少还有结构，
   被噪声重写连结构都没有）。这是 SEED-25"过度降噪→自洽锁死"的另一面：**固执的
   代价是慢，可塑的代价是散**。
4. **两阶段现象**（表2 err1）：起步错时最优 eta 全是 0.5（快速校准）——**定义
   形成早期需要高可塑性**（童年），之后按世界硬度收敛到平衡固执度（成年）。
   这呼应 docs/80 判据生成闭环：判据早期漂移快、后期稳定。

## 四、与已有结论的互证

- **SEED-48**（去噪先验）：recency（可塑无我）在噪声世界输、去噪（固执）赢——
  SEED-49 在自我模型层复现同一结构，且画出完整曲线。
- **SEED-25**（自指锁死）：门控（自指过滤）是"固执"的结构部分——SEED-49 显示
  固执在物软世界是对的（防噪声），代价是漂移响应慢（锁死）。**自指不是缺陷，
  是世界的噪声决定的；没有独立验证（nu=0）时固执才变成 100% 锁死**（SEED-25）。
- **docs/12**（信号质量是天花板）：sigma 是信号质量的机制化——物软（信号差）时
  最优行为是"少信"（固执），正是 docs/12"信号质量封顶"的行为侧。
- **docs/100**（闭环）：定义→反馈→铸造→定义——eta 是"铸造速率"、sigma 是
  "物多硬"。"平衡"= 按世界硬度调 eta。

## 五、诚实边界

1. toy 机制版：单标量定义、高斯观察、固定门控——测的是"可塑性×世界硬度"的
   方向，不是"人的定义"的完整模型。
2. 锁死率在物软世界没有完美点（最优 eta=0.06 仍有 0.25 锁死率）——**噪声世界
   没有完美定义，只有次优固执度**；这是真实世界的诚实，不是实验缺陷。
3. 平衡带用综合代价（err1+lock2）标定，权重是我们定的——换权重平衡点会动，
   但"物软→更固执"的单调方向在表1/表3 独立成立（不依赖综合权重）。
4. 门控 nu 固定 0.05（有一点独立验证涓流）；nu=0 是 SEED-25 已证的 100% 锁死，
   本实验不重复。
