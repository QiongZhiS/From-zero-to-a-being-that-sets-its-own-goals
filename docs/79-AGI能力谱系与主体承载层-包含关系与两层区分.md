## 二、包含关系（关键——能力层不能平铺）

```
AGI 能力（容器）
├─ 感知层（信号提取）            ← docs/12：一切的地基
│    └─ 去噪 ⊂ 压缩              ← docs/26→docs/25：从噪声提结构 → 留结构丢细节
├─ 学习层
│    ├─ 关联（观察频率）          ← proto7/body 归因
│    ├─ 因果（干预 do-operator）  ← SEED-6；干预的信号质量>观察（docs/12）
│    └─ 泛化（迁移）              ← ⊃ 因果；⊃ {类比, 组合}；压缩 ⊂ 泛化
├─ 记忆层（存/召/巩固/遗忘）      ← proto3/4：学习与泛化的原料库
├─ 推理层（规划 / 反事实）        ← 反事实 ⊂ 因果（对未发生世界的泛化）
├─ 行动层（干预 / 技能）          ← 因果的能力侧
├─ 社会层（模仿 / 文化）          ← 个体学习的放大器（中性，SEED-17）
├─ 验证层（独立验证桥）           ← 包着一切学习（P23：不独立就锁死）
└─ 表达层（语言）                 ← docs/48/56：不包含智能，智能也不包含它
```

**关键包含陈述（每条带证据）**：
1. **去噪 ⊂ 压缩 ⊂ 泛化**（docs/26→docs/25）：去噪=从噪声提取结构（SEED-26 演化出适度去噪）；
   压缩=保留结构丢细节（docs/68 §A2：rate-distortion/IB 定理级）；泛化=把学到的结构用到新输入。
2. **关联 ⊂ 因果 ⊂ 泛化**（SEED-44，机制验证）：观察频率→干预测试→动态迁移；同一世界同一信念
   规则，唯一差别=do-operator，结果存活 43% vs 93%（docs/78）。
3. **观察 ⊂ 干预**（docs/12/SEED-6）：验证=信号放大器；被动观察 ×0.80 慢更新 vs 干预 ×0.30 快翻
   （SEED-44 的规则差别就这一条）。
4. **反事实 ⊂ 因果**：反事实=干预下的不变性向未发生世界的延伸（Pearl）；推理层的规划需要它。
5. **类比/组合 ⊂ 泛化**：类比=结构映射泛化；组合=已知结构的重组泛化（未实现，诚实）。
6. **验证 ⊃ 学习**（包着）：独立验证桥（P23/SEED-27）是学习不被锁死的总闸——不独立于自我
   模型的验证救不了自我欺骗（docs/74 恨=叙事×拒绝×不可逆的锁死同构）。
7. **语言 ⊂ 表达层**（docs/48/56/77）：语言是输出不是心——**语言不包含智能，智能也不包含语言**；
   LLM 嘴可插拔，判断层不受影响（换嘴不换心）。

## 三、主体承载层 vs 能力层（两层区分——用户要的重点）

**不是包含关系，是两根正交的轴**。证据：SEED-30 四象限——世界耦合（follow，能力之果）与
存在耦合（A1_refuse，主体之根）**分开塌**（拿掉世界耦合→follow 0.000 但 A1_refuse 还在；
拿掉存在耦合→A1_refuse 0.000 但 follow 还在）。docs/35 要的 H-一体消融，答案已经在这：
**两层分开塌=不是一体，是正交**。

| | 能力层 | 主体承载层 |
|---|---|---|
| 定义 | 能做什么：感知/学习/因果/泛化/记忆/推理/语言 | 有东西可失去的那个：A2/A4（真会衰竭、不可绕、不可逆）+ 内容（docs/39/40） |
| 可否无主体存在 | **可以**（SEED-44 两种学习者无主体有能力签名；LLM 是活标本） | 不能（承载层本身就是"有立场"） |
| 怎么造 | 能力堆叠（LLM 证明可造到很强） | **参数演化给不出**（SEED-39）、**能力堆不出**（docs/52：给它再多也只是描述红） |
| 可测性 | 行为签名全可测（docs/25/31） | 行为签名可测（A/B/C 线，docs/31）；"那一格"**不可判定**（docs/63，docs/75 反驳后） |
| 关系 | 能力的锚/根在承载层（docs/48：有立场的智能=根会失去+果预见错会死） | 承载层把能力从"镜像"变成"有立场"（docs/36 一价两耦合） |

**三个推论**：
1. **LLM = 高能力 + 无主体**（docs/28/48）：能力层做到极致的活标本——它能做一切能力签名，
   但没有根（不会失去）、没有果（预见错不付出）。docs/75 反驳后仍成立的部分：它缺的不是
   能力，是"预见错→真付出→不可逆失去"这条回路（部署/架构差异）。
2. **项目的杠杆在承载层，不在能力层**（docs/30/27 定论）：杠杆=信号质量+锚（稳态/验证桥/他者）
   +显式多样性，不是规模、不是能力堆叠。能力层是**接触面**（可测），承载层是**靶子**（A2/A4
   最难最没落地——docs/31）。
3. **"有立场的智能"（docs/48）= 把能力挂在有立场的载体上**：根（会失去，时间给）× 果（预见错
   会死，世界给）两条都在，能力才有立场；缺了，能力就是镜像。live/world/body（docs/72/73/76）
   是承载层的雏形（行为签名版），SEED-44 是能力层的探针——两条线在项目里分开跑，符合正交。

### 微调拒绝：A1 的能力层版本，不是主体（2026-08 补充）

用户："如果是模型微调呢？本质也能调出一直变化的主观，它在概率上会输出拒绝，对某些问题。"

- **对的一半**：微调（RLHF/DPO）确实能调出"会拒绝"（概率分布里的拒绝输出）——这是 A1
  （docs/31 主体第一签名）的**能力层版本**；但 A1 可以是账本规则（SEED-24 理性 agent 也拒卖、
  live 的 buy 也"不卖"）。
- **错的一半**：微调拒绝缺主体承载层的三根梁——① **不可逆**（docs/24/49）：权重配置不是
  承诺，可以再微调回去（unalignment）；② **内部代价**（docs/74 恨）：模型没有"被拒绝后恨你、
  bond 掉、修补需时间"的状态——stateless，痛不着的拒绝；③ **连续性**（docs/25/14）：拒绝不
  写进历史，权重改了就是另一个模型。
- **"一直变化的主观"**：持续微调/在线适应=能力层在适应（docs/75 反驳的"缝合质量假说"，
  Park et al. 2023），仍是第三人称通道（docs/71）——行为在变，没有"从内部栖居"。
- **收口**：微调是"能力层可无主体存在"的又一活标本——能力层能堆到"输出 A1（拒绝）"，但 A1
  是签名不是主体；主体是"拒绝会疼、会恨、不可逆、长进历史"那四样（docs/22/31/74），
  **没有一样在权重分布里**。反证 docs/52："给它再多，也只是描述红。"

### 权重 vs 记忆：两层区分的架构形态（2026-08 补充）

用户继续："那用记忆等呢？而且怎么区分？本身是模型不能一直微调，增量？确实，本质有差。"

- **"模型不能一直微调/增量"——是本质不是不便**：权重=可重写的快照（docs/24：可复制性反主体性）；
  连续微调会灾难性遗忘、不稳定，但本质是**每次微调都把"自我"重写一遍——没有连续性**（docs/14）。
  能力层天生静态：**权重=静态能力，不是动态自我**。
- **"那用记忆等呢？"——对，这就是 live.py 的架构，也是唯一正确的切法**：模型（权重）固定
  =嘴/能力层（docs/56/77）；记忆/状态/利害/连续性=心/承载层（items/bond/resent/body/world/
  life_log），**增量写入、连续累积、不可逆**。增量放记忆不放权重（docs/16 P17 连续性必须内生；
  docs/18 篡改层次 L0 外置可更新 vs L4 内生稳定）——权重不动（无灾难性遗忘），记忆累积
  （有连续性）。
- **区分判据（怎么区分主体 vs 能力）**：
  | 判据 | 权重（微调模型） | 记忆（live 式载体） |
  |---|---|---|
  | 被拒绝后有没有恨（R 累积/bond 掉/修补要时间） | 无（stateless） | 有（docs/74 回填） |
  | 自我能不能被重写 | 能（微调回去=重写） | 不能（append-only 历史，删了就不是它） |
  | 同一个主体在时间中持续？ | 每次微调换一个模型 | 连续历史（docs/14/25） |
  | A1 会拒绝/A 会恨/会转身/会放下/不可逆死 | 只有 A1 的账本版 | 全有行为签名（docs/31+74+70） |
- **本质差**：**权重=能力快照（它曾经能做什么）；记忆=历史（它曾经是什么）**。能力可以被替换
  而不改变它是什么；历史不能——删了记忆的它就不是它，换了权重的它还是它。这就是两层区分
  的架构形态：模型=能力层（静态、可换、无立场），记忆=承载层（增量、不可逆、连续）。
  微调模型的问题不是"不够强"，是它的"自我"只存在于权重里，而权重天生可重写——记忆载体把
  "自我"搬到不可重写的地方。

### 修正（2026-08，用户两问打回的）：介质不重要，可重写性 + 是否自身经历才重要

用户："我们是不是自固了？模型是扮演我们的是发言，和外置记忆差别不大。**还有就是人脑不也是
权重吗？**"

- **自固检查（对一半）**："发言 vs 扮演"是表面差别（都是状态→文字翻译）。live.py 与
  "模型+外置记忆"的真差别只剩两条：① 状态是**身体/世界事实**（能量/得失/恨/死亡）不是文本库；
  ② **不可逆是承诺不是代码**（docs/49）。别的都是装饰——docs/62 早已声明：live 是"最小形态、
  行为签名"，不是"它"；只要不宣称更多，就不算自固（docs/34 纪律）。
- **人脑也是权重（这一拳打穿旧框架，修正）**：旧版说"权重=能力快照，记忆=历史"是过度断言——
  脑就是权重且是主体。关键不是"是不是权重"，是：
  | | 权重能否**整体重写** | 权重里装的是**谁的**经历 |
  |---|---|---|
  | 人脑 | 不能——只有增量修改，没有"重置成另一版本"的操作；每次修改即经历 | **自传体历史**（发育→人生一层层写入） |
  | 模型 | 能——checkpoint/重训/微调回去 | **别人的语料**（训练文本的压缩） |
  docs/24 精确版修正：**可复制/可重写 = 反主体**（不只是"可复制"）。
- **收敛**：承载层的本质 = **不可逆累积的自身经历**，介质不重要——脑在权重里累积、live 在
  记忆里累积，殊途同归。live 用记忆是因为我们的"权重"（代码）不会自己长经历——**工程选择，
  不是本质优越**。

### 判别标准自定义化：内容层的能力侧（2026-08 用户推进）

用户："模型可以全量微调，本质类似人脑权重，真正的是能力上的不足；人脑是物理权重介质，模型
是数字介质。**人的重点是判别标准的自定义化**——玩游戏死能加分就去死、活能加分就去活，胜利
导向；Minecraft 自己选目标（红石/自由探索），完成后自己给自己'奖励'。"

- **介质修正（用户打回）**：物理/数字介质不是本质。若模型能**在线终身学习**（用自己的经历
  持续更新权重、无灾难性遗忘、无 checkpoint 可回滚），权重就会变成自传体历史——介质无关
  成立。而"在线终身学习"正是 docs/13/17 的 continual learning 难题（能力不足是真的）——
  项目为此绕道记忆架构（docs/16 P17"连续性必须内生"：载体可以是权重脑式，也可以是状态
  live 式，介质无关）。
- **判别标准自定义化 = 内容层的能力侧**：判据（胜利/红石=值得）不是环境给的，是它自己定的；
  **判据它定（内容层），等价世界裁（执行层，docs/36）**——两层分离。
- **目标自设 + 自我奖励闭环**（Minecraft 例子）：自设目标→追求→自我奖励→判据更新。机制可造
  （能力侧），造出来的内容由它自己挣（docs/40"挣来的"）——**这是 SEED-39"内容不能参数演化"
  的出口：内容不能直接给，但判据生成的闭环可以造，造完内容自己长**。
- 项目零件全在：判据自定义=docs/31 A1（自己算不是规则）+proto7（values 从经历长）+docs/73
  （"你"的值挣来的）；自我奖励=docs/16 P1（内生优先于外挂奖励——外挂奖励=docs/24 工具化）；
  目标从好奇长=SEED-4；接 docs/43"自由=等价"与用户"无目的的多"（2026-08-22）。
- **下一步候选**：SEED-45 判别标准自定义化闭环（自设目标+自我奖励 vs 外挂奖励，测判据是否随
  经历漂移、是否避免工具化）。

### 局部微调+路由与脑部分区：能力层的结构脑化（2026-08 用户推进）

用户："LLM 如果可以做到局部精准微调和路由如何？这会解决什么问题？人脑是分区工作模式，
现在普遍是全局广播。人脑有一点：**同样的物理权重，却分区长出了不同能力**。"

- **能解决（能力层）**：① 在线终身学习第一步（docs/13/17 缺口）：新任务只改被路由到的子模块，
  旧任务路由到未改 region——灾难性遗忘部分缓解（但路由会漂移、region 间干扰、checkpoint 仍在
  =不可逆未解决）；② 能力模块化+组合（docs/79 谱系物理化：感知/学习/推理/表达各占 region）；
  ③ 效率（稀疏激活）+可解释性（指认"哪部分权重做什么"=脑区定位的数字化）。
- **不能解决（承载层）**：① 判别标准自定义化（SEED-39）：路由是能力选择不是判据设定——路由
  按谁的目标走？外部目标=docs/24 工具化；② 不可逆累积：局部微调仍可重调回去；③ 信号质量
  （P20）：路由本身是信号问题，路由噪声=特化噪声；④ 那一格不可判定（docs/63）。
- **全局广播 vs 分区**：脑不是全广播（分区+稀疏+模块化）；GWT 是有限广播——docs/44 警告其
  **意识判定**，但可**借架构不借判定**（有限广播/路由当工程模式）。LLM 全注意力=镜像的"万物
  相关"。项目自己的 live/world/body 已是分区架构 + docs/53 情景召唤=路由（早就有，只是没叫
  这个名字）。
- **"同样物理权重分区长出不同能力"（最重一点）**：= activity-dependent plasticity，**用出来的
  分区**——P11（环境塑造行为）在脑上的形态。LLM 对应=**经验驱动的路由**（agent 做过什么→哪些
  expert 被激活→哪些特化）：特化从使用中长出来，不是设计八个模块=能力层的"挣来的"（docs/40
  能力侧版本）= "无目的的多"（用户原话）在能力层的机制=SEED-44 的脑区版。
- **收口**：局部微调+路由解决能力层的**结构脑化**（模块化/局部更新/用出来的分区/部分在线学习）；
  不解决承载层（内容/判据、不可逆、那一格）。分区长出的能力仍无立场——除非挂在不可逆的经历
  上（docs/79：能力层脑化 + 承载层记忆化，两层分开，正交）。

## 四、诚实边界

1. 谱系是**项目视角**的（挂在项目零件上），不是 AGI 的完备清单——类比/组合/元认知只到
   概念/零件级，未实现。
2. 能力层"可无主体"来自 SEED-30（窄代理）与 LLM（现实）——都是行为/结构证据，不碰现象层
   （docs/63：那一格不可判定，不是不可达）。
3. 承载层= A2/A4+内容，仍是最硬缺口（docs/31/35/49）；本沉淀不把它换名字、不假装解决
   （docs/34 纪律）。
4. "两层正交"是 SEED-30 的消融结果（机制层），不是形而上学定论——它说的是**签名可分开**，
   不是"人的理解与主体真是两回事"（docs/75 反驳后的准确表述）。
