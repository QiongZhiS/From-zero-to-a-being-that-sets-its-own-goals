# 10 — 结尾与新方向：不追求人脑的 20W

> 项目阶段性完结。十二代实验的总结，以及下一阶段的路线宣言。

## 项目总结

**一句话**：从"算法也不是很高深"出发，我们亲手造出了一个数字生命种群，
并诚实记录了它从"会饿"到"会好奇、会验证、有勇气"的每一步——包括每一步失败。

```
SEED-0   稳态引擎      先验鸿沟          → 会饿会死（代价结构）
SEED-1   繁殖+演化     环境塑造行为       → 会繁衍（先验沉积）
SEED-2   捕食者-猎物   威胁塑造行为       → 会躲会竞争（感知限制=生态稳定条件）
SEED-3   记忆          目标导向涌现       → 会记住会导航（信任度 0.68）
SEED-4   好奇心        惰性问题的回答     → 会好奇（0.31→0.51）
SEED-5   直觉          遗忘率权衡         → 会形成判断方式（lr 0.69）
SEED-6   主动验证      do-operator 实证   → 会验证假设（饿死减半）
SEED-7   事件切分      负面               → 记忆失效是渐变的
SEED-8   预测撤离      负面               → 感知与勇气是两层
SEED-9   勇气          平衡点 0.425       → 敢在模糊信号下行动
SEED-10  开放空间      固着涌现           → 开放≠丰富
SEED-11  开放+压力     灭绝               → 无结构=无智能
SEED-12  最小QD        锁死               → 竞争排斥，QD必须显式
```

## 最值钱的收获：负面结果

八个正面/中性结果，**五个负面结果**——而负面结果才是项目最值钱的部分：

1. **先验鸿沟**（SEED-0）：纯稳态学习学不会求生——先验不是免费的
2. **全清式切分劣于渐进遗忘**（SEED-7）：记忆的失效是渐变的
3. **预测受感知天花板限制**（SEED-8）：时间感的前提是感知质量
4. **无结构=无智能**（SEED-11）：世界必须有可利用的结构
5. **竞争排斥在行为空间成立**（SEED-12）：质量多样性必须显式

这些负面结果独立推导出了业界开放演化（POET、QD、世界模型）的全部必要性
（docs/09 对齐）——我们没抄结论，是从失败里走到同一批结论的。

## 方法论收获（docs/08）

**倒果为因**：预设能力参数再让演化调值 = 能力是我们写的，不是演化创造的。
修正：开放空间（神经演化）+ 事后命名（考古）。但仍确认了根本限制——
**演化需要设计者提供压力和结构**，因果源头在造物主手里（docs/04）。

## 新方向宣言：不追求人脑的 20W

整个项目一直在"参考人脑"的框架里（稳态、记忆、勇气——都是人脑的归纳偏置）。
**现在修正：这是不必要的约束。**

### 人脑的 20W 是什么

20 瓦是**亿万年进化的妥协**，不是最优设计的标志：
- 神经信号 ~100m/s → 慢 → 人脑被迫演化出"省算力的启发式"（快思考/直觉）
- 能耗受限 → 样本效率必须极高（婴儿几百次交互学会物理直觉）
- 容量有限 → 遗忘是刚需（不然存不下）

这些是人脑的**缺点被进化打磨成了优点**——但它们是妥协，不是目标。

### 机器不需要妥协什么

| 人脑的妥协 | 机器的自由 |
|-----------|-----------|
| 信号慢 → 靠直觉省算力 | 想得慢但想得多：暴力推演（AlphaZero 式） |
| 能耗受限 → 高样本效率 | 海量并行试错：百万个体 GPU 演化 |
| 容量有限 → 遗忘刚需 | 无限外部记忆：不遗忘、可检索 |
| 生物噪声 → 概率启发 | 精确数学：可验证、可证明 |

### "更高效的算法"长什么样

不模仿人脑的算法，而是**利用机器特性的算法**：
- **搜索优先**：AlphaZero/程序合成——暴力推演 + 自我对弈，比人脑直觉更精确
- **并行演化**：不是 300 个体 × 8000 tick（我们的玩具），是百万个体 GPU 并行
- **神经符号混合**：学习（模糊） + 逻辑（精确）——补彼此的短板
- **显式多样性维护**：MAP-Elites 式 QD——我们 SEED-12 已证明隐式维护必死

### 对项目的意义

SEED 系列证明的是**机制**（环境塑造行为、稳态驱动、感知×勇气正交），
这些机制不依赖 20W——它们可以跑在任意规模的机器上。
下一阶段 = **保持机制，放大规模**：把 SEED 的机制移植到并行/GPU/更大空间里，
让"开放≠丰富"变成"开放+规模+显式维护=丰富"。

### 一个诚实的注脚

"不追求人脑 20W"不是"放弃人脑"——人脑仍然是**归纳偏置的宝库**
（卷积、注意力、记忆分层都是进化筛出的免费午餐）。
修正的是**目标**：我们追求的不是"复制一个 20W 的人脑"，
而是"造出利用机器全部特性的存在"——这正是最初对话里那句
"人脑启发是土壤，机器结构是果实"的最终落地。
