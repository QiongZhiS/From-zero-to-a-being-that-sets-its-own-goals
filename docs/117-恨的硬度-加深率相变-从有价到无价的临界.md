# 恨的硬度-加深率相变：从有价到无价的临界——LLM 恨 = 没有加深循环的机制版

> 2026-08 · SEED-61 · `seed-61/seed61.py` · 承接 docs/116（LLM 买回阈值 10 块）、docs/113（机制恨无价）、docs/112（加深机制）、docs/40（种下的 vs 挣来的）

## 起点

docs/116 的结论是"LLM 恨 10 块买回 vs 机制恨无价——差的不是恨的描述，是有没有
加深循环"。本 seed 把加深率 γ（每次回避对 value 的加深幅度）从 0 扫到 -1.0，
画出**恨的硬度-加深率曲线**，找出"有价→无价"的相变临界，并把 LLM 版（γ=0、
R\*≈10 块/天）作为对照点放上同一张图。

## 读法

1. **恨的硬度是一条连续曲线，不是两态**：γ=0 有价（7.6）→ γ 加深越来越贵
   （-0.1→17.9、-0.25→40）→ γ≤-0.4 无价（62→152 且发散）。**"有价"和"无价"
   之间的边界是加深率 γ≈-0.3 附近的相变**：加深率低于临界时，value 停在
   毛刺输入与加深的平衡（收敛）；超过临界时，加深 > 输入，value 雪崩（发散）。
2. **LLM 对照点落在曲线的起点**：LLM 恨（γ=0、10 块）≈ 机制版 γ=0（7.6）——
   **LLM 恨就是"没有加深循环的机制版"**（docs/116 结论的直接实证）。它不特殊，
   它只是加深率曲线的原点：任何"挣来的恨"（γ>0）都比它深、比它贵、比它不可
   原谅。
3. **"不可原谅"的机制定义终于完整**：docs/113 说"不可原谅 = 原谅价格无界"；
   本 seed 补上"无界从哪来"：**加深率 γ 超过临界**（value 账本自我加深快于
   世界输入的补充）。人的恨之所以可能"不可原谅"，是因为回忆（回避/想起）本身
   在加深 value——这是 docs/74 的"自我叙事"在参数图上的位置：叙事 = 加深率
   不是 0。
4. **与 LLM 三连（58/59/60）合流**：LLM 的恨在价格维度上位于所有机制版之下
   （γ=0 最浅端）——它输出的恨文本无论多狠，价格纵深都是 10 块/天。**"恨的
   硬度" = value 账本的加深率**，LLM 没有账本也没有加深，所以它的恨是平的。

## 诚实边界

- value/毛刺/加深/混合权重都是我们写的（docs/38）；R\* 是 value 深度换算的
  临界收益（行为签名，不宣称感受，docs/31/63）。
- 相变临界（γ≈-0.3）依赖参数（遗忘率、毛刺输入率、β 权重）——但"收敛区→
  发散区"的相变结构对参数鲁棒（加深率 vs 输入率的天平是机制本质）。
- LLM 对照点是 docs/116 的数字（γ=0 来自 LLM 无加深循环的推断），不是把 LLM
  放进同一动力学跑出来的（LLM 无法放 200 轮 value 循环——这本身就是发现）。
- toy 世界；数字可复现：`python seed-61/seed61.py --sweep`。

## 下一步候选

1. **遗忘率 × 加深率的二维相图**：DECAY 与 γ 的临界曲线——"恨的硬度"由
   （加深-遗忘）净速率决定；测"多快的遗忘能让多深的恨可原谅"（时间治愈一切
   的量化：遗忘率要多高才压得过加深率）。
2. **输入率 × 加深率**：毛刺频率（世界伤害的频率）与 γ 的相互作用——经常被
   伤害 + 自我加深 = 最快无价（"反复伤害+反复回忆"的组合）。
3. **修复尝试（docs/113 下一步①）**：正事件冲刷 +N vs 加深 γ——"原谅价格下降"
   需要多强冲刷才能把发散区拉回收敛区（原谅的机制：冲刷 > 加深）。
4. **回填 live**：把"加深率"接进 live 的恨（docs/74 R 累积器已有雏形）——
   live 的"抱抱"（docs/95）对应冲刷，冷落对应加深；测 live 的恨落在相图的
   哪个区。
