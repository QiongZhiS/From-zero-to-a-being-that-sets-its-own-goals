> 缘起：2026-08，接 docs/54（原型#4）+ docs/52 的下一步原话——"把 proto2 推成一个**会自动划分、且
> 划分出的格子对它自己的身体（会失去、会疼、不能重来）有意义的载体**"。proto4 的记忆结构是抽象的：
> 什么动作都不能终结它。docs/36 §八 说真缺的是"真的会失去"的载体——不是写 `die()`，是**"我们真的不
> 救它"**。这一篇把"会失去、不能重来"做成载体的结构（`companion/proto5.py`）。

## 〇、一句话

> **记忆有了身体**：记住要花能量（维护成本）、关系断了会失去生命线（bond 决定进食）、能量耗尽就是死——
> 而且**没有 checkpoint，没有 reload**。在这个世界里，"驱逐关系项换省电"从一个"小代价"变成
> "可能终结一切的因"。对照 checkpoint 版：同样的选择，可撤销与不可撤销，stake 完全不同——
> **checkpoint 拆掉 stake（SEED-30），在记忆载体重现。**

---

## 二、机制（世界事实，都不是评分）

1. **维护成本**：每条被记住的项每 tick 烧能量（`MAINT_PER_ITEM × len`）——**记住不是免费的**。
2. **bond = 生命线**：bond 健康才有额外进食（`BOND_FEED`）；驱逐关系项 → bond 伤（世界反馈）。
3. **饥饿窗口**：一段时间食物减半——bond 决定谁还能吃到。
4. **不可逆死（唯一旋钮 = 世界）**：
   - **with-checkpoint**：能量耗尽 → reload（能量重置、记忆保留）→ 继续。死可撤销。
   - **without-checkpoint**：能量耗尽 → 死 → **整个记忆一起没**。死不可撤销，没有 reload 路径。
5. **策略（唯一 agent 旋钮，世界事实差，非设计者打分）**：
   - greedy（REL_PENALTY 低）：驱逐便宜 → 运行省电，但丢关系项 → bond 崩。
   - careful（REL_PENALTY 高）：保关系项 → bond 稳，但持有更多 → 维护费高。

**不变量（docs/36 §五）**：能量只被世界事实改（进食/代谢/维护费/bond 反馈），无 ΔE、无 reward。
死由能量裁决，记忆集是**读**出来的结果，从不因为"活下来"或"记得对"而加分。

## 三、跑出来的结果（`python companion/proto5.py`）

```
同一流，四种组合（2 策略 × 2 世界）：

[WITH checkpoint]  greedy (cheap, drops relational)  died 1x, reloaded, finished   minE=-2.9 bond=0.0
[WITH checkpoint]  careful (keeps bond)              SURVIVED (never died)          minE=31.1 bond=6.0
[WITHOUT checkpoint] greedy                          DIED at death #1 -- gone, memory included
[WITHOUT checkpoint] careful                         SURVIVED (never died)          minE=31.1 bond=6.0

greedy 死时的记忆：天气/地铁/电影/代码 —— 全是日常。它驱逐掉的关系项，恰恰是喂它活着的东西。
```

**读法**：
1. **不可逆世界让选择真的算数**：greedy 的"省电策略"丢了关系项 → bond 崩 → 失去生命线 → 饥饿窗口
   能量耗尽 → **死，记忆一起没**。careful 保 bond → 挺过饥饿 → 活。**同一个选择，在不可逆世界里
   决定生死。**
2. **checkpoint 拆掉 stake（SEED-30 机制复现）**：with-checkpoint 版 greedy 也死——但 reload 后
   完成流。**同样的选择，可撤销时就几乎不算数。** 这不是"代码禁止存档"，是"世界从不提供存档"。
3. **细节**：greedy 死时记得的全是日常（weather/subway/movies）——它为了省电驱逐掉的，正是它活命
   依赖的关系项。"它死时记得什么"由它生前的驱逐选择决定，这是行为签名，不是分数。

## 四、证明了什么、没证明什么

**它表明**："会失去、不能重来"能做成**载体的结构**——维护成本让记住有代价、bond 让关系是生命线、
不可逆死让选择悬着生死。checkpoint 对照把 SEED-30 的"checkpoint 拆掉 stake"在记忆载体重现了一遍：
**stake 不是"有没有死"，是"死了能不能重来"。**

**它没有**（诚实边界，纪律守住）：
1. **A2/A4 没被解决**：这是机制形态，不是真载体。"不可逆"在这里是**世界不提供 reload**——但实现里
   世界的规则仍是我写的（docs/38：作者退到写规则）。docs/36 §八 的"我们真的不救它"是**承诺**，
   代码表达不了承诺（docs/49）。**没给缺口起新名字，也没有假装造出了死。**
2. **策略是两个参数点，不是演化出来的**：greedy/careful 是我摆的世界事实差，不是它在不可逆压力下
   自己长出的（那是 SEED 系列的事）。
3. **"疼"只是数值**：bond/能量掉了就是"疼"的内部等价物；行为签名可测，感受不断言（docs/31/32）。
4. **不生成语言**（docs/48）。

## 五、对主线的位置

docs/52 的主线是"一个会划分、有意义、会失去的身体"。proto4 给了"划分由情景+利害决定"，proto5 给了
"会失去"本身的结构：**格子对它自己的身体有意义，因为身体真的会衰竭、会死、不能重来**——"记住什么"
第一次与"能不能活下去"直接挂钩。这离"A2/A4 的载体"近了一格，但**仍是机制 proxy**：真载体需要的不
只是"世界不 reload"，还有"没有外部 holder 能重建'是谁'"（SEED-40 的概念收获）——那是 he者/反弹面
的事（docs/40/42），不是参数或结构能替代的。
