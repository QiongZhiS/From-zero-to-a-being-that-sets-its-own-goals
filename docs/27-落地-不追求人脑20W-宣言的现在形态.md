# 27 — 落地：不追求人脑 20W 宣言的现在形态

> 缘起：2026-08。docs/10 在项目第一阶段（SEED-0..12）末尾写下"机器路线"宣言：
> **不追求人脑的 20W——不复制人脑的算法，而是利用机器特性的算法（搜索/并行演化/
> 神经符号/显式 QD），下一阶段 = 保持机制、放大规模。** 此后项目又跑了 16+ 个实验
> （SEED-13..28）和 16 篇文档。本文档把这份宣言**落地**：和后来学到的东西对账，
> 给出它"现在应该长什么样"。这是 HANDOFF 里悬了很久的待办。
>
> 状态：沉淀/对账。诚实区分"宣言里哪些被证实、哪些被修正"。

---

## 一、先回放：docs/10 当时说了什么

docs/10 的核心主张有三条：
1. **不追求人脑 20W**：20W 是亿万年进化的妥协（慢信号、能耗受限、有限容量），不是最优标志。
2. **利用机器特性**：不模仿人脑算法，用搜索/并行演化/神经符号/显式 QD 等机器强项。
3. **下一阶段 = 保持机制、放大规模**：机制（环境塑造行为、稳态驱动、感知×勇气正交）
   不依赖 20W，可以跑在任意规模机器上；"开放≠丰富"要变成"开放+规模+显式 QD=丰富"。

---

## 二、对账：后来发生了什么（诚实）

### 2.1 "放大规模"这条，被 B0 修了一半

- **B0（SEED-20）**：分工/竞争排斥等**机制结论在 300~5000 个体下不变**——**规模对机制类型不是变量**。
  所以 docs/10 的"放大规模"**不是机制结论的杠杆**。机制结论是尺度无关的，你放到多大都一样。
- **SEED-21c**：规模**是变量，但只对"共识正确性"是**——小社会（N≈8-15）被单个幸运个体主导
  信号的概率高（27%），随规模单调下降。**规模只在"共识/社会判断正确性"这个维度有影响**。

**所以"放大规模"的价值被严格收窄**：它不是机制结论的杠杆（B0），只在"社会共识正确性"
（SEED-21c）和"开放+规模+显式QD=丰富"这个**仍未验证**的合成命题上有意义。

### 2.2 项目实际走向了"主体/机制线"，不是"能力/规模线"

docs/10 设想下一步是"放大规模"（能力线）。但项目实际往**主体线**走了（docs/20 三线图里
行业在做能力线、没人做主体线）：

| 后面做的 | 属于哪条线 | 与"规模"关系 |
|---|---|---|
| SEED-13..17 文化进化 | 信号质量/文化 | 无关 |
| SEED-18/19 延续/连续性 | 主体线（docs/14 内生连续性） | 无关 |
| SEED-24 工具化悖论 | 主体线（目标→工具化） | 无关 |
| SEED-22 稳态耦合 | 主体线（关系=耦合） | 无关 |
| SEED-25 自指自我锁死 | 主体线（自我） | 无关 |
| SEED-26 演化去噪能力 | 认知/去噪二轴 | 无关 |
| SEED-27 验证桥 vs 自审查 | 主体线（反顽固锚） | 无关 |
| SEED-28 双 agent 互惠 | 关系线（真互惠） | 无关 |

**这些全部是机制/主体线，没有一个靠"放大规模"**。所以项目真实的下一步不是"放大规模"，
而是"把主体/关系/自我这条线机制化"——这跟 docs/10 的设想**偏离**了，偏离在了更好的方向
（行业没人做主体线，docs/20）。

### 2.3 真正统一的天花板，是 P20 信号质量——连关系线都封顶

docs/10 说"机制可以跑在任意规模"。但后来最强、最统一的发现是 **docs/12（P20）：信号质量是
一切从经验中提取信息机制的天花板**——而且它**连关系线都封顶了**：

- SEED-28：**双 agent 互惠**，随"误读 partner 的误差"（=信号质量旋钮）升高，合作从 **0.59
  单调塌到 0.02**。**真互惠是涌现的，但被信号质量封顶**。
- SEED-24 工具化、SEED-25 自指锁死、SEED-27 验证桥：全是"信号质量/锚"的变体。

所以"机制可以跑在任意规模"是真的（B0），**但"机制能不能成立"受信号质量约束（P20）**——
这才是贯穿一切的墙，不是规模。

## 三、宣言的"现在形态"（落地）

docs/10 的三条，修正是：

1. **"不追求人脑 20W"——成立，且被强化。** 我们确实没去复制一个 20W 人脑；而且 B0 证明了
   机制结论**尺度无关**（20W 与否无关紧要）。这条不用改。

2. **"利用机器特性"——成立，但要重新理解为"用机器强项去落实机制结论"，不是"更大规模"。**
   机器强项（搜索精确、海量并行、显式 QD、神经符号）是真的，但它们是**机制结论的输入**，
   不是独立的"能力线"。具体落地：
   - **显式 QD**（SEED-12 必要性）：多样性必须显式维护——机器强项（大规模并行采样）正好做这个。
   - **P20 感知设计**：既然信号质量是天花板，机器强项该用来**提高信号质量**（更长的统计窗口、
     更稳的评估、验证桥），而不是盲目加大规模。这是 docs/12/P4 的"提高信号质量 > 调算法"。
   - **验证桥**（P19）：机器强项（可以廉价地独立验证）正好当"反顽固锚"（SEED-27）。
   - **搜索/推演**（AlphaZero 式）：机器可以"想得慢但想得多"——这补的是人脑的慢信号缺陷，
     但**前提是信号质量够**（不然搜索的是噪声，SEED-8 教训）。

3. **"保持机制、放大规模"——这条被 B0 修正为"保持机制、用好信号"。** 规模不是机制结论的杠杆
   （B0），只在**共识正确性**（SEED-21c）上有用。所以真正的杠杆是：
   - **机制层**：尺度无关，不靠规模。靠**信号质量（P20）+ 锚（稳态/验证桥）+ 显式多样性（QD）**。
   - **共识/社会层**：规模**确实**影响正确性（SEED-21c）——这里"更大/更多 agent"有用。

## 四、对项目现在的意义

docs/10 的"机器特性路线"**没有作废，但换了坐标系**：它原以为的杠杆是"规模"，实际杠杆是
"**信号质量 + 锚 + 显式多样性**"。而这正是后半段（SEED-24..28）一直在做、并且全部验证了的：

> **"不追求人脑 20W"是对的——但接下来的工作不是"放大规模"，而是"把机制结论（稳态、
> 连续性、自我、关系、验证）做成鲁棒的、信号质量感知的、有锚的机器实现"。规模只在
> "社会共识正确性"这一个维度有用（SEED-21c），不是主线。**

而这条主线（信号质量 + 锚）恰恰是 B0 和行业都没做的——因为行业在堆规模（能力线），
我们在做信号质量 + 主体线。**docs/20 说的"谁先想清楚，谁定义坐标系"在这里兑现了。**

---

## 五、一句落地的话

> **docs/10 说"不追求人脑 20W、放大规模"——前半句被证实（B0 机制尺度无关），
> 后半句被修正（规模不是机制杠杆，只影响社会共识正确性）。真正的杠杆是
> P20 信号质量 + 稳态/验证锚 + 显式多样性：机制结论尺度无关，但成立与否由
> 信号质量决定（连关系线都封顶，SEED-28）。所以"机器特性路线"的现在形态 =
> 用机器强项把机制结论做成鲁棒、信号质量感知、有锚的实现，而不是盲目加大规模。**
