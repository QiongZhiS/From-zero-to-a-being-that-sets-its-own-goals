## 核心结论

**"合成生命 → 智能涌现 → 主体"的完整链路，目前没有人走通。** 大家都在同一条起跑线上，分头做片段：
- 化学派：真生命，无智能
- 数字派：生命现象，无抽象
- 演化派：环境越玩越好，无自主目标

## 我们的差异点（为什么不是重复造轮子）

1. **概念框架先行**：感知/动作/稳态/主体四词宪法（docs/02）——大多数项目是现象驱动，我们是定义驱动
2. **无外部奖励的严格性**：大多数演化项目偷偷给了 fitness，我们是"能量耗尽"唯一物理规则
3. **完整思想链**：从"算法不高深"到"判据外置的矛盾"再到 SEED 系列实验——哲学到实验一条线
4. **诚实记录失败**：先验鸿沟、惰性极值（docs/05）——论文里看不到这些

## 对标用法

SEED-2/3 设计时可对照：
- 猎物-捕食者动态 → 对照生态学 Lotka-Volterra 与 JaxLife
- 形态/行为多样性 → 对照 Flow-Lenia（但我们不追求形态，追求行为与稳态）
- 持续开放演化 → 对照 POET（但我们的目标不是解迷宫，是主体性）
