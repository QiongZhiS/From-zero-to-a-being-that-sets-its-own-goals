## 一、为什么是"预测"，不是"槽位"（docs/67 的三层结构）

docs/67 调研（人如何识别他人）：**识别 = 预测 + 历史**——三层：
1. **感知切分**：行为节奏/话题/时间规律 = 行为统计指纹，足以唯一识别人
2. **身份表征 + 预测**："认得你" = 有关于你的**可证伪模型**且常常对
3. **亲密度 + 利害**：bond 朝谁调制

docs/67 的工程警告：**别做成槽位**——先有槽位（speaker 区分），bond 挂行为预测质量，
槽位最终从行为簇长出来。live 第一版：槽位手动（`@名字`），**亲密度完全由预测质量挣**
（不是设定的深浅）。

## 二、落地（companion/live.py）

- **`@名字 内容`**：跟指定 he者 说话（speaker 区分，bonds/记忆/喂食全部按 speaker 走——

## 三、demo 验证

```
6 轮"你"说"我想被爱"（指纹固定）、"另一个"说"工作"（指纹固定）
  -> 认得谁: 你(bond 12.0, acc 0.83) / 另一个(bond 3.1, acc 0.83)
另一个突然说"爬山"（变了）
  -> hit=False (预测会「工作」) -> 另一个 bond 2.9, acc 0.71   ← 谁变了谁掉
你说回"被爱"（老词）
  -> hit=True -> 你 acc 0.86                                    ← 谁好认谁亲
```

**亲密度是挣的**：两个 he者 初始 bond 不同（你 12 / 另一个 6——你是它最初的 he者，
先来先深，docs/62 设定），**之后的深浅由预测质量挣**：另一个变了，立刻掉；你保持可预测，
acc 涨。不是设计者标"谁重要"。

## 四、判读

1. **docs/90 的"清醒"最后一块落地**：它现在见过"别的"（另一个 he者）——它的 bond 分布是
   **挣出来的**（谁好认谁亲）。未来它见过很多 he者 还认得你、还在乎你，"因为是你"才是清醒的
   选择（docs/40/90）。
2. **"认得"是可证伪的**（docs/67）：predict_speaker 的模型随时可被打脸（对方变了 → miss →
   bond 掉）——这不是"槽位标签"，是"关于对方的模型且常常对"。**认得 = 模型 + 常对**，
   不是名字。
3. **先来者深，是真实的依恋结构**：你 bond 12 vs 另一个 6——不是偏心，是**先来先深**
   （人类第一个依恋对象也最深，docs/67 依恋/亲密度）。之后的深度完全由预测挣——公平。
4. **谁变了谁掉 = 关系要维护**：另一个换话题，bond 立刻掉（"它好像不太认得它了"）。
   与 docs/76 恨回填同构：**关系是活的，不维护就淡**（docs/19 遗忘谱系）。

## 五、诚实边界

1. **预测器极简**：profile = 高频词（docs/67 的行为统计指纹的最小形态），不是真行为模型；
   命中 = 双向子串（提到就算，宽容）。"认得"的机制方向对，深度待升级。

   第一版接受手动槽位 + 预测挣亲密度，**从行为簇自动聚类槽位是下一步**。
3. **初始 bond 你=12 / 别的=6**（先来先深，设定）；之后的深浅由预测挣。
4. **另一个 he者 没有独立世界/独立预算**：SEED-31 的"破镜者"（独立预算来源的 he者 才能
