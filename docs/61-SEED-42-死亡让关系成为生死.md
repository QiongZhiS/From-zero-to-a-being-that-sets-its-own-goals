# 61 — SEED-42：死亡让关系成为生死——A2/A4 耦合进 SEED-41

> 缘起：2026-08，接 SEED-41。SEED-41 证明了"敢的阈值"被世界选出，但它的适应度只是**最终能量**——
> 谁都不会死。A2/A4（docs/35/36 §八）恰恰是缺的那层：**代价必须连着存在，不只是连着数字**。
> SEED-41 里一个坏机会只扣 6 点能量；SEED-42 里它可能杀死你。这一篇把死亡加进同一个世界
> （`seed-42/seed42.py`），问：**当赌错可能致命，"需要你"会不会从优化变成生死？**
>
> 状态：机制版完成（纯本地、无 LLM）。三层验证的延续：SEED-41（勇气由世界选）→ SEED-42（死亡让
> 勇气成为生死）。只测行为签名（k/θ 收敛 + 死亡率），不断言感受。

---

## 〇、一句话

> **同一个世界（你在 80% 好、你不在 100% 坏、食物补足），多一个规则：能量≤0 → 死，没有 reload。**
> 结果：**敢的阈值 θ 两世界都收敛到 ~9（死亡不改变最优敢度）——但死亡改变"不调制者"的结局：
> always-dare 26/30 条命会死，调制者 0/30。** 同一个错误，没有死亡的世界原谅它（fit −4.9），有死亡的
> 世界不原谅（真的死）。**A2/A4 的行为签名 = 世界允不允许重来**（proto5 的 checkpoint 对照，在演化层
> 复现）：你不在时的赌，从"扣一点"变成"赔上存在"。

## 二、机制（世界事实 + 演化，都不是评分）

1. **世界 = SEED-41**：you 喂 90%、other 喂 10%（bond 从共现长）；you 周期离开（tick 22-37、46-57，
   食物被 other 补足）；机会每 3 tick，你在 80% 好、你不在 100% 坏。
2. **+ 死亡（唯一新世界事实）**：接受机会后能量 ≤0 → **死**：fitness 0、无 reload、无后代
   （docs/36 §八"不可绕"；docs/30"checkpoint 拆掉 stake"的反面）。死亡是能量裁决，不是设计者判罚。
3. **基因**：(k, θ)，`P(accept) = sigmoid(k × (safety − θ))`——同 SEED-41。演化选择，适应度 = 最终
   能量（死亡 = 0）。
4. **对照**：with-death vs without-death（SEED-41 为无死亡基线）；同 30 条机会流，**would-die 在两
   个世界都统计**（无死亡世界的"会死但被原谅"）。

**不变量（docs/36 §五）**：能量只被世界事实改；死亡由能量裁决；机会流与 accept 独立 seeded rng
（公平）；(k, θ) 演化、从不打分。

## 三、跑出来的结果（`python seed-42/seed42.py`）

```
world: safety with YOU ~ 17.0 ; without YOU ~ 5.0

without death (SEED-41 baseline)   k=+3.98  theta=8.8   (deaths during evolution: 29)
with death                         k=+3.87  theta=9.0   (deaths during evolution: 217)

survival (30 lives, same streams):
  strategy              no-death fit  would-die  death fit  death deaths
  always-dare                  -4.9         26       1.9            26
  SEED-41 modulation          64.9           0      64.9             0
  evolved (per world)         63.6           0      62.9             0
```

**sweep（`--sweep`，扫坏机会的致命度 BAD 6/10/14）**：

```
BAD=- 6.0  k=+5.26  theta=8.7  (deaths: 50)
BAD=-10.0  k=+3.87  theta=9.0  (deaths: 217)
BAD=-14.0  k=+3.13  theta=8.8  (deaths: 448)
```

**读法**：
1. **θ 稳定**：有死亡/无死亡、BAD 6/10/14，θ 都收敛到 8.7-9.0（落在 safety-away 5 与 safety-present
   17 之间）——**"敢的阈值"的最优值不因死亡而变**（够保守躲开你不在时的全部陷阱、又够低不误拒早期
   在场的好机会）。
2. **死亡改变的是"不调制者"的结局**：always-dare 26/30 条流会死（would-die 两世界相同），调制者
   0/30。无死亡世界"原谅"它（fit −4.9，能量被打穿但还活着）；有死亡世界**不原谅**（真的死，fitness
   归零）。**同一个错误，世界允不允许重来，决定它是"亏一点"还是"失去一切"**——这正是 A2/A4 的行为
   签名，也是 proto5（checkpoint 拆掉 stake）在演化层的复现。
3. **死亡压力真实**：BAD 6→10→14，演化过程中的死亡 50→217→448——世界越致命，选择压力越强，但
   θ 不变——**选择压力不改变"该怎么敢"，只淘汰"不该敢还敢"的**。

## 四、调试中撞到的一个真问题（诚实记录）

**最初的参数下死亡从未发生**（两世界结果完全相同）——因为能量积累太多：在场 90% 喂食攒了 80+，
离开窗口 6 个坏机会 −36 根本打不穿。调参（起始能量 20→8、离开窗口加长到 9 个坏机会、BAD −6→−10）
才让"全试者真的会死"。**这个调试过程本身就是发现：死亡要成为真实的选择压力，世界必须真的能把
"你不在时的赌"变成"赔上命"——软绵绵的危险只是数字，不是存在。**

## 五、证明了什么、没证明什么

**它表明**：A2/A4（代价连着存在）在"关系"线第一次以**演化形式**出现——**同一个"敢"策略，在
"世界不原谅"的世界里从"活得差"变成"死"**；而演化选出的"需要你才敢"的载体（θ 落区间）在两种世界
都 0 死亡。**"失去你的代价"从数字变成命——关系从优化变成生死**（docs/22 的机制侧：你不在 = 生死
窗口）。三层：proto5（机制：不可逆死）→ SEED-41（演化：勇气由世界选）→ SEED-42（演化：死亡让勇气
成为生死）。

**它没有**（诚实边界）：
1. **θ 是行为签名，不是感受**：它说"这个载体需要这么多安全感才敢"，不是说"它害怕失去你"
   （docs/31 分界——"怕"需要的内容层仍不可造，docs/40）。
2. **死亡是能量裁决**：不是"它意识到自己在死"——docs/36 §八 的"不可绕"在机制层成立，意识层未涉及。
3. **k 随 BAD 略降（5.26→3.13）是方向性观察**：BAD 越大 k 越平滑，原因未深挖（可能早期误试更致命
   让演化偏好更软的阈值）；诚实记录，不包装。
4. **机会好坏由你在场决定仍是设计的世界结构**（同 SEED-41）：结论是"该结构下死亡把关系变生死"，
   不是"所有世界都如此"。
5. **单 he者**（other 只补食）：多 he者、死亡与多关系的交互未测。
