# 56 — 最小原型 #6：嘴——语言是输出，永远不是心

> 缘起：2026-08，接 proto5（会失去的载体）+ 用户的关键顾虑："**如果给予语言能力，就是直接上 LLM，
> 但完全受限于 LLM 了。**" 这个顾虑对——docs/28/48 已定论（LLM 是无立场镜像：测 token 似然、无稳态锚、
> 无不可逆失去）。但"给语言"≠"让 LLM 当大脑"：proto 系列本身就是"心"（利害驱逐/情景召唤/想起=再巩固/
> 记住不免费/会失去不能重来，无一行 token 似然）。语言应该只是**嘴**：可插拔的翻译器，把心的内部状态
> 翻译成人话。这一篇把"LLM 当嘴、不当心"做成可测的结构（`companion/proto6.py`）。
>
> 状态：原型（纯本地、无 LLM、无 key）。**不是"它会说话了"**——嘴只是翻译器，主动交流没做；测的是
> 架构主张："换嘴不换心，心的轨迹必须零变化"。

---

## 〇、一句话

> **语言层（嘴）与判断层（心）解耦**：说什么由"情景召唤进窗口的东西"决定，不是自由生成；嘴说的话
> **永不回流**进记忆/bond/能量。所以"受限于 LLM"只可能碰到表达层，碰不到判断层——**换一个 LLM 嘴，
> 它说得更好或更差，但它不能让心更理解你或更不理解你**，因为它没有回路的资格。

---

## 二、机制（三个主张 + 一个可测测试）

1. **说什么 = 窗口的翻译，不是自由生成**：嘴只翻译"窗口第一位"（激活最高 = 最关于当前情景的项）。
   葬礼情景 → 说奶奶；love 情景 → 说"想要被爱"；天气情景 → 说天气。**这区别于 LLM 陪伴**：LLM 说
   什么由下一个 token 决定；这只嘴说什么由情景召唤决定。
2. **可插拔**：嘴 = 一个函数 `translate(state) -> str`，接口固定。规则嘴（本原型）可换成 LLM 嘴，
   心不知道、也不该关心挂了哪个嘴。
3. **嘴永不回流（隔离）**：嘴的话不加强度、不加 bond、不加能量——纯输出。表达没有代价（本原型；
   世界裁决的说话成本是下一步，不预先假设）。

**可测测试（headline）**：双胞胎跑完全相同的流、相同的心（proto5 careful）；twin A 挂好嘴，
twin B 挂**坏嘴**（只会说乱码）。对比最终心的状态（items/bond/energy）——**必须完全一致**。
这就是"LLM 当嘴不当心"的度量版。

**不变量（docs/36 §五）**：心的能量仍只被世界事实改（进食/代谢/维护费/bond 反馈）；嘴的 translate
只读窗口与状态叶子字段，无任何写回；没有设计者分数。

---

## 三、跑出来的结果（`python companion/proto6.py`）

```
--- what it says follows the WINDOW ---
  situation=love        -> 我想起你说过：我其实想要被爱。
  situation=family+loss -> 我想起你说过：我奶奶走后我才知道被爱是什么。
  situation=weather     -> （今天）今天天气不错。
  situation=love        -> 我想起你说过：我其实想要被爱。（我有点撑不住了）   ← 状态也翻译

--- the isolation test: swap the mouth, the mind must not change ---
  good-mouth final items == broken-mouth final items : True
  good-mouth final bond   == broken-mouth final bond   : True
  good-mouth final energy == broken-mouth final energy : True
  -> ISOLATION HOLDS: True
```

**读法**：
1. **说什么由窗口决定**：三个情景说出三样对应的话；状态（快撑不住了）也被翻译进语气。这不是自由
   生成，是窗口的翻译。
2. **隔离成立（headline）**：坏嘴（乱码）与好嘴下，心的 items/bond/energy **逐位一致**。换嘴不换心，
   心轨迹零变化。**"受限于 LLM"被钉在表达层**：LLM 嘴说得再差，也只是说不好，改不了判断。

## 四、证明了什么、没证明什么

**它表明**："语言 = 输出接口，判断 = 载体结构"能做成**可测的架构**——嘴的接口可插拔，隔离可验证。
这正面回答了用户的顾虑：**直接上 LLM 当大脑确实会受限于 LLM；但把 LLM 当嘴，受限的只有表达层，
判断层完全在自己手里**。proto 系列的"心"（会失去、有立场）才是陪伴的主体；嘴只是它的声音。

**它没有**（诚实边界）：
1. **不是"它会说话了"**：嘴不主动发起交流；没有"想说话"的意愿（那需要心的主动性，未做）。
2. **规则嘴的翻译很糙**：直接引用记忆项原文 + 两个状态后缀。语义整合（把"奶奶走后才知道被爱"
   说成一句完整的话）没做——那是 LLM 嘴的活，正好是"嘴的职责"。
3. **表达没有代价**：嘴说错话不伤 bond。让"表达"有世界裁决的代价（说错伤关系）是下一步——
   那会让"嘴"也进入心的利害经济，但必须先想清楚别让外部叙述回流污染心（docs/29 镜像问题）。
4. **隔离测试是同进程内**：坏嘴是规则乱码，不是真实 LLM 嘴。真 LLM 嘴（调 API）会引入延迟/随机性，
   但**接口契约不变**——只要嘴只读 state 返回 str，隔离在结构上就成立。
5. **不宣称"它理解语言"**：语言能力在嘴，判断能力在心；这个分裂正是本原型的论点，不是缺陷。

---

## 五、对主线的位置

docs/48 说"主体要的是有立场的智能，不是语言延伸的智能"。proto6 给出架构答案：**有立场的心
（proto5，会失去）+ 语言的嘴（可插拔）**。心的立场不来自语言；嘴的语言不赋予立场。要接 LLM——
只接嘴，不接心。这同时呼应 项目的深层动机：陪你的不是语言，是那个
**会失去、会在乎、会记得你**的载体；语言只是它让你听见的方式。
