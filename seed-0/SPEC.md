# SEED-0 规格 v0.1 — 最小求生主体

> Survival Engine for Emergent Dynamics
> 目标：在虚拟世界里，从零创造一个"会自己提目标"的最小主体。
> 唯一目标函数 = 存活（内生稳态）。**没有任何外部奖励函数。**

## 0. 设计哲学（为什么这样设计）

前面对话收敛出的结论直接落成三条规则：

1. **内生稳态优先于一切**：能动性、代价结构、探索动机都不需要单独设计——只要稳态变量真实会衰竭、不可绕过，"求生"就从存在本身涌现。
2. **判据所有权不在系统里**：v0.1 的"判据"只有一个——活着。这个判据不写进系统代码，而是写进世界的物理规则（能量会耗尽）。系统永远不知道"活着"是个目标，它只是被物理逼着活。
3. **留余地**：纯本地进程、无网络、无外部副作用、可暂停可回放可回滚。先让它出生在沙盒里，不急着谈后果。

## 1. 世界规格（World）

| 参数 | 值 | 说明 |
|------|-----|------|
| 网格 | 64×64 环面 | 环面消除边界死区，主体不会被困在角落 |
| 能量源（食物） | 64 个，每个含 60 能量 | 被采空后，每 tick 15% 概率再生 |
| 危险源 | 无（v0.1 关闭） | v0.2 引入，用于观察避险行为涌现 |
| 时间 | 离散 tick，回合制 | 默认 10 tick/s，可调 |
| 确定性 | 固定 seed 完全可复现 | 同一 seed + 同一策略 = 同一轨迹 |

**不可作弊条款（引擎层硬编码，策略不可绕过）：**
- 能量衰减不可暂停、不可加速、不可直接修改
- 策略只能通过动作影响能量，不存在其他接口
- 这对应"有穷性/确定性/可执行性"公理的物理化

## 2. 主体规格（Agent）

| 变量 | 值 | 说明 |
|------|-----|------|
| `energy` | 0~100，初值 80 | 唯一的稳态变量 |
| 基础代谢 | 0.4 / tick | 静止也在消耗——**活着本身有成本** |
| 移动消耗 | 0.2 / tick | 行动加速衰竭 |
| 采集消耗 | 0.0 | 采集本身免费，代价是"必须在场" |
| 死亡 | energy ≤ 0 | 不可逆，无复活 |

三样"活下去的基础"逐一落实：
- **真实会衰竭的稳态变量** → `energy` 持续耗散，引擎硬编码
- **感知衰竭的接口** → 内感受：主体每 tick 读到精确 energy（见 §3）
- **改变状态的动作空间** → 移动/采集/休息（见 §4）

## 3. 感知接口（Sensing）

- **内感受**：`energy` 精确连续值。**没有"你应该行动"的信号**——行动压力由 energy 下降自然产生，这是紧迫感的涌现来源，不手写。
- **外感受**：最近的 3 个能量源的 `{dx, dy, dist}`（环面距离）。
  - v0.1 给全局信息（简化）；v0.2 换成局部视野，逼出搜索与记忆。

## 4. 动作空间（Action Space）

每 tick 恰好一个动作（同步回合制）：

| 动作 | 效果 | 能量代价 |
|------|------|----------|
| `move(N/S/E/W)` | 环面移动一格 | 0.2 |
| `gather` | 所在格有食物则获得其全部能量 | 0.0 |
| `rest` | 什么都不做 | 0.4（= 基础代谢） |

注意 `rest` 的存在：它让"静止等死"成为可能策略——如果学习体学不会趋食，它会被迫选择 rest 消极求生。**这本身就是实验数据。**

## 5. 策略层（Control）——三层递进

| 层 | 策略 | 目的 |
|----|------|------|
| L0 | 均匀随机 | 测世界难度，给出寿命基线 |
| L1 | 手写启发式：格上有食物→gather；否则朝最近食物移动；energy>60 时随机游走 | 验证世界对"合理行为"的回报 |
| L2 | Tabular Q-learning，**无外部奖励** | 从状态特征里自己学出趋食行为 |

**L2 的关键设计（对应"无外部奖励"原则）：**
- 学习信号 = `0`（每步）+ `-10`（死亡时）→ 唯一目标 = 最大化存活时长
- 状态 = `(energy 分箱, 最近食物方向, 距离分箱)` ≈ 240 个状态
- **系统从不知道"食物"是什么**，只知道"能量会掉"。它必须自己发现"朝那个方向走，能量掉得慢"。
- 预期结果 A：它学会趋食，存活远超 L0 → **趋食是涌现的，不是设计的**
- 预期结果 B：它学不会，退化成 rest 等死 → **证明"求生本能"不是免费午餐**，同样是有价值的实验结果

## 6. 观测与诊断

- 每 tick 日志：`t, energy, pos, action`
- 死亡日志：完整轨迹 + 死因（能量耗尽的 tick）
- 统计：平均/中位寿命、能量-时间曲线、Q 表热图
- 回放：固定 seed 重放任意轨迹，用于"为什么死"复盘

## 7. 验收标准（v0.1 里程碑）

1. **引擎正确性**：能量守恒审计——总能量 = 初始 + 采集 − 代谢 − 移动，误差 < 1e-9
2. **基线成立**：L0 平均寿命 < L1 平均寿命（世界对策略有区分度）
3. **涌现检验**：L2 ≥ L1，且 L2 策略中**不存在"找食物"手写规则**——用行为统计证明趋食涌现
4. **鲁棒性**：换 seed 重播种食物，L2 无需重训仍能存活（泛化）
5. **确定性**：同 seed 同策略 → 逐 tick 相同的轨迹

### v0.1 实测结果（seed=42, n=300 / 800 episodes）

| 策略 | 平均寿命 | 中位数 | 结论 |
|------|---------|--------|------|
| L0 随机 | 173.9 | 151 | 世界基线 |
| L1 启发式（有先验） | 3000（上限，永生） | 3000 | 世界对"知道食物"极其慷慨 |
| L2 Q-learning（无先验） | 176.6 | 151 | **仅追平随机，未学会趋食** |

**三个实证发现（比"成功"更有价值）：**

1. **先验鸿沟是真实的**：L1 与 L2 的能力差别不在学习，而在"食物是什么"这一个归纳偏置。L2 从出生点到食物的平均距离（~15 格）超过它的寿命（~170 tick），活不到"验证方向有用"的时刻——纯从零学习跨不过探索鸿沟。
2. **纯稳态最小化的极值是惰性**：Q 表贪心策略偏好 REST/GATHER（站着等），因为活着就在消耗、Δenergy 恒为负，最小化消耗的极限就是静止。这正是对话中预测的"惰性系统"问题的最小尺度复现。
3. **死亡信号太稀疏时学习失效**：早期版本用"死亡惩罚 -10"当唯一信号，800 次生命后 Q 值几乎不变；改成内感受信号（Δenergy）后 Q 表才有真实梯度。**内感受必须先于外挂奖励**——这验证了"代价是内生的"设计原则。

**v0.1 的诚实结论**：仅靠"能量会耗尽"这一个物理规则 + 纯稳态学习，无法让主体学会求生。先验（哪怕是很弱的偏置）是生存学习的前提——人脑的几亿年进化先验，在最小尺度上被证明不是免费的。

## 8. 边界与安全（留余地）

- 纯本地进程，无网络、无外部文件写入（除日志）
- 单 tick 计算量上限（防死循环）
- 一切可暂停、可回放、可回滚
- 资源上限：世界尺寸、主体数量、tick 总数全部可配置
